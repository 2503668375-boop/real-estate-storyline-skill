# 客群分层的文案体系（v9.0）

不同客群、不同业态，买的是不同的东西，文案说的必须是同一件东西。刚需买的是"确定"，改善买的是"全家适配"，顶豪买的是"身份与传承"，文旅买的是"松弛"，商办买的是"效率"。一套文案打天下，等于对所有人都不说话。

## 一、五类客群文案密码

### 1. 刚需/首置（年轻家庭、新市民）

- **买的是什么**：确定性和上岸感——交付安全、得房率、总价可控、学区和通勤的确定性。
- **文案密码**：确定性承诺 + 算得清的账 + 生活切面。不写"梦想家园"，写"首付××万，月供×××，地铁×站到公司"。
- **关键词汇**：算得清、不将就、刚刚好、有自己的家、离地铁×分钟、首付×万起。
- **禁忌**：不谈风险不谈压力；不写"尊贵/奢华/塔尖"（那是别人的客群）；不居高临下。
- **经典范式**：万科"让建筑赞美生命"的社区感；龙湖小户型的"总价友好+生活齐全"；贝壳/链家式"真实数据"信任感。
- **示范句**："首付 68 万，地铁 5 站到公司，周末去楼下公园——你的第一套房子，应该是让你松一口气的那种。"

### 2. 改善/首改（置换家庭）

- **买的是什么**：全家适配升级——面积、安静、老人孩子、通勤与生活品质的全面升级，以及"这次要买对"的确定性。
- **文案密码**：全家场景 + 换房叙事 + 取舍显影。核心是"住在这里的每一天是什么样"。
- **关键词汇**：不用再将就、一家三代、双主卧、安静、换房、把时间还给家人、买对一次。
- **禁忌**：不写"刚需刚改"降格；不回避换房焦虑（回避=不真实）；不堆面积数字，要写空间改变的生活。
- **经典范式**：绿城"屋中有院，院中有树，树上见天，天中有月"；虚构改善项目示例"想换又不敢换——怕买错，怕赌输"。
- **示范句**："孩子在书房写完作业，老人在阳台晒到下午的太阳——你换一次房，换的不只是面积，是全家人各得其所。"

### 3. 顶豪/高端住宅

- **买的是什么**：身份、稀缺、圈层、传承、资产安全性。价格是筛选器不是卖点。
- **文案密码**：克制留白 + 稀缺事实 + 圈层身份 + 时间叙事。说得越少越高级，意象越具体越值钱。
- **关键词汇**：仅××席、藏品、传世、私域、不可复制、为少数人、只在此处。
- **禁忌**：不喊"奢华/顶级/王者"（越喊越廉价）；不堆品牌（石材品牌不是价值）；不写"高品质生活"这种空话。
- **经典范式**：汤臣一品"永不落幕的东方都会"的稀缺感；深圳湾1号"世界湾区的天际线"；奢侈品式"反义词宣言"（香奈儿：奢侈的反义词不是贫穷，是粗俗）。
- **示范句**："这里没有两扇相同的窗。17 层的晨光与 28 层的夜色，是同一块地段的两种私有。"

### 4. 文旅/度假

- **买的是什么**：松弛感、归属感、精神出口、第二人生。不是房子，是生活方式。
- **文案密码**：情绪价值 + 场景自由 + 反内卷叙事 + 社群归属。
- **关键词汇**：慢下来、回到、山海、院子、烟火、社群、另一种活法、离城市×公里。
- **禁忌**：不写投资回报主导（文旅买的是生活不是升值）；不写"度假胜地"泛泛而谈；不堆配套清单。
- **经典范式**：阿那亚"人生可以更美""大海边的诗意生活"；麓湖"守着黛青色的安宁"；大理的小院子"把生活过成诗"。
- **示范句**："周五晚上出发，两小时后，孩子在院子里追萤火虫，你在阳台看山。城市是别人的，这里是你的。"

### 5. 商业/办公/产业园

- **买的是什么**：效率、流量、资产回报、企业形象。理性决策，客户是老板和投资客。
- **文案密码**：数据说话 + 效率叙事 + 区位红利 + 投资账本。
- **关键词汇**：×分钟到机场、日均客流×万、×%出租率、企业总部集聚、按揭月供≈租金、资产配置。
- **禁忌**：不写情怀和诗意（商用客户不吃这套）；不回避收益测算（回避=心里没底）；不堆虚名。
- **经典范式**：写字楼"××CBD，×条地铁交汇"的效率直给；产业园"上下游×分钟车程"的集群叙事；戴森式"把参数翻译成收益"。
- **示范句**："楼下双地铁，到机场 28 分钟；写字楼月供与出租回报打平——买办公室，买的是一台现金流机器。"

## 二、跨品类心法移植（非地产广告怎么用）

| 来源 | 心法 | 移植到地产的用法 |
|---|---|---|
| 耐克 | 命令句情感动员（"Just Do It"） | 行动号召式文案："别再看房了，来住""别等降价，等不起的是孩子上学"——适合刚需/首开 |
| 宜家 | 把产品翻译成生活场景 | 把户型图翻译成"起床-早餐-送娃-回家"的一天；把精装翻译成"孩子在地上爬、老人晚上起夜不绊脚" |
| 戴森 | 把技术参数翻译成生活改善 | 35 分贝→"老人在卧室睡得沉"；恒温恒湿→"回南天家里不发霉"；参数永远跟一个人、一个动作绑定 |
| 可口可乐/星巴克 | 卖情绪与归属 | 文旅/社区盘卖"归属感"：星巴克卖的是"第三空间"，社区盘卖"楼下咖啡店认识邻居" |
| 保时捷/劳力士 | 把消费写成身份叙事 | 顶豪把买房写成"选择一种人生坐标系"：不卖车，卖"开它的人是谁"；不卖房，卖"住在这里的人是谁" |

**跨品类迁移的通用规则**：先问"这个客群买它到底是为了完成什么人生任务"，再选心法；心法必须落回项目事实，禁止只借皮不借骨。

## 三、同一项目内的分层语系

一个项目往往同时面对不同决策阶段的人（第一次来 vs 来三次 vs 竞品对比中）。语系分层：

| 决策阶段 | 文案任务 | 语系 |
|---|---|---|
| 第一次看见 | 建立记忆与好奇 | 意象句、主张句（如"下一站，是确定"） |
| 深入了解 | 建立可信 | 证据句、参数句（35 分贝、×米地铁、×%得房率） |
| 对比犹豫 | 帮客户算账 | 对照句、账本句（二手落地价 vs 全新科技宅） |
| 全家决策 | 打动共同决策者 | 场景句、亲情句（孩子的睡眠、老人的腿脚） |
| 临门一脚 | 降低风险焦虑 | 承诺句、兑现句（交付标准入合同、节点公开） |

## 四、客群×语系矩阵速查

| 客群 | 第一眼 | 建立信任 | 算账 | 全家决策 | 临门一脚 |
|---|---|---|---|---|---|
| 刚需 | "有自己的家" | 总价/月供/交付 | 首付vs月供vs租房 | 孩子的学区 | 烂尾保障/进度公开 |
| 改善 | "换房换生活" | 场景/配置参数 | 卖旧买新账本 | 三代人各得其所 | 交付入合同 |
| 顶豪 | 稀缺/藏品 | 资源账本/圈层 | 资产配置 | 传承/身份 | 私密交付/定制 |
| 文旅 | "另一种活法" | 社群/自然实景 | 使用频率账 | 家庭度假时光 | 淡季服务/托管 |
| 商办 | 效率/流量 | 数据/出租率 | 现金流账 | （企业）团队效率 | 物业服务/法务保障 |

## 五、与现有纪律衔接

- 每类客群文案仍须意象有据（事实支撑）、情绪有度（不煽情）、商业落点（能复述/能到访）；
- 客群画像必须先由前策推导（前策决策链），文案语系是表达层，不得反推客群；
- 对外页面仍禁止内部术语；不同客群文案不得在同一页面混搭（刚需页出现"塔尖"即违和）；
- 文案仍过四硬审与换盘测试；客群分层是"对谁说话"的选择，不是降低标准的借口。
