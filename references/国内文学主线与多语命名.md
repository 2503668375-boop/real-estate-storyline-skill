# 国内文学主线与多语命名

> 11.0适用说明：本文件保留创作方法、历史案例或旧格式经验；固定页数、字数、候选/支柱数量、词性和旧脚本门槛仅作历史参考。新任务按SKILL.md、《价值提炼与推导》及《11版数据契约与验收》执行。关键假设进入决策正文，公共技能不随项目操作自动回写。

## 对外呈现纪律

“文学主线”是写作要求和内部底稿，不是外部提案中的独立章节。不得制作“文学主线关”“情绪标题链自检”“本案文学方法”等页面。文学必须渗透在全案标题、人物动作、价值转场、概念长文、产品场景和传播语系中；市场、成本、利润和排期页保持准确克制。

内部可以生成多个中文或多语候选并核验；外部主稿必须由策划团队给出唯一推荐。其他候选只在确有决策需要时进入附件。不得把三个外语词并列后让甲方自行选择。

## 1. 文学不是润色，是另一条推导轨道

全案同时运行两条轨道：

- **逻辑轨**：事实 → 矛盾 → 判断 → 取舍 → 机制 → 价值 → 经营后果；
- **情绪文学轨**：看见处境 → 认出痛点 → 说破欲望 → 形成价值选择 → 看见改变 → 情绪集中 → 概念命名。

两条轨道逐页咬合。逻辑回答“凭什么”，文学回答“这与我有什么关系”。不能先写完策略，再统一加诗意标题。

## 2. 情绪母线

在价值推导前确定一条情绪母线：

`人物原本怎样生活 → 哪种不适被长期忍受 → 最怕失去什么 → 项目说破了什么 → 哪项真实机制带来转折 → 最终成为怎样的人或家庭`

至少串联5个客户痛点和5个价值回应。痛点不能只是“配套不足、品质不高”，要写成能被看见的动作、关系和代价；价值不能只是功能参数，要写它怎样改变人的时间、尊严、边界、亲密、自由或身份。

## 3. 逻辑文学链

价值推导的每个节点同时写九项：

1. 逻辑节点；
2. 事实判断；
3. 客户痛点；
4. 价值回应；
5. 文学标题；
6. 人物动作；
7. 意象来源；
8. 承接上一节点的句子；
9. 推向下一节点的句子。

文学标题必须仍是判断，不能只剩气氛。意象必须来自土地、人物、地方行为、自然机制、材料或真实空间，不得从奢侈品牌和诗词库随意借用。

示例结构：

- 逻辑判断：双职工家庭最稀缺的是无需反复安排的共同时间；
- 人物动作：父母下班后仍在三个群里协调接送与预约；
- 文学表达：一家人最远的距离，有时只是每个人都在赶自己的下一站；
- 价值回应：连续动线和并行场景让共同生活无需再次组织；
- 下一跳：因此项目要为自然发生的相处留出空间和时间。

## 4. 概念集中

概念出现前，主线必须完成六次收束：

1. 所有土地事实集中到一个项目机制；
2. 所有人物痛点集中到一个共同矛盾；
3. 所有价值点集中到一个清晰选择；
4. 所有产品动作集中到一种生活改变；
5. 所有情绪集中到一个终局感受；
6. 最后才压缩为概念命题、中文主张和命名。

最终概念应让前文产生“只能走到这里”的感觉。若删去前文也能直接喊出口，它多半只是广告词。

概念集中必须形成：

- 核心矛盾；
- 价值选择；
- 概念命题；
- 中文主张；
- 150—400字概念长文；
- 30秒销售讲法；
- 从最后一项证据到概念的“最后一跳”。

## 5. 国内文学表达

国内表达追求含蓄、准确、有人情和可复述，不等于四字词堆叠。

### 宜用

- 人物动作代替阶层标签；
- 关系与代价代替空泛情绪；
- 短句、递进、回环和留白；
- 中国家庭真实的代际、置换、体面、照护、成长与归属；
- 地方人的生活节奏、语言习惯、空间经验和共同记忆；
- 少量有力量的长句承担章节高潮，其余页面克制托举。

### 禁用

- 每页“世界、时代、封面、作品、答案、传奇”；
- 把高净值、圈层、塔尖、藏家当人物精神；
- 没有主体的伪哲学问句；
- 用古诗、法语或艺术家名字替代项目思想；
- 翻译腔、欧化倒装和硬造抽象名词；
- 全案每页都像广告，导致事实和经营失去可信度。

## 6. 多语命名

先读 `概念案名与梵文命名.md`。项目定位、核心概念、推广案名、Slogan、产品/空间命名必须分字段、分页面、分责任。不得因为表达短就把两个抽象汉字同时当定位、概念和案名；定位优先写成完整战略判断，案名长度由识别、口传、搜索、文化和法务决定。

英文、西班牙文、法文等可以用于豪宅、风貌住区、国际生活方式或特定建筑语境，作用是完成声音、气质和文化联想；不能承担中文概念尚未完成的逻辑。

使用顺序：

`中文思想内核成立 → 判断项目需要何种文化语感 → 选择语言 → 生成候选 → 核验语义、发音和文化风险 → 与中文案名建立关系 → 最后做商标与域名核验`

每个外语候选必须记录：

- 语言与原文拼写；
- 标准发音或近似中文读音；
- 字面义、文化语境和隐含联想；
- 与中文概念的对应关系；
- 为什么必须使用该语言，而不是英语或中文；
- 声音、节奏、字形和豪宅调性；
- 母语者可能产生的误读、低俗义或地域风险；
- 商标、企业名称、项目重名和域名核验状态。

外语不是越生僻越高级。优先短、可读、可听写、可被销售正确说出、能自然回到中文内核的名称。

多语命名必须先回答“为什么这个项目非用外语不可”。合格理由包括真实建筑文化、品牌国际关系、目标受众长期使用习惯、城市语境或声音系统需要；“显得高端”不成立。

主稿中的推荐页只保留：

- 推荐名称与语言；
- 发音；
- 中文思想内核；
- 为什么使用该语言；
- 它是推广案名、英文名、楼栋名、会所名还是传播副题；
- 与核心概念、中文案名的关系；
- 母语、商标和重名核验状态。

若没有不可替代理由，优先使用中文。核心概念不自动等于推广案名；推广案名也不自动等于法律备案名。

### 语言选择提示

- **英文**：现代、都会、国际、建筑与生活方式表达，传播门槛最低；
- **法文**：精致、艺术、历史街区、生活美学，但最容易落入伪法式；
- **西班牙文**：阳光、热情、庭院、家族与生活生命力，需避免旅游地产俗套；
- **意大利文**：设计、工艺、建筑、家居与城市生活，需有产品支撑；
- **梵文**：哲学、文化传统与精神语义密度高，但宗教、构词、转写和商业化风险也高；仅在与项目存在真实文化或思想关系时使用，必须同时记录天城体、IAST、通行转写、词根/构词、准确义、发音、母语或学术复核与文化风险；
- 其他语言只在土地、建筑师、品牌血统或真实文化关系成立时使用。

禁止从网络“梵文美词表”直接摘词、把巴利语/印地语误标梵文、用无变音符号的拉丁拼写掩盖构词错误，或以“神秘高级”作为采用理由。未完成复核只能标记“梵文命名方向待核验”。

像用户提到的嘉佰道这类项目，多语名称承担的是调性完成与记忆强化；真正决定项目高度的，仍是前面的中文思想、人物情绪和价值推导。

## 7. 验收

- 只读文学标题，是否能感到情绪递进而非句句同调；
- 去掉文学句，逻辑是否仍成立；
- 去掉数据表，人物处境是否仍具体；
- 每个痛点是否得到一个项目价值回应；
- 最终概念是否汇聚前文，而非突然出现；
- 外语名称是否能用中文解释清楚，销售是否会读，客户是否能记；
- 外语候选未完成母语、商标与重名核验时，只能标记“命名方向待核验”。
- 外部主稿是否只给一个推荐，并明确名称层级；
- 删除独立“文学主线页”后，全案是否仍有连续的情绪推进；若没有，说明文学尚未进入正文。

11.1文学终稿和多语表达按《文案写作与文学表达》及《去AI腔编辑与结构审校》复核。不得把未核验品牌语录作为权威，不仿写在世作家的独特个人风格；一般技法可研究。
