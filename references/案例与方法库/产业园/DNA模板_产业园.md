# 业态DNA模板 · 产业园

> 用法：做产业园项目前先读本模板 + `references/客户产品价格与非住宅.md` + `references/8_2头部房企操盘与市场数据源.md`。产业园的客户是政府+企业两端，产业逻辑先行。

## 适用对象
产业园区（科技园、制造园、总部基地、产城融合）；目标客群是园区定位产业的企业，同时要满足政府产业导入诉求。

## 业态逻辑内核（成败关键一句话）
产业园卖的是**产业生态**——企业入驻是因为这里能招到人、拿到订单、降低配套成本。先有产业定位（为什么是这里、服务什么产业），再有空间产品；政府关系与招商能力是护城河。

## 结构骨架（方案章节）
```
决策摘要 → 城市/区域产业政策与产业基础 → 目标产业的企业数量与扩张需求
→ 竞品园区比较（租金/政策/配套）→ 产业定位与招商对象 → 产品：厂房/办公/研发空间
→ 价格：租金/销售与政策组合 → 定位：某产业的承接平台 → 案名与命名
→ 营销：招商战役与产业运营 → 附录
```

## 常见两难困境
1. 产业宽度 vs 深度——园大面全 vs 单产业做深；
2. 政府诉求 vs 市场收益——产业导入要政绩，投资回报要利润；
3. 厂房效率 vs 形象展示——生产功能 vs 企业门面；
4. 招商速度 vs 产业纯度——先填满还是坚持产业定位；
5. 政策依赖 vs 市场韧性——靠补贴招商还是靠生态留商。

## 概念生成路径
1. 从**目标产业的"扩张时刻"**出发：产业链转移、订单增长、研发中心外迁——为什么是现在、为什么来这里；
2. 找到本项目**承接该产业的具体优势**（产业基础、人才池、交通物流、政策配套）；
3. 写清**为产业做了什么专属安排**（定制厂房、共享实验室、供应链配套、人才公寓）；
4. 定位写"某产业在某某城市的承接平台"，不写"智慧产业园"这种空词；
5. 换盘测试：换到隔壁城市园区还成立即淘汰。

## 关键证据清单
- 城市/区域产业规划与政策（主导产业、补贴、税收优惠）；
- 目标产业企业数量、扩张计划、选址偏好（实地/电话访谈）；
- 竞品园区：租金、入住率、政策、配套、招商进度；
- 基础设施：交通、物流、水电、环保容量。

## 典型产出物
- 产业定位：目标产业选择与理由、招商企业清单（白名单）；
- 产品：空间产品线（标准厂房/研发楼/总部独栋）、共享配套（实验室、会议、食堂、公寓）；
- 价格：租金/销售定价、政策组合（税收返还、装修补贴）、租售策略（先租后售、整租优惠）；
- 营销：招商战役（产业链招商、展会、政企对接）、园区运营（企业服务、圈层活动、政策申报代办）。

## 常见坑
- 没有产业定位就建园（什么产业都招=什么都招不来）；
- 用住宅营销思路做招商（不讲产业逻辑）；
- 过度依赖政策补贴，产业没生态，补贴一停就空；
- 忽视政府和企业的双客户关系。
