# 业态DNA模板 · 办公（写字楼）

> 用法：做办公项目前先读本模板 + `references/客户产品价格与非住宅.md`。办公的"客户"是企业，决策链和住宅完全不同。

## 适用对象
写字楼（含商办综合体中的办公部分）；目标客群是区域内的企业（总部/分支/成长型企业）；租赁或销售均有。

## 业态逻辑内核（成败关键一句话）
企业租/买办公空间的本质是**人才争夺与形象升级**——地段决定通勤与招聘半径，楼宇决定企业形象，成本决定盈亏。办公的价值 = 地段可达性 × 楼宇能效与形象 × 运营服务，三者缺一不可。

## 结构骨架（方案章节）
```
决策摘要 → 城市/板块办公市场（空置率、租金、吸纳量）→ 竞品楼宇比较（硬指标+软服务）
→ 客户：目标企业的扩张路径与选址决策 → 产品：标准层效率与空间方案
→ 价格：租金/售价与回报测算 → 定位：某类企业的最优解
→ 案名与命名 → 营销：渠道与大宗谈判 → 运营服务承诺 → 附录
```

## 常见两难困境
1. 租金水平 vs 出租率——定高租金撑形象还是降租金保流速；
2. 标准层效率 vs 大堂气派——把成本花在功能还是门面；
3. 大客户整层 vs 中小客户散租——租给谁决定了楼宇的档次与风险；
4. 自持运营 vs 散售——产权分散会毁掉楼宇品质；
5. 硬件 vs 服务——物业、餐厅、共享空间等软实力越来越值钱。

## 概念生成路径
1. 从**目标企业的"扩张时刻"**出发：新设总部、区域扩张、从住宅楼/老楼升级——为什么是现在换办公室；
2. 找到本楼宇**可验证的效率证据**（标准层得房率、电梯配置、通勤可达、停车、能耗）；
3. 写清**为哪类企业做了专属安排**（如：为科技企业做弹性办公、为总部企业做整层定制）；
4. 定位写"某类企业的最优解"，不写"城市商务标杆"这类空洞词；
5. 换盘测试后淘汰套话。

## 关键证据清单
- 板块写字楼存量、空置率、租金/售价走势（供需是定价前提）；
- 竞品楼宇硬指标对比：标准层、净高、电梯、停车、配套；
- 目标企业画像：行业、扩张计划、办公面积需求、租金承受力；
- 交通与城市配套兑现节点。

## 典型产出物
- 产品：标准层效率方案（核心筒优化、弹性空间）、形象入口（大堂、电梯厅）、服务配套（餐饮、会议、共享）；
- 价格：租金/售价定价逻辑、投资回报测算（租售比、IRR）、租赁条款（免租期、递增）；
- 营销：渠道分销体系、大宗客户一对一、企业搬迁地图（从哪些楼宇搬迁而来）、楼宇体验日；
- 运营：物业服务标准、企业服务包（工商、政务、社群活动）。

## 常见坑
- 用住宅逻辑做办公（讲户型不讲企业效率）；
- 只有租金没有空置率与吸纳量，市场判断失据；
- 概念停在"商务标杆、智慧办公"，无效率证据；
- 忽视运营服务，散售后楼宇品质失控。
