# 业态DNA模板 · 商业（购物中心/街区商业）

> 用法：做商业项目前先读本模板 + `references/客户产品价格与非住宅.md`。商业的本质是"把人留下来花钱"，先有客流逻辑，再有建筑。

## 适用对象
购物中心、街区商业、社区商业、商业综合体中的商业部分；客户是品牌商户与消费者两端。

## 业态逻辑内核（成败关键一句话）
商业的成败由**客流——驻留——消费——复访**的循环决定。定位是什么（社区型/区域型/目的地型）决定了品牌组合、建筑形态和运营投入；招商是承诺，运营是兑现。

## 结构骨架（方案章节）
```
决策摘要 → 城市/板块消费人口与竞品商业 → 客群：周边居民与目的地客的行为地图
→ 定位：做什么类型的商业 → 业态组合与品牌落位 → 空间设计与动线
→ 价格：租金/销售/物业费结构 → 案名与命名 → 营销：开业战役与持续运营 → 附录
```

## 常见两难困境
1. 招商快 vs 定位高——先填满租户还是坚持定位；
2. 大盒子 vs 街区——室内一站式 vs 户外体验感；
3. 流量品牌 vs 利润品牌——引流和赚钱不是同一批商户；
4. 自持 vs 散售——产权分散直接破坏运营；
5. 线上冲击 vs 线下体验——实体商业必须给线上给不了的体验。

## 概念生成路径
1. 从**周边居民/目标客的一天**出发：下班后、周末、带孩子——什么时刻会来、为什么来；
2. 找到项目**独属的消费理由**（不是"一站式"，是具体的：深夜食堂、亲子街区、户外公园商业）；
3. 写清**业态组合与空间的对应关系**（哪个业态放哪个位置、动线怎么引客）；
4. 定位一句话说明"谁来、为什么来、为什么留下来花钱"；
5. 换盘测试后淘汰一切空洞概念。

## 关键证据清单
- 周边人口与消费力：常住人口、客单价、消费外溢率（去哪个商圈买）；
- 竞品商业：客流、租金、空置率、业态结构；
- 品牌资源：目标商户的拓展计划与租金承受力（招商可行性的前提）；
- 交通可达与停车条件。

## 典型产出物
- 定位与业态组合：商业类型选择、业态配比（零售/餐饮/娱乐/服务）、品牌落位表；
- 空间：动线设计（入口、中庭、连廊）、主题区打造、夜经济与户外空间；
- 价格：租金定价（保底+提成）、销售价或持有测算、物业费结构；
- 营销：开业战役（预热/开业/首月）、会员体系、四季活动运营日历。

## 常见坑
- 先画建筑再想客流（动线反推业态才是对的）；
- 只有招商清单没有消费理由，开业主力店一走就空；
- 用住宅营销思路做商业（不讲客流动线讲概念）；
- 忽视运营，把开业当终点。
