# 业态DNA模板 · 改善（含刚改）

> 用法：做改善/刚改项目前先读本模板 + `references/消费阶层生活方式与设计接口.md` + `references/客群驱动的产品与空间.md`。本模板给结构骨架与推导路径。

## 适用对象
面向"卖旧买新"家庭的核心需求市场；面积段通常在 100-180㎡（刚改 90-130㎡）；客户以置换为主，总价敏感度高，决策链含家庭共同决策。

## 业态逻辑内核（成败关键一句话）
改善客户买的不是房子，是**全家日常的系统性升级**——互不打扰、收纳、通勤、学区、老人孩子各得其所。产品必须证明"现在住的痛点被一件件解决"，价格必须证明"置换划得来"。

## 结构骨架（方案章节）
```
决策摘要 → 城市/板块置换链与供求 → 竞品产品空位 → 客户：在地置换家庭的一天
→ 产品：户型与空间的痛点解法 → 价格：卖旧买新的总价锚与安全线
→ 定位：一家人不再互相迁就 → 案名与命名 → 全周期营销（首开/持销/尾盘）→ 附录
```

## 常见两难困境
1. 房间数量 vs 居住品质——四房更实用但每间变小，三房舒适但不够住；
2. 改善预算 vs 学区/通勤——家庭总要为某一样妥协；
3. 功能（收纳/家政）vs 展示（客厅气派）——预算和面积有限，钱花在哪；
4. 老人同住 vs 两代隐私——三代互不打扰的实现成本高；
5. 买新 vs 等二手——市场不确定性下的决策时机。

## 概念生成路径
1. 从**置换家庭的真实一天**出发：早上谁送娃、晚上谁做饭、周末谁陪老人——找出最痛的那个时刻；
2. 找到市场现有方案为何不够（户型目录式罗列、只讲风格不讲生活）；
3. 写清本项目**具体为哪个痛点做了哪个动作**（如：为两代隐私设双主卧动线、为收纳做整墙系统）；
4. 概念落到人物、动作、场所，如"婆婆在阳台有她的茶角，你在书房有你的工位"；
5. 换盘测试：安到竞品盘还成立即淘汰。

## 关键证据清单
- 板块二手置换链：楼龄10年+小区的挂牌量、成交周期、议价空间（蓄水池够不够大）；
- 竞品面积段去化顺序：先售罄的面积段=真实需求，剩的是外溢池；
- 客户总价带与首付/贷款能力（卖旧所得 + 可调现金）；
- 家庭结构数据：目标板块的三代同堂/双孩/养老比例。

## 典型产出物
- 设计任务书：面积段配比（用决策分叉生成，不套固定菜单）、户型痛点解法、精装配置分级；
- 价格：以"卖出旧房+可承受月供"反推总价带，做进取/基准/防守三情境；
- 营销：样板间按"现在的一天 vs 入住后的一天"做情景动线；首开以竞品余货和来访转认筹决定推货量。

## 常见坑
- 用刚需逻辑做改善（只比谁便宜）；
- 户型靠容积率或竞品惯性指定，没有证据推导；
- 概念用"美好生活"等万能正确句，无人物无动作；
- 价格只有单价没有总价锚，客户算不过置换账。
