# 业态DNA模板 · 文旅（度假/康养/旅居）

> 用法：做文旅项目前先读本模板 + `references/8_2头部房企操盘与市场数据源.md` 的文旅分支。文旅不是"景区边上盖房子"，是先有生活方式运营，再有不动产。

## 适用对象
依托自然资源或文化资源的度假/康养/旅居项目；买家多为城市高净值人群的第二居所；决策周期长，复购与转介绍占比高。

## 业态逻辑内核（成败关键一句话）
文旅卖的是**城市生活的另一面**——时间换空间，用度假的节奏对冲都市的压力。但只有"可抵达性 + 场景营造 + 运营兑现"三者成立，第二居所才买得下手。运营是文旅的命门：房子交付只是起点，社区运营才是价值。

## 结构骨架（方案章节）
```
决策摘要 → 客源城市与可达性（高铁/机场/自驾时间）→ 度假需求与竞争格局（同类度假地）
→ 客户：第二居所家庭的决策逻辑 → 产品：度假场景的空间与户型
→ 价格：自住价值×运营回报的双重账 → 定位：城市生活的另一面
→ 案名与命名 → 营销：体验式营销与社群运营 → 交付后运营承诺 → 附录
```

## 常见两难困境
1. 自住 vs 投资——买家既要度假体验又要资产保值；
2. 运营成本 vs 业主权益——会所、餐厅、活动都要持续投入，谁来买单；
3. 旺季 vs 淡季——度假地的使用频率低，空置期谁来管理；
4. 场景 vs 配套——风景再好，缺医疗、缺商业、缺管家，老人不敢住；
5. 复制 vs 在地——全国文旅盘同质化，在地文化才是护城河。

## 概念生成路径
1. 从**城市客的"逃离时刻"**出发：周五下班到周日返程的完整旅程，找出最想被解决的摩擦；
2. 找到本项目**独有的自然/文化资源**（不是"山清水秀"，是具体的景观面、气候、文脉、活动）；
3. 写清**运营体系如何兑现**：谁运营、什么活动、什么服务、业主什么权益（阿那亚式：社群与公共空间是证据）；
4. 概念落到"一段具体的生活"而非"一种感觉"；
5. 换盘测试：换到任何度假地都成立即淘汰。

## 关键证据清单
- 客源城市人口与高净值密度、到项目地的交通时间与班次；
- 同类度假地竞品：入住率、价格带、运营模式、业主结构；
- 目标客群的第二居所拥有率与复购行为；
- 本地政策：旅游产业扶持、用地性质、运营合规。

## 典型产出物
- 产品：度假户型（景观最大化、社交场景、短期驻留动线）、公区配套清单（业主会所、康养、亲子）；
- 价格：自住价值（可比的度假房价格）×运营回报（租金/分时）双口径；
- 营销：体验式营销（试住、样板体验日）、社群运营（老业主带新）、内容种草（小红书/抖音场景内容）；
- 运营：交付后运营承诺书——谁运营、服务标准、业主权益、费用结构。

## 常见坑
- 把文旅当住宅卖（只讲房子不讲生活）；
- 概念用"诗与远方"，没有可抵达性和运营证据；
- 价格只算自住账，不算运营账，客户下不了手；
- 无运营承诺，交付即价值崩塌。
