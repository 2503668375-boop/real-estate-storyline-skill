# 业态DNA模板 · 顶豪（超高端住宅）

> 用法：做顶豪项目前先读本模板 + `references/顶级住宅客户与价值控制权.md` + `references/消费阶层生活方式与设计接口.md`。本模板给结构骨架与推导路径，不是现成案名或文案。

## 适用对象
目标售价进入本城市新房价格前 5% 的住宅；单价/总价显著高于板块均价；买家以全款或高首付为主。

## 业态逻辑内核（成败关键一句话）
顶豪卖的从来不是面积，是**独占性**——占稀缺资源、占身份认同、占退出通道。地段稀缺是第一道门槛，但只有"资源独占 + 身份叙事 + 资产安全"三者同时成立，价格才能站住。

## 结构骨架（方案章节）
```
决策摘要 → 城市顶豪格局与供应断档 → 本板块独占资源清单 → 客户：多居所家庭与财富代际
→ 产品：稀缺资源×户型独占做法 → 价格：备案/折后/实收三层与退出逻辑
→ 定位：资源占有者的身份叙事 → 案名与命名 → 圈层营销与私域承接 → 交付与物业承诺 → 附录
```

## 常见两难困境（至少从这 5 组里选，避免凭空编）
1. 城市核心 vs 资源景观——要 CBD 便利还是要海/江/山景，两者难以兼得；
2. 大户型去化慢 vs 小户型稀释圈层——面积越大越纯粹但流速越低；
3. 高定价撑身份 vs 高总价挡客群——价格是身份的组成部分，但客群池更小；
4. 私密性 vs 展示性——顶豪客户既怕被打扰又要被看见；
5. 品牌背书 vs 产品主义——客户为品牌买单还是为产品细节买单。

## 概念生成路径（两难 → 取舍 → 概念）
1. 列出本项目的**独占事实**（不是"稀缺""唯一"这种词，是具体资源：一线景观、历史文脉、大师作品、绝版地段）；
2. 找到客户在**多居所身份**（常住/度假/会客/收藏）中的真实矛盾；
3. 写清项目**为独占做了什么、放弃了什么**（如：为景观让出容积率、为圈层砍掉小户型）；
4. 概念必须能解释「只服务谁、不服务谁」；换到竞品盘上还成立即淘汰；
5. 案名只承担识别，不冒充定位。

## 关键证据清单（缺则降级）
- 城市顶豪近3年供应/成交/库存（供应断档是定价前提）；
- 同价位竞品的成交结构与去化周期（多少套、多久卖完）；
- 目标客群的资产与置换证据：多居所数量、现金与融资方式、决策链；
- 本板块/本宗地的独占资源证明（景观面、文脉、规划限制）。

## 典型产出物
- 设计任务书：户型独占做法（框筒结构、无承重柱、X空间、独立动线）、精装设备清单（八衡系统级）、会所与服务接口；
- 价格：三层口径（备案/折后/实收），进取/基准/防守三情境，退出与撤回信号；
- 营销：圈层私域（不是大众广告）、一对一定制服务、KOL/老业主转介、样板区沉浸体验。

## 常见坑（失败回归样本）
- 用改善逻辑放大做顶豪（"大一点、贵一点"不成立）；
- 概念停在"从容、圈层、传承"等词，没有可验证的独占机制；
- 价格只有营销视角，没有退出逻辑和权益折算；
- 案名冒充定位，删去项目名后套到任何顶豪都成立。
