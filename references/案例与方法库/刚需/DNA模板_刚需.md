# 业态DNA模板 · 刚需（首置）

> 用法：做首置/刚需项目前先读本模板 + `references/刚需项目概念格调与购买共鸣.md`。刚需不是"审美较低的人群"，预算边界、家庭变化、日常效率、生活尊严和购买把握共同构成价值。

## 适用对象
首次置业、预算受约束的年轻家庭；面积段通常 60-110㎡；客户最怕买错（用掉六个钱包），决策谨慎且依赖可验证信息。

## 业态逻辑内核（成败关键一句话）
刚需客户买的是**确定性**——在预算内买到能应对未来5-8年家庭变化的房子，且不被坑。产品证明"小而全"，价格证明"买得起且值得"，传播证明"别人也这么选"。

## 结构骨架（方案章节）
```
决策摘要 → 城市/板块供求与首置门槛 → 竞品性价比比较 → 客户：首置夫妻的预算与顾虑
→ 产品：小而全的户型与公区 → 价格：总价门槛与月供可承受度
→ 定位：年轻家庭的第一步 → 案名与命名 → 营销：验证型打法（让客户亲手验证）→ 附录
```

## 常见两难困境
1. 总价 vs 面积——总价锁死，面积和位置只能选一个；
2. 通勤 vs 空间——买远买大还是买近买小；
3. 首付 vs 月供——六个钱包凑首付后，月供还要扛得住；
4. 现在 vs 未来——婚房、生育、老人带娃，户型要能跟着变；
5. 安全感 vs 面子——"上车"心态是羞辱，客户要的是生活尊严。

## 概念生成路径
1. 从**首置家庭的预算表与顾虑清单**出发（不是"理想生活"）；
2. 找到项目在总价约束下**为生活效率做了什么具体安排**（如：小户型里的家政收纳、可变空间、地铁步行时间）；
3. 概念必须给客户**购买把握**——明确的账、明确的取舍、可验证的承诺；
4. 保留客户尊严：不写"逆袭、上车、刚需房"，写"第一步、够得着的生活"；
5. 换盘测试后淘汰一切套话。

## 关键证据清单
- 板块首置门槛：主力总价带、新房/二手价差、月供与家庭收入比；
- 竞品去化：先售罄的面积段与总价段（真实需求信号）；
- 首置客户的行为证据：看房次数、决策周期、被什么打动/劝退；
- 板块通勤与配套兑现节点（地铁开通时间=营销战役锚点）。

## 典型产出物
- 设计任务书：小而全（收纳、可变空间、全龄）、公区安全感、装修配置可感知；
- 价格：总价门槛优先于单价；首开价格与竞品差形成性价比锚点；
- 营销：验证型打法——实体样板/工艺展示/已购客户证言/明码标价，让客户亲手验证承诺，不靠氛围烘托。

## 常见坑
- 把刚需写成"牺牲、妥协、上车"，伤害客户尊严；
- 只讲单价不讲总价和月供账；
- 概念停在"青年大城、理想生活"等词，无人物无动作；
- 用奢华展示挤压真实生活功能（首置客户更信样板间的收纳和动线）。
