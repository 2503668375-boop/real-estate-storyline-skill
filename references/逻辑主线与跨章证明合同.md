# 逻辑主线与跨章证明合同

> 11.0适用说明：本文件保留创作方法、历史案例或旧格式经验；固定页数、字数、候选/支柱数量、词性和旧脚本门槛仅作历史参考。新任务按SKILL.md、《价值提炼与推导》及《11版数据契约与验收》执行。关键假设进入决策正文，公共技能不随项目操作自动回写。

## 目的

逻辑主线不是一句 Slogan，也不是目录。8.1 的主线先完成前策，再进入概念与成交：

`现实变化 → 市场趋势 → 土地能力 → 消费阶层/人物代价 → 竞争失效 → 产品战略取舍 → 产品与设计任务 → 价格经营校验 → 项目定位 → 核心概念 → 推广案名 → 传播转译 → 成交与长期兑现`

后文每章只做两件事：证明这条主线的一个节点，或把它推进到下一个节点。不能出现与主线并列的第二套价值体系。

## 主线命题的合格结构

使用一句可证伪的因果命题：

`因为〔外部趋势与土地能力〕让〔目标消费阶层〕出现〔购买机会/具体代价〕，而市场仍用〔旧答案〕回应，所以项目必须选择〔产品结构与设计任务〕，并在〔经营边界〕内让人物获得〔可感知改变〕；这才形成〔项目定位、核心概念、案名与营销后果〕。`

合格主线必须同时具备：

- 项目独有或高度占有的事实；
- 人物动作和代价，不以阶层标签替代；
- 被拒绝的行业旧答案；
- 明确服务谁、放弃什么；
- 至少三项产品或空间后果；
- 一项价格或经营后果；
- 一项传播与成交后果；
- 成立边界和可证伪条件。

只有“稀缺、中心、品质、松弛、国际、未来”等抽象词，不算主线。

## 双轨推进

每页同时记录两条轨：

- 逻辑轨：本页接住什么事实，推出什么判断；
- 情绪轨：人物从什么不适，走向什么确认。

情绪轨服务逻辑轨，不得制造新的结论。数字、成本和风险页保持准确克制；人物、概念和场景页承担情绪集中。

## 十四节点证明合同

建立 `逻辑主线底稿.json`，至少包含以下十个节点：

1. `现实变化`：什么变化迫使项目现在作答；
2. `市场趋势`：未来6/12/24个月的方向、分化与失效信号；
3. `土地能力`：地块能做什么、不能做什么；
4. `项目问题`：项目真正需要解决的决策；
5. `消费阶层`：谁有动机、支付与置换能力；
6. `人物代价`：谁在什么场景付出什么代价；
7. `竞争失效`：竞品共同答案为何不能解决该代价；
8. `产品取舍`：三种结构比较后服务谁、放弃什么；
9. `设计任务`：面积、户型、空间、机电、服务如何兑现；
10. `价格证明`：货值、利润、现金流、支付与价差怎样成立；
11. `项目定位`：对市场角色的完整战略描述；
12. `核心概念`：对已成立取舍的思想压缩；
13. `推广案名`：对既定身份的识别名称；
14. `传播与成交`：不同受众如何相信、行动并持续反证。

每个节点写：

- `上游依据`
- `本节点结论`
- `人物动作或感受`
- `排除的旧选项`
- `下游决定`
- `证据与状态`
- `成立边界`

缺少上游依据或下游决定的节点不得进入主稿。不得用项目定位、核心概念或案名作为产品取舍的上游证据。

## 章节级证明合同

每章制作前写一张合同：

- 本章接住主线的哪个节点；
- 开章时听众仍不相信什么；
- 本章新增什么证据；
- 本章最终让听众接受什么；
- 本章因此排除哪个旧选项；
- 下一章必须回答什么；
- 若删除本章，主线会在哪里断裂。

章节末使用“已证明什么 → 下一章必须回答什么”转场。不得用“接下来进入产品篇”这类栏目转场代替因果。

## 页面级不可逆推进

页面必须至少完成一项：

- 纠正一个旧认知；
- 揭示一个人物代价；
- 排除一个竞争答案；
- 批准一个战略取舍；
- 证明一个产品机制；
- 解释一个支付理由；
- 改变一个营销动作；
- 暴露一个必须管理的风险。

只增加信息、不改变理解或决定的页面进入附件。

HTML 页面使用：

- `data-proof-node`：`reality`、`problem`、`human-cost`、`competition-failure`、`choice`、`concept`、`product-proof`、`price-proof`、`communication`、`conversion`；
- `data-section`：沿用外部章节；
- `data-prototype`：记录页面结构，不显示在页面上。

同一 `data-proof-node` 可以跨页，但不得在已经进入下游后无理由退回上游。

## 一页纸、标题链与销售讲法同源

以下四处必须表达同一条因果，不得各说一套：

1. 前置一页纸战略总纲；
2. 全案标题链；
3. 30 秒销售讲法；
4. 全周期营销总主题。

30 秒讲法使用：

`因为〔事实〕，所以项目不做〔旧答案〕；它用〔三项机制〕让你获得〔人物改变〕，因此你支付的是〔可验证价值〕，不是一句概念。`

## 反向校验

成稿前逐项测试：

1. **删概念测试**：删掉概念名，前文因果是否仍成立；
2. **换项目测试**：换成最强竞品，主线是否仍成立；若成立，重做；
3. **删章测试**：删除任一章，是否出现明确断点；没有则合并或删除；
4. **产品测试**：主线是否改变至少三项产品决定；
5. **价格测试**：主线是否解释至少一项价差或支付理由；
6. **营销测试**：各阶段主题是否都在推进同一信念；
7. **复述测试**：管理层和销售能否分别在 90 秒、30 秒内复述；
8. **证伪测试**：写清什么新证据出现时必须撤回或改写主线。

## 禁止

- 用一句口号冒充逻辑主线；
- 每章各有一个漂亮概念，彼此没有因果；
- 市场章讲供应，客群章突然讲圈层，产品章又换成审美；
- 概念与已定产品、价格没有可指认映射，或反向要求上游配合文案；
- 章节转场只报目录，不总结证明结果；
- 用重复页眉或装饰性进度条伪装“贯穿全文”。
