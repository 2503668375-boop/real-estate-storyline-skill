# 核心概念生成与比选

> 11.0适用说明：本文件保留创作方法、历史案例或旧格式经验；固定页数、字数、候选/支柱数量、词性和旧脚本门槛仅作历史参考。新任务按SKILL.md、《价值提炼与推导》及《11版数据契约与验收》执行。关键假设进入决策正文，公共技能不随项目操作自动回写。

## 1. 要产出什么

先形成“核心判断”，最后才生成案名和口号。

核心判断要能重新解释项目、客户与市场的关系，必须包含：

`项目事实 + 客户难题 + 市场现有方案为什么不够 + 新判断 + 产品/服务做法 + 对销售经营的影响`

“松弛生活、城市封面、自然美学、未来社区”只是语词，不是概念。单独出现的案名、隐喻、名人引文和视觉风格不计入创意数量。

## 2. 概念推导底稿

发散前先完成 `概念推导底稿`。住宅刚需、首置、首改项目完整读取 `刚需项目概念格调与购买共鸣.md`。底稿必须写清目标人物、购房情境、客户原话/行为、现实约束、人物愿望、两难困境、市场现有方案、项目取舍、独有做法、客户获得的改变、核心判断、可信依据、表达调性、商业任务与边界。缺一项，不得用词语发散掩盖研究缺口。

四个重点方向形成后、最终概念定稿前，强制完整读取 `概念文学跃迁与终审.md`，为每个重点方向建立 `文学跃迁卡`。不得从结构化底稿直接跳到口号；没有人物时刻、动作物件、关系代价、改变后的动作、项目意象和最后一跳的方向直接淘汰。

发散前建立三类带编号的原料：

### 项目事实

至少20条，包括土地前史、规划机制、产品决定、工程代价、运营能力、地方行为、客户行为和经营限制。每条写ID、事实、来源、置信度、它改变什么。

### 语言母体

至少3个，不是“山水、艺术、松弛”等主题词。每个必须写：`真实来源物/场所/动作 → 其形态或运行规律 → 项目如何把它变成空间、服务或经营机制 → 客户能看见的结果 → 为什么不是贴符号`。它是概念与案名的共同根，而不是一张情绪图；没有真实来源物与项目机制的隐喻不进入命名。

### 客户难题

至少8条。每条写谁、想得到什么、同时害怕失去什么、用什么行为证明、项目能否介入。

### 市场套话

至少12条。记录竞品和行业反复使用的价值说法、视觉符号、产品证明与口号结构。它们是必须避开的现成答案，不是灵感库。

## 3. 概念切入角度

从下列角度中选择最能解释本案的6—12个，每个形成2—4个结构不同的初步方向，共不少于24个。先写“反对什么、以什么事实成立、改变什么比较标准”，最后才允许写漂亮词；数量不能代替结构差异：换同义词、换语序、只换意象的方向一律合并。

1. **反常识翻转**：如果行业最相信的那句话恰好错了；
2. **矛盾加压**：把人物想要与害怕失去放在同一句话；
3. **代价显影**：找到客户为旧生活默默支付的时间、关系或身份代价；
4. **身份重命名**：不按财富标签，而按正在形成的新人物身份定义客户；
5. **关系重构**：重新理解家庭、邻里、城市与自然之间的关系；
6. **时间改写**：从一天、十年、代际或城市周期重估项目价值；
7. **空间机制**：从真实总图、动线、边界、密度和可见性中发现思想；
8. **城市权力**：追问谁有资格占有资源、发言、进入或留下；
9. **地方源代码**：从地方人的行为、节奏、技艺与共同记忆提取机制，不抄符号；
10. **自然机制**：从水、风、光、地形、生长和季节的运行方式提取关系；
11. **品牌能力**：把开发主体真正擅长且竞品难复制的组织能力变成价值；
12. **改写市场比较方式**：拒绝行业默认的比较方法，建立新的比较标准。

每个初步方向必须引用至少2条项目事实和1个客户难题，并写明：购房情境、客户原话/行为、两难困境、它反对什么、让人意外的新理解、项目取舍、30秒人物场景、单一情绪、具体产品/服务做法、可信依据、若成立会改变什么。只有换词而没有改变事实组合、客户难题、项目取舍和产品后果的方向不计数。

## 4. 三轮筛选与深化

### 第一轮：60个初步方向去同义

按“事实组合＋人物矛盾＋因果骨架＋产品后果”聚类。仅更换“时间、陪伴、秩序、附近、松弛”等词的方向合并。每个引擎至少保留1个结构不同的方向。

### 第二轮：18个深化方向

从初步方向中选18个，不按文采排名。每个方向至少完成两种深化：

- 反转：把行业旧答案推到相反方向；
- 加压：提高人物选择的代价；
- 具身：让思想变成可拍、可走、可触摸的动作；
- 换尺度：在城市、社区、家庭、个体间切换；
- 机制化：把情绪词改写成产品或运营机制；
- 去修辞：删掉案名、名言和美图后重述；
- 商业化：说明它怎样改变产品、价格、供货和展示；
- 文化化：找到超越功能利益但不脱离真实生活的公共意义。

每个深化方向写清：核心判断、新理解、购房情境、两难困境、市场现有方案、项目取舍、不可替代的因果、人物场景、单一情绪调性、文学表达、3—5条可信依据、至少5项已定产品/经营结论的对应关系、它能带出的展示/销售/营销动作、不成立条件。产品/经营字段用于检验概念是否忠实总结前策，不得让概念反向发明或修改产品。

### 第三轮：四个重点方向比选

保留4个真正不同的重点方向。分别请六种角色反向挑刺：

1. 创意总监：是否意外、准确、有语言力量；
2. 竞品偷窃者：怎样把它改两个字偷走；
3. 客户怀疑者：为什么不信、为什么不愿多付钱；
4. 产品工程师：哪里无法画进总图、户型或服务；
5. 文化批评者：是否挪用历史、消费焦虑或伪装高级；
6. 经营负责人：是否改变供货、成本、展示和成交。

挑刺不是只写“通过/不通过”。每次必须记录最强质疑、暴露的问题、修复后的方向和是否仍值得保留。四个方向至少完成24张挑刺记录。

每个重点方向还必须逐项回答“判断新、占有准、人物真、语言亮”。这是四项硬审，不是四个可相互补偿的分数；任一项不成立即淘汰。尤其要拦截“每个选择都经得起推敲”一类万能正确句：正确、顺口和正能量不能代替项目判断。

## 5. 最终选择

最终选择必须同时交代：

- 为什么它最值得押注，而非最高分平均主义；
- 它舍弃了什么客户、审美或产品选项；
- 第二名为什么没有被选；
- 哪条新证据出现时会推翻它；
- 它怎样生成价值体系、空间概念、人文传播、案名和战役。

不能选择“最安全、最全面、最容易解释”的方向。顶级概念通常具有清晰的排他性：一部分人会立刻认同，另一部分人会明确觉得它不属于自己。

### 概念初测不能省略

四个方向比选后，先做内部去品牌测试，再用最终方向做客户概念初测。至少记录5秒回述、相关性、可信依据、具体画面、竞品差异和下一步意向。内部评分、管理层喜欢或销售觉得顺口都不能代替测试。没有真实样本时可继续形成方案方向，但必须标注“方向待验证”，不得称为最终通过。

### 警戒词

“不将就、不妥协、不止、不负、刚刚好、更懂生活、全能大盘、青年大城、理想生活、未来答案”若没有明确对象、购房情境、客户两难、项目取舍、独有做法和实际产品营销动作，直接淘汰，不进入文字优化。“不将就的大盘”固定作为失败回归样本。

## 6. 命名纪律

四个重点方向完成反向挑刺前，禁止把案名、Slogan、罕见字和视觉风格当评分对象，但必须检验概念是否能长出准确、有情绪力量的中文表达。先选判断，再寻找语言。

命名阶段为最终概念生成至少三套语系：

- 直陈判断：一句准确的新价值判断；
- 人物语言：目标客户愿意说出口的话；
- 象征系统：能延展空间、栏目、活动和视觉的母体。

语言不能挽救因果薄弱的概念。命名前再做一次“语言工艺”检查：核心概念应是可争论的新判断；推广案名应是可识别、可口传、可检索的身份；产品系名称才可承载系列化世界观。不得把产品系的宏大四字、项目概念与法定/推广案名混用。

豪宅或特定文化语境项目可在中文内核成立后探索多语命名，完整规则读取 `概念案名与梵文命名.md`（全语种矩阵：梵文/法文/意文/英文，语种决策树与避坑清单）。外语负责调性完成，中文负责思想解释；中文内核不成立时，外文不能救场。

## 7. AI运行纪律

- 分轮生成，禁止一次提示同时要求60个初步方向、评分和最终答案；
- 每一轮只读取必要原料，避免上一轮的漂亮措辞污染后续判断；
- 先输出结构化底稿，再写文学表达；
- 评分只用于排序，硬断点和对抗攻击优先于总分；
- 淘汰稿保留原因，避免下一轮换词复活；
- 生成者不得独自宣布终局；没有独立审查条件时标记待审。
- 生成者不得自己填写“独立创意总监通过”后继续交付；独立终审缺失时必须标记 `结构通过，待独立创意终审`，不得上封面。
- 生成者、评分者与客户测试记录分离；不得先解释概念再询问是否喜欢；
- 评分前先执行“换给两个竞品”“删除项目名”“只看一句话5秒回述”“能否生成具体产品与营销动作”四项测试；
- 格调不以罕见字、外语、豪宅词或句子长度判断，而以研究是否准确、是否尊重客户、表达是否克制、是否有地方质感和项目证明判断。
