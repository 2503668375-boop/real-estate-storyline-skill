# 完整外部提案导演法

> 11.0适用说明：本文件保留创作方法、历史案例或旧格式经验；固定页数、字数、候选/支柱数量、词性和旧脚本门槛仅作历史参考。新任务按SKILL.md、《价值提炼与推导》及《11版数据契约与验收》执行。关键假设进入决策正文，公共技能不随项目操作自动回写。

## 1. 目的

内部工作按专业流程生产结论，外部提案按听众的认知顺序组织结论。两者不是同一目录。

完整读取 `逻辑主线与跨章证明合同.md`。十二幕沿同一条主线展开十四个证明节点；每章制作前写章节证明合同，章末用“已证明什么 → 下一章必须回答什么”转场。

内部先研究、发散、评分、否决、校验；外部听众只需要回答：

1. 今天为什么必须讨论这个项目；
2. 市场和客户发生了什么；
3. 旧答案为什么不够；
4. 哪些市场、消费、土地和经营证据形成了决策分叉，最终建议做出什么产品选择；
5. 产品与经营成立后怎样形成定位、概念、案名和传播；
6. 首开如何把它变成真实成交；
7. 需要公司或甲方批准什么。

## 2. 完整提案的十二幕

总页数通常70—120页。以下是内容预算，不是固定模板；可因项目阶段合并相邻页，但不得删除责任。

### 幕一｜把问题说准（4—7页）

- 封面；
- 本次决策议题；
- 目录或阅读地图；
- 一页纸战略总纲；
- 项目使命与本次需要批准的事项。

一页纸必须在前5个内容页内出现，作为全案脊柱。

### 幕二｜城市正在换一种答案（6—10页）

- 政策、人口、资产、消费、供需、成交、库存、价格和资金变化；
- J.P. Morgan等宏观机构、趋势动物/冰山指数等高频观察与官方数据的交叉验证；
- 给出未来6/12/24个月的明确趋势结论、分化对象和失效信号；
- 每项变化都导出对项目的具体后果；
- 不做宏观材料堆积，只保留会改变产品、价格、供货或传播的事实。

章节结尾提出：市场真正奖励的已不是哪一种旧价值。

### 幕三｜竞争已经把什么说满了（6—10页）

- 直接竞品、替代竞品、未来供应；
- 产品、总价、去化、话语、证据、客户重叠；
- 竞争代码地图和空位判断；
- 项目不应再重复的旧答案。

### 幕四｜这块地真正难在什么（5—9页）

- 项目身份、规划指标、资源、限制、历史与品牌能力；
- 不可替代事实及来源；
- 优势与代价并存的土地矛盾；
- 项目必须解决的经营命题。

### 幕五｜谁会为这个答案付钱（8—12页）

- 真实成交、访谈、资产与家庭决策证据；
- 核心购买者、共同决策者和影响者；
- 资产、现金、融资、可承受总价；
- 置换/迁居/家庭事件的触发链；
- 看房、比较、否决、复访和成交链；
- 客群规模与货量的初步匹配。
- 家务、清洁、洗护、厨房、网络、健康、适老、宠物、居家办公和社交行为；
- 行为怎样形成空间、机电、收纳、设备和服务接口。

标题必须写人物处境，不以“高净值、精英、改善”代替人。

### 幕六｜从消费行为走到产品选择（12—20页）

- 趋势、土地、客群与行为共同形成的产品机会；
- 产品战略总图：客群—总价—面积—套数—货值；
- 市场趋势、消费趋势、土地能力、竞品空位、支付和经营怎样形成决策分叉；
- 由分叉生成的产品情境及反事实；数量和类型不预设；
- 低密地块把稀缺土地能力转化为何种客户结果，为什么不是惯性80㎡或自动豪宅；
- 唯一推荐的面积段、房型、套数与角色；
- 总图、建筑、园林、公区、户内、精装、机电、物业/服务任务；
- 扫拖机器人上下水、洗烘、厨房空调、网络、适老、宠物等行为接口；
- 重点房间逐一写任务、参数、成本和支付理由；
- 图纸缺失时明确“设计任务书”与待验证项。

产品选择必须在概念之前成立。空间建议来自人物动作，不从通用“会所、连廊、庭院”词库出发。

### 幕七｜为什么产品与价格成立（8—13页）

- 计价口径与可售资源；
- 成本结构及来源/假设；
- 单位成本、盈亏平衡、现金流安全线；
- 目标利润与目标利润售价；
- 竞品可实现区间和客户支付上限；
- 产品、楼栋、楼层、景观、户型价差；
- 首推货量与推荐首开成交价；
- 进取/基准/防守敏感性；
- 收入、毛利额、毛利率、现金峰值和切换信号；
- 需补数据和财务审批事项。

### 幕八｜把产品选择集中为定位、概念与案名（12—18页）

只呈现外部价值推导：

1. 趋势与土地能力；
2. 消费阶层与人物代价；
3. 竞品旧答案；
4. 证据生成的产品情境与唯一取舍；
5. 产品和经营如何成立；
6. 项目在市场中承担什么角色；
7. 完整项目定位；
8. 3—5个价值支柱；
9. 所有价值如何集中为一个生活改变；
10. 最后一跳与核心概念；
11. 推广案名及其与概念的关系；
12. 150—400字概念长文与30秒讲法；
13. 人物在同一天前后动作如何改变，以及主意象怎样从事实走到概念。

不得呈现60个种子、四强比赛、评分、评审人或否决红线。项目定位、核心概念、推广案名和Slogan必须分列；多语或梵文未核验时只标方向待验证。

此幕通常需要12—18个有效页面。同步读取 `价值叙事与文学表达.md`，以场景单元、情绪曲线、意象递进和前后动作对照提升感染力；市场与经营证据保持克制，禁止用文学跨越逻辑断点。

### 幕九｜把同一个价值说给不同的人（7—11页）

- 人文概念；
- 核心购买者、家庭共同决策者、市场解释者、社群种子的主要顾虑；
- 每类受众的主信息、证据门槛、讲述者和行动；
- “看见—认出—相信—参与—见证”内容五章；
- 中文概念语系、视觉母体、销售口径；
- 延续幕八的唯一案名和多语层级，不在传播章重新命名。

### 幕十｜媒介与案场怎样承接价值（6—10页）

- 内容资产与传播母题；
- 官方、垂直、大V、本地号、社交平台、私域、渠道的分工；
- 案场、示范区、样板间、销售物料和销售话术；
- 从曝光、留资、到访、复访、认筹到成交的漏斗；
- 预算、业绩认定、KPI和负责人。

价值体系已在幕八和幕九建立，不得在媒介之后重新出现。

### 幕十一｜成交是一场全周期战役（18—28页）

- 市场阶段、目标库存、主题承诺、客群状态和漏斗；
- 全周期战役总图与预算优先级；
- 线上内容、搜索、短视频/直播、私域的职责和连续铺排；
- 线下案场、样板、工地、城市触点与客户亲手验证；
- 圈层入口、信任来源、进入方式、合作方与销售承接；
- 首开前120—90天；
- 90—60天；
- 60—30天；
- 前30天至开盘；
- 开盘当周；
- 首开后首周；
- 首开后首月；
- 每次加推；
- 关键发布、样板开放、圈层活动、登记冻资、认筹选房、签约按揭；
- 开盘日流程、岗位、销控、直播、媒体、接待和应急；
- 价格、库存、渠道、舆情与天气预案；
- 预算、负责人、响应SLA、KPI、业绩认定和切换信号；
- 持销、尾盘、交付、业主共创与转介绍。

完整营销另需覆盖持销、尾盘/现房和交付入住；可在幕十一扩展，或在幕十二按组织与运营责任呈现。不得在首开后停止。

每个关键阶段形成 `线上触达 → 线下验证 → 圈层/私域信任 → 销售下一步 → 复盘` 闭环。动作从主题、客户信念、市场和库存生成，不从平台或通用活动名称倒推。详细执行读取 `整合营销战役与创意动作.md`。

### 幕十二｜把方案变成组织动作（4—8页）

- 总排期；
- 工作分解、甲乙方负责人和协同机制；
- 预算总览；
- 关键决策与审批节点；
- 风险清单和补证计划；
- 结论与需批准事项。

## 3. 叙事转场

每章末用“已证明什么 → 下一章必须回答什么”转场。例如：

- 市场证明核心区仍有支付力，但还没有证明谁会为本项目支付；
- 客群与行为证明了人物代价，但还没有证明项目应选择哪种产品结构；
- 产品比较证明了设计方向，但还没有证明货值、利润和价格成立；
- 产品和经营成立后，接下来才回答项目应如何定位、概念化和命名；
- 定位与概念准确总结了前策选择，接下来证明如何形成首开势能。

禁止突然插入与上一章无因果关系的模块。

## 4. 主稿与附件

主稿负责决策和叙事；附件负责核验：

- 完整数据表；
- 访谈纪要；
- 来源清单；
- 竞品明细；
- 产品计算；
- 成本与现金流明细；
- 备选概念和命名；
- 内部审查记录。

内部审查记录原则上不外发。确需项目组存档时单独成册，不附在客户主稿之后。

## 5. 唯一推荐纪律

任何需要甲方批准的核心问题，主稿都必须写：

- 推荐什么；
- 为什么；
- 放弃了什么；
- 成立条件；
- 风险；
- 下一步动作。

不允许只列方向让听众替策划团队完成判断。情境数量由决策分叉决定，但必须明确一个推荐情境、被排除的关键反事实和切换条件。

## 6. 标题链

标题必须是完整判断，并带人物感受或决策后果。整套标题连读应像一本故事：

`城市变了 → 人仍被旧生活困住 → 竞争只是在放大旧答案 → 土地提供新的能力 → 证据生成分叉并作出产品选择 → 价格证明选择可经营 → 定位与概念总结它 → 案名让它被识别 → 传播让不同人认出自己 → 全周期战役让价值成为行动与长期证据`

栏目名只用于小型章节标识，不能占据主标题。
