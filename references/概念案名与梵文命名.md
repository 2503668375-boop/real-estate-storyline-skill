# 概念、案名与多语命名

> 本文件覆盖全语种命名体系：梵文（重点）、法文、意大利文/西班牙文、英文、日文等。任何语种进入候选前，先过第 1-3 节的身份分层与生成顺序，再查对应语种的适用边界与候选卡。

## 1. 五种身份

| 身份 | 回答问题 | 合格形式 | 失败方式 |
|---|---|---|---|
| 项目定位 | 为谁、解决什么、以何种能力占据什么角色 | 完整战略判断 | 两个空泛字 |
| 核心概念 | 全案相信什么、选择什么 | 命题/短语/思想母题 | 当成项目名称 |
| 推广案名 | 客户怎样识别、搜索、口传和长期记住 | 可注册名称 | 用概念直接顶替 |
| Slogan | 某阶段怎样说服 | 完整传播句 | 承担全部定位 |
| 产品命名 | 子系统怎样被理解 | 分层名称体系 | 与母概念无关 |

内部字段和外部页面都必须标注身份。一个表达最多承担一个主身份；需要跨层引用时明确写“由核心概念派生”，不得含混。

## 2. 不迷信两个字

先写项目定位完整句，再决定是否需要短名。推广案名字数由以下因素决定：

- 开发商品牌冠名长度；
- 城市已有项目密度与重名；
- 客户能否听写和搜索；
- 文化与地名关系；
- 法律和推广使用场景；
- 子品牌体系；
- 视觉与口播节奏。

两字、三字、四字、五至六字、中文+外文组合均可。禁止把“高端=两个生僻字”“刚需=两个温暖字”当规则。

## 3. 生成顺序

`完整定位句 → 核心价值选择 → 核心概念命题 → 名称策略 → 多长度候选 → 语音/语义/文化/法务筛选 → 唯一推广案名 → Slogan与子命名`

在核心概念之前不得定案名。案名不得反过来要求定位配合其字面。

## 4. 梵文适用边界

只有满足至少一项时进入候选：

- 项目与印度文化、佛教/瑜伽/哲学传统、南亚建筑或品牌有真实关系；
- 核心概念确有一个无法被中文/英文同等表达的梵文思想；
- 目标受众能识别或愿意学习该文化语感；
- 梵文用作经核验的国际副名、空间名或文化章节，而非伪装成法律案名。

“神秘、古老、听起来高级”不是理由。涉及宗教、神祇、经文、种姓、仪式、死亡和禁忌的词，必须由合格母语/学术顾问复核。

## 5. 梵文候选卡

每个候选记录：

- 天城体；
- IAST（含变音符号）；
- 通行拉丁转写；
- 近似中文读音与重音提示；
- 词根、词性、格/数或复合构词；
- 字面义、经典语境、现代语境；
- 是否为巴利语、印地语或其他语言，禁止误标梵文；
- 与中文概念的准确对应与不可替代理由；
- 宗教、地域、性别、阶层和商业化风险；
- 中国客户无提示读音测试；
- 母语者/梵文学者复核人、日期与结论；
- 中国商标、项目重名、搜索、域名和社交账号状态；
- 使用层级：推广案名/国际副名/空间名/传播题。

未完成语言和文化复核时，只能写“梵文命名方向待核验”。

## 6. 三轮测试

1. **盲读**：20名目标客户不看解释读出并写下联想；
2. **回译**：母语者把候选解释回中文，检查是否仍是原概念；
3. **场景**：销售电话、地图搜索、合同附件、家人转述、车载导航和社交平台中测试。

名称需要超过40字解释才能显得正确，或多数人无法稳定听写时，不进入主案名。

## 7. 外部推荐页

只呈现一个推荐：

`推广案名｜读法｜名称策略｜中文内核｜与核心概念的关系｜采用理由｜使用层级｜核验状态`

梵文若仅是空间名或国际副名，必须明确，不得利用外语模糊项目身份。备选进入内部底稿或确有决策需要的附件。

## 8. 全语种适用矩阵

中文负责思想，外文负责调性。外文名进入候选必须同时满足：**中文内核先成立**（去掉外文，中文名+概念仍完整）、**语种与项目有真实关系**、**目标客群能识别或愿意学习**、**完成商标/发音/文化三重核验**。

| 语种 | 适用业态 | 调性作用 | 真实案例 | 典型结构 |
|---|---|---|---|---|
| 梵文 | 顶豪、文化/康养文旅、与印度哲学/佛教传统真实相关的项目 | 精神性、哲思、永恒感 | 梵悦·108、梵悦·万国府 | 中文主名+数字锚点（梵悦·108） |
| 法文 | 法式风格高端住宅、浪漫/优雅调性的改善盘 | 优雅、浪漫、生活艺术 | 印象巴黎、巴黎春天 | 中文表意+法文副名；法语单词（Belle Époque 等）只做空间名 |
| 意大利文/西班牙文 | 庄园系、滨海度假、托斯卡纳风格 | 度假感、庄园感、闲适 | 利海·托斯卡纳、帕提欧公馆 | 风格词+中文（托斯卡纳/帕提欧） |
| 英文 | 全球视野项目、国际化社区、滨海/度假、商务综合体 | 国际化、现代、效率 | 蔚蓝东岸、K.SUMMIT嘉峯汇、UPTOWN | 城市/概念+英文；或英文做国际副名 |
| 日文/德文 | 极少用（除非项目与相应文化真实相关，如日式园林盘） | 克制、秩序、匠心 | 未检索到正面主案名案例 | 仅空间名/景观名 |

## 9. 语种选择决策树

```
中文内核成立了吗？
 ├─ 否 → 先解决中文概念，外文不能救场
 └─ 是 → 项目与某语种文化有真实关系吗？
      ├─ 否 → 不用外文；中文案名做足
      └─ 是 → 该语种能比中文更精准表达一个核心概念吗？
           ├─ 否 → 外文只做副名/空间名
           └─ 是 → 目标客群能识别/愿意学习吗？
                ├─ 否 → 退回中文
                └─ 是 → 过候选卡（发音/文化/商标/搜索）→ 三轮测试
```

## 10. 多语命名避坑清单

1. **发音禁忌**：中文读音不能产生不雅/歧义谐音；外文读音要让销售员和客户都能念；
2. **文化挪用**：不要像"碧桂园梵高的海"（西方艺术+海边=东拼西凑被群嘲）；外文必须与项目有真实血缘；
3. **商标显著性**：通用词（Avenue/Bay/One）难注册；先查中国商标局与域名/社交账号；
4. **地名监管**：多地已出台建筑命名规范（如武汉、南宁限制"欧洲城""巴黎春天"式洋名），命名前查当地《建筑物命名管理办法》；
5. **去掉外文后仍成立**：中文名独立可识别、可搜索、可口传；外文是加分项不是必需品；
6. **禁止三语并列让甲方选**：外部只给唯一推荐，候选进内部底稿；
7. **宗教/神祇词**：梵文涉及神祇、经文、种姓、仪式必须母语/学术顾问复核（见第 4 节）；
8. **层级纪律**：外文做推广案名=承担全部识别责任；做空间名/国际副名=必须明示，不得模糊项目身份（见第 7 节）。
