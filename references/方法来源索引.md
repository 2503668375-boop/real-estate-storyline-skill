# 方法来源索引

本文件只记录可复用机制与公开来源，不复制案例文案。使用时必须重新核验发布日期、项目阶段和适用边界。

## 客户价值与决策

- Strategyzer, Value Proposition Canvas  
  https://www.strategyzer.com/library/the-value-proposition-canvas  
  借鉴机制：把客户任务、痛点、收益与项目的减痛、增益机制对应；不把客户画像等同于购买原因。

- Christensen 等，Know Your Customers’ “Jobs to Be Done”  
  https://hbr.org/2016/09/know-your-customers-jobs-to-be-done  
  借鉴机制：关注客户在特定情境中想完成的功能、情感和社会进步，而非只按年龄收入分组。

- Google, Decoding Decisions / Messy Middle  
  https://www.thinkwithgoogle.com/_qs/documents/18366/Decoding_Decisions_Marketing_in_the_Messy_Middle.pdf  
  借鉴机制：传播在探索、比较和购买之间持续提供降低风险、增强确信的证据。

## 地产故事线与价值表达

- 德科地产频道，《刘德科是这么捕捉“故事线”的》  
  https://news.qq.com/rain/a/20250401A09CGO00  
  借鉴机制：故事线可从产品闪光点、用户共情、地理情感、城市精神、文明观照等不同尺度进入，但必须回到项目自身。

- 真叫卢俊团队，《我们如何为一个百亿单盘做策划的》  
  https://mp.weixin.qq.com/s/oUNn0aYJUU_eEbsi3fKuXQ  
  借鉴机制：通过跨部门深访，把产品决定的原因、代价和结果逐层剥开；以核心价值和标签重组产品，而不是照规划、建筑、景观、室内目录罗列。

- 博加尹山湖公开案例索引  
  https://www.m448.com/info/docview_289874.html  
  借鉴机制：先定义项目必须解决的认同问题；通过实地调研、客户反馈和多次自我推翻收窄结论，不把第一次洞察当答案。

- 公开 GitHub Skill：acui-real-property-storyline  
  https://github.com/cuiyan0412/acui-real-property-storyline  
  借鉴机制：按住宅、办公、商业分流，并用母题/子线统摄混合业态；其公开结构作为对照，不复制命名、句式或案例内容。

## 概念提炼与价值推导

- Strategyzer, Value Proposition Canvas（见"客户价值与决策"）  
  借鉴机制：客户任务/痛点/收益与项目减痛/增益机制对应，是"客户路径提炼概念"的底层工具。
- 麦肯锡金字塔原理（Barbara Minto 公开方法论）  
  借鉴机制：问题树拆解 + MECE 去重 + 自下而上归并，用于从政策/经济/城市/板块/市场/客户六堆信息里收敛出≤3个核心判断。
- 特劳特定位理论（公开方法论）  
  借鉴机制：占据心智的一个词——找"没人占的位置"而非"最好的位置"，一词占领、全案排布。
- 公开报道案例（郑轨云麓、金茂樾满云川、建国门9号、宸园139、招商林屿缦岛等，URL 以当时检索为准）  
  借鉴机制：从地块物理属性（轨道/景观/规划约束）到精神隐喻的一步跃迁，均保留"降维回事实"的验证路径。

## 多语命名

- 公开项目名案例：梵悦·108、梵悦·万国府（梵文顶豪系）、印象巴黎、巴黎春天（法文）、利海·托斯卡纳、帕提欧公馆（意/西语）、蔚蓝东岸、K.SUMMIT嘉峯汇（英文）  
  借鉴机制：中文表意+外文表调性；外文只做调性完成，中文负责思想解释；主案名中文独立成立。
- 地名监管动态（武汉、南宁等城市建筑物命名规范公开报道）  
  借鉴机制：命名前查当地《建筑物命名管理办法》，禁止无真实血缘的洋名（如"碧桂园梵高的海"式争议）。

## 客群分层的文案体系

- 万科"让建筑赞美生命"（刚需社区感）、龙湖小户型"总价友好"（公开案例）  
  借鉴机制：刚需卖"确定性"——交付安全、得房率、总价可控、算得清的账。
- 汤臣一品、深圳湾1号（公开高端案例）  
  借鉴机制：顶豪卖"克制留白+稀缺+身份"，说得越少越高级，意象越具体越值钱。
- 宜家产品叙事、戴森参数翻译（公开广告案例）  
  借鉴机制：把产品/技术参数翻译成生活场景与人物动作，参数永远跟一个人绑定。

## 全周期营销与演示实现

- Byter, Marketing a New Build Development in London  
  https://byter.com/marketing-new-build-development-london-launch/

- Driven Properties, St. Regis Residences Launch Case  
  https://www.drivenproperties.com/case-study/70-of-units-sold-at-launch-of-st-regis

- hakimel/reveal.js, The HTML Presentation Framework  
  https://github.com/hakimel/reveal.js  
  借鉴机制：键盘、触摸、缩放、减弱动画和离线演示的实现参考；本Skill仍要求静态DOM和项目专属设计，不把框架默认主题当视觉方案。

## 使用纪律

- 来源提供的是方法启发，不是结论；
- 不引用无法核验的销售数据、奖项或“第一/唯一”；
- 不把阿那亚、良渚、绿城等现成概念嫁接到新项目；
- 案例的价值在于“怎样从证据走到判断”，不是其口号和命名。
