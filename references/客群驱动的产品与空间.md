# 客群驱动的产品与空间

## 1. 起点

产品不是概念的装饰，也不是行业组件清单。先确认谁会买、为什么买、能付多少、在哪些时刻感知价值，再决定面积段、房型、公区和服务。

产品是前策输出，不是用户必须预先提供的输入。没有户型时输出“产品战略+设计任务书”；已有户型时先验证其是否匹配上游市场、土地、客群和经营，不得围绕既有户型选择性找证据。

基本链条：

`市场/消费趋势与土地能力 → 消费阶层与家庭结构 → 关键事件 → 日常动作/设备 → 当前代价/否决 → 支付边界与竞品空位 → 决策分叉 → 证据生成的产品情境 → 产品任务 → 尺度/性能/机电接口 → 成本与工程 → 支付/去化 → 验证`

同时读取 `市场趋势判断与产品推导.md` 和 `消费阶层生活方式与设计接口.md`。

## 2. 先生成决策分叉，再比较产品情境

不得把行业常见面积段当候选菜单。先把会改变产品的证据写成决策分叉，例如“二手已承接低总价需求，但目标板块新增的是三代置换家庭”“低密土地可提高户均资源，但总价上限可能压缩客群”“目标客户高频在家工作，但竞品仍以卧室数量代替弹性”。

情境数量由分叉决定。每个有效分叉保留能被证据支持的分支；若某分支在客群规模、支付、工程或经营上不成立，作为“被排除反事实”记录原因，不为了凑数保留。情境可以围绕家庭确定性、弹性代际、低套数稀缺、总价效率、特殊生活方式或混合结构形成，但这些只能作为研究启发，不能预先写进结论。

每个情境比较：

- 来源分叉和核心因果假设；
- 客群规模与证据；
- 消费任务与第一否决点；
- 可承受总价；
- 面积段和套数；
- 销售周期；
- 单方售价与总货值；
- 建筑效率；
- 户型竞争力；
- 成本与精装投入；
- 风险和停止条件。
- 对土地低密、限高、景观、纯粹度和户均资源的利用率。
- 与最强竞品是跟随、升级、错位还是创造新参照，以及客户为何在意。

主稿最终只推荐一种主结构，可保留少量补充产品，不把情境比较变成无结论的菜单。

当容积率约3.0或更低，或相对板块显著低密时，重点判断土地能力应被分配给户均资源、公共生活、低层感、私密、弹性、总价效率还是其他客户结果。禁止因板块历史刚需多直接沿用70—90㎡，也禁止因低密自动判定豪宅；结论必须同时回答市场趋势、消费趋势、竞品差异、支付、货值、现金流和撤回条件。

## 3. 客群—空间任务书

每项建议至少包含九个字段：

1. 目标人物；
2. 发生时刻；
3. 可观察动作；
4. 当前代价或第一否决点；
5. 产品/空间/服务答案；
6. 面积、净宽、层高、收纳量、隔音、采光、设备或运营参数；
7. 成本、报建、结构、机电和物业边界；
8. 影响的支付理由、价差、去化或复访；
9. 验证方法与停止条件。

无参数的“高级、松弛、社交、归家、圈层”不算产品建议。

## 4. 分层反推

### 总图

回答楼栋关系、朝向、景观资源、噪声、消防、车行/人行、展示和分期如何服务主力客户及货值。没有总图不得发明环、轴、院、连廊。

### 建筑与立面

回答开窗、阳台、设备平台、遮阳、私密、层高、标准层效率、核心筒和立面成本。形式必须服务室内体验和价格分层。

### 户型

先写家庭或个人的一天，再写空间。至少检查：

- 入户与家政是否互扰；
- 公私、动静、主客是否分离；
- 卧室数量是否对应真实家庭结构；
- 客餐厨是否对应款待、陪伴或独处；
- 主卧套房是否对应工作、睡眠、收纳和照护；
- 可变空间是否真能转换，不靠软装想象；
- 面积效率和浪费是否可解释为支付价值。

户型任务书还要覆盖真实设备接口：扫拖机器人上下水与检修、洗烘和分洗、厨房空调与冷凝水、弱电/AP/网关、智能窗帘与安防、适老预埋、宠物清洁。具体字段见 `消费阶层生活方式与设计接口.md`。

### 房间

对客厅、餐厅、厨房、主卧、次卧、书房、衣帽、家政、卫浴、储藏逐项给任务和参数。核心房间应给平面关系、尺度区间、设备和使用动作。

### 公区

大堂、架空层、会所、电梯厅、车库、归家动线只在客群有高频任务时成立。写清每日/每周使用频率、同时人数、运营主体、开放时间、面积成本和维护费用。

### 园林

从使用者、时段、季节、活动、视线、噪声、遮阴、雨天、看护与维护出发，不从“几进、几园、四季”命名出发。

### 服务与运营

服务必须有人员、频率、标准、成本、预约方式和退出机制。一次性活动不能冒充长期服务。

## 5. 通用组件禁令

围合、连廊、天际会所、地下通道、下沉庭院、无边泳池等都不是默认答案。仅当同时满足以下条件才可进入主稿：

- 最新图纸或规划机制允许；
- 目标客群存在具体且高频的任务；
- 相比替代方案有明确收益；
- 成本、消防、报建、物业和维护可控；
- 能解释价格、去化或体验差异；
- 有验证和停止条件。

否则只能列为内部假设，不进入外部方案。

## 6. 概念映射

每个价值支柱至少落到：

- 一个产品结构决定；
- 一个户内或公区参数；
- 一个客户可感知动作；
- 一个价格或销售证明。

若概念不改变任何面积、尺度、配置、服务、展示或价格决定，它仍只是文案。
