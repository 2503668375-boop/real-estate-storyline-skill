# 价值提炼与推导 · 11.0
目标：发现项目值得怎样做、客户为何选择及愿意付出什么，再形成能统领产品、服务、销售和表达的主张。价值包含功能、关系、身份、审美与经营，但每一层都保留事实和机制。

## 1. 四种角色分开
| 角色 | 判断 | 用法 |
|---|---|---|
| 成交门槛 | 缺了就被否决，具备后未必加价 | 优先补齐与证明，不虚构溢价 |
| 选择优势 | 同总价比较时客户更倾向本案 | 进入带看、竞争比较和产品主张 |
| 溢价理由 | 在其它条件可比时仍愿多付或承担代价 | 需带价选择/行为等证据及边界 |
| 记忆表达 | 让上述判断易理解和识别 | 形成概念、名字、视觉与传播；不能替代支付证据 |

没有溢价证据，可以保留选择优势，不强迫每项优势货币化。宣传独特与产品独特分别检验；行业共有功能也可能通过可靠的组合和兑现形成优势。

## 2. 一张事实盘点，三条发现路径
盘点土地与空间、当地生活与文化、产品与工程、品牌兑现与服务、交易与经营五类。标明现状、限制、可改项、时间、成本、权利和来源。缺点必须如实保留。
- 土地路径：客户可使用到什么、受到什么限制？怎样组织才能带来不同结果？
- 客户路径：具体家庭/企业在什么触发事件下想改变什么，同时不愿牺牲什么？用真实行为或明确标记的推演回答。
- 竞争路径：最强替代怎样满足此任务、代价在哪里？低去化可能来自价格、供货、渠道或信誉，不能直接证明产品空白。

三路汇合的是可检验的机会假说；独属资源不必强行证明竞品失败，无竞品供给也不等于存在需求。

## 3. 八问深挖
事实是什么 → 谁有资格且能稳定使用 → 用什么机制改变结果 → 原方案付出什么代价 → 本案减少什么代价并增加什么成本 → 最强替代能否同样做到 → 什么证据表明客户愿选择/支付 → 项目是否有能力长期兑现。
每个箭头都能说明凭什么；断点写验证动作。不要从“有地铁”直接跳“时间自由”，中间需步行、雨天、换乘、拥挤与实际生活安排。

## 4. 价值取舍与组合
先区分必要底盘、差异机会、无效投入和潜在负担。把机会放在同一张表：受众规模、痛点频率/强度、竞争替代、可感知程度、支付/选择证据、兑现难度、增量成本、维护和复制速度。
可以使用有依据的评分辅助比较，不把主观分数伪装市场概率，不预设权重。优先选择在预算内能改变选择且可持续兑现的组合。
组合价值要解释协同：独立卧室、隔音、储物、弹性空间共同减少家庭互相打扰，组合可比单个配置更有意义；但不能将同一结果重复计作多项溢价。
主张数量由证据和任务决定。区分一项核心购买理由与支撑体系；大盘需要解释长期生活系统、兑现顺序与容量，不按面积强制凑三根支柱。

## 5. 双向提炼：从细节到项目观念，再回到细节
选择真实的升维轴：时间与秩序、家庭关系与边界、地方生活与文化、身体与自然、身份与自主选择、城市空间与公共生活。按资源真实性、客户处境和竞争意义选择，不为显得宏大硬贴国际范式。
依次写：客户生活会怎样改变 → 项目坚持的设计/服务原则 → 可识别的生活模式或观念 → 核心概念。
升维不能停在“安心/松弛/高级”，也不必每盘制造身份阶层。宏大尺度须有土地/城市与组织能力，克制的日常价值也能有审美高度。
高端项目可沿城市坐标、人物认同、建筑代表性和珍藏理由提炼，形成“世界湾区／峰层人物／时代封面／臻藏席位”等表达。身份、审美与收藏感可成为购买向往，是否形成选择优势或溢价仍分别验证；具体推导与写法见[传统高端地产叙事与价值转译](传统高端地产叙事与价值转译.md)。
再反推：这个观念会要求怎样的总图/户型/服务、舍弃什么、增加多少成本、销售怎样证明？反推不成立则改概念或方案。

## 6. 价值卡和六联单
每个入选价值记录：ID、主张、角色、目标客户、客户任务、证据ID、可用机制、竞争替代、客户代价、项目取舍、成本兑现、选择证据、溢价状态、表达方向、验证计划、失效条件。
六联单：客户任务 → 项目做法 → 产品/空间/服务接口 → 可验证证据 → 销售讲法 → 操盘动作。支撑关系同源，表述可按决策阶段变化。
设计意图、图纸合同、实景测试、客户行为、长期运营分清。未建成的不能借效果图写成使用效果已发生。

## 7. 反事实和市场检验
- 去掉项目名：对手若也能说，进一步比较兑现组合、成本和使用结果；不为强求唯一制造假差异。
- 删除某项投入：客户选择是否变化？若不变，可能是低优先投入。
- 总价提高/旧房卖慢/竞品降价：主张是否仍成立？何时退回选择优势而不主张溢价？
- 客户复述：记住什么、相信什么、怀疑什么、愿采取什么下一步？
- 销售演示：能否带客户完成验证，而非背广告词？
访谈只发现方向；支付溢价用含价格和替代品的取舍测试、真实选择或成交观察，交代样本限制。不存在真实样本就标未验证。

## 8. 示例：同预算家庭改善（合成教学场景）
事实假设：总价受限、三代同住、既有户型边界混乱；可改动隔音、储物及房间关系，无法增加面积。
机会A加豪华饰面，机会B重组家庭互不打扰的生活系统，机会C增加收费服务。比较使用频率、否决点、成本和长期负担后，B可作为待验证推荐。
功能结果：学习、照护、休息可并行；生活意义：共同生活仍保有个人边界；设计原则：重要关系有接近的空间，也有退出的余地。
可探索的观念是“有分寸的共居”，具体案名与文案另做。展示以真实家具、声音与动线演示验证；若客户主要矛盾是现金而非使用，先解决总价和交易，不能拿概念覆盖支付障碍。
以上不是实际客户访谈、已验证溢价或通用概念。
