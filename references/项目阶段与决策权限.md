# 项目阶段与决策权限
| 阶段 | 关键判断 | 动作与限制 |
|---|---|---|
| 拿地/投前 | 地价上限、需求、融资 | 不拿/延后/调整条件均可；全成本与股东回报并算 |
| 已拿地未定案 | 支付与土地能力 | 产品配置和分期比较，核对报批锁点 |
| 已定案未首开 | 竞争、首批货包与价格 | 不默认重做户型；列改动成本与时序 |
| 持销/滞销 | 哪些库存在哪步流失 | 价差、权益、展示、渠道、交易路径分批检验 |
| 现房/尾盘 | 房源障碍、解限与处置 | 和继续持有/可行改造比较，保留蓄客及复访 |
| 复工/盘活 | 权利、复工交付缺口 | 先核可售与资金闭环，不预设债权人同意 |
| 持有运营 | 租户经营、收缴与退出 | 免租/补贴/改造算全租约现金，招商率不替代实收 |

项目决策卡记录版本、项目、基准日、阶段、本轮任务、目标优先级、可改项、锁定项、现金约束、销售制度、证据缺口、需输出模块、责任人与权限。
未知不填0。分清项目可执行、需公司审批、需第三方落实；方案本身不增加外部行动权限。
地域适配看需求与交易机制：核心城市置换、外围大盘、县域、本地改善、跨城多居所、租户经营分别验证。豪宅按本城总价/单价分布及资产用途识别，不设全国单价门槛。
周会同口径看目标库存、流失、净签约、实收与可用现金、预算、工程兑现、待决策动作，记录批准人、范围和生效日。
