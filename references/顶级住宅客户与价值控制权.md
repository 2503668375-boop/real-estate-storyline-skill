# 顶级住宅客户与价值控制权

## 适用条件

项目被定义为顶级、超高端、城市标杆住宅，或目标售价进入本城市新房前5%价格带时强制使用。价格高只是触发器，不是“顶级”的证明。

## 一、先判断本次购买在资产组合中的角色

不得从“高净值家庭”直接跳到大户型、会所或酒店服务。逐项回答：

1. 买方是个人、夫妻共同决策、企业主家庭，还是家族办公室/专业顾问参与；
2. 这是唯一主宅、城市主宅、商务落脚、代际资产、收藏型物业，还是第二/第三居所；
3. 资金来自现金、企业分红、金融资产退出、旧房置换或组合融资；
4. 决策看一年生活效率、十年持有，还是跨代传承；
5. 谁负责筛选、尽调、签约、装修、入住、维护与未来处置；
6. 哪些风险一票否决：暴露、混杂客流、噪声、工程不确定、运营失控、服务费、流动性、品牌衰退。

输出 `购买角色卡`，不得只写年龄、职业和家庭结构。

## 二、建立不可替代资源账本

每项资源记录：

`资源事实｜数量/边界｜法律与规划确定性｜客户使用时刻｜最强竞品是否拥有｜未来能否复制｜转化成何种控制权｜对售价/去化/长期价值的作用`

资源可包括：不可新增的城市位置、永久或高确定性景观、历史与文化原真性、低单位数、独立到达、可定制的大尺度空间、稀缺运营牌照、可信品牌标准。把“江景、核心区、大师”列为资源但没有数量、边界和可复制性，视为无效。

## 三、顶级客户购买的七种控制权

1. **到达控制权**：车、人、访客、服务、物品与应急动线互不暴露；归家不经过公共展演。
2. **隐私控制权**：单位数、梯户关系、视线、声环境、数据、访客和员工权限可管理。
3. **空间控制权**：结构、机电、层高、面宽、承重、设备与装修允许长期定制和更新。
4. **时间控制权**：礼宾、维修、家政、代收、车辆、宴请和多居所管理真正减少业主协调时间。
5. **社交控制权**：既能体面款待，也能决定不被社交；私宴、艺术、商务与家庭流线有边界。
6. **服务控制权**：服务有SLA、权限、隐私、人员稳定、费用透明、替换和退出机制，不依赖一次性营销承诺。
7. **资产控制权**：产权、质量、长期维护、服务费、出租限制、品牌退出、转售客群和稀缺性可尽调。

产品价值必须至少由三类控制权共同构成，并说明放弃了什么。不得把七项全部堆成清单。

## 四、从控制权生成产品

每项进入设计任务书：

`控制权 → 关键人物/顾问 → 使用或尽调时刻 → 现有风险 → 空间/工程/运营机制 → 参数 → 成本 → 长期维护 → 支付证明 → 撤回信号`

顶级住宅重点检查：

- 单元数、核心筒、独立前室、门厅视线、车位到户与访客核验；
- 管家、住家服务人员、宴会、艺术品、贵重物品、宠物和大件物品的分流；
- 声学、空气、水、温湿、遮阳、备用电源、网络与数据隐私；
- 大尺度连续空间与未来再分隔，机电容量和检修不破坏主空间；
- 艺术品承重、照明、恒温恒湿、安防与进出路径；
- 多居所“锁门即走”、周期巡检、远程授权和到访前恢复；
- 服务团队权限、响应时限、人员背景审查、费用与替换机制。

## 五、溢价必须分解

不得用土地贵倒推售价。建立：

`可比市场基准 + 不可替代资源溢价 + 空间/工程确定性溢价 + 服务与品牌降风险溢价 + 稀缺供给溢价 - 运营/流动性/交付风险折价`

每一项写证据、幅度区间、最强反对理由和失效信号。品牌只在质量标准、运营持续、全球识别或转售流动性可验证时计入；Logo本身不计溢价。

## 六、概念必须完成“控制权跃迁”

普通改善概念常从家庭摩擦走向更好生活；顶级住宅要继续追问：

`买方已经拥有很多房子，为什么仍需要这一处 → 哪种稀缺资源让他取得别处没有的控制权 → 项目怎样让财富不必被展示、时间不必被协调、生活不必被公共规则打断 → 这改变了他与城市、家庭、资产或自我的什么关系`

核心概念不得停在“从容、圈层、传承、世界、峰层、定制、隐奢”。这些词只有绑定独有资源和可验证机制后才可出现。

## 七、反伪豪宅验收

任一命中即退回：

- 用更多房间、更多会所、更多品牌替代不可替代性；
- 公开社交和圈层活动削弱隐私，却被包装为尊贵；
- 酒店与住宅共用入口、设施或客流而未说明隔离；
- 只承诺服务项目，不写SLA、费用、权限、隐私和长期运营主体；
- 只写审美风格，不写空间与工程可定制性；
- 只谈保值，不写持有成本、品牌退出、出租限制、转售客群和风险折价；
- 案名靠生僻字、外语、宫殿/王室意象制造等级，没有在地事实。

## 八、底稿最小结构

`顶级住宅战略底稿.json` 必须包含：

- 项目级别与触发依据
- 购买角色卡
- 客户资产与决策结构
- 多居所/资产组合角色
- 一票否决
- 不可替代资源账本
- 推荐控制权
- 控制权到产品机制
- 服务治理
- 溢价分解
- 风险折价
- 反伪豪宅检查
- 控制权文学跃迁
- 撤回/降级信号

研究启发来自 Knight Frank、Savills、Sotheby's 等2025—2026全球高端住宅/品牌住宅研究：国际连接、资本安全、隐私、专属设施、服务一致性、多居所管理与投资逻辑重要；花哨设施、共享酒店客流和不透明服务费会削弱价值。上述结论只能作为研究入口，必须用项目所在城市、竞品成交和真实客户/顾问样本校准。
