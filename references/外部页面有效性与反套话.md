# 外部页面有效性与反套话

## 一页的准入线

每页先回答一个可执行的问题：听众看完后，谁要在何时对哪个对象做什么，依据是什么。答不出，合并或删除。

外部页只采用以下类型，并在HTML中记录对应的隐藏字段：

| 类型 | 客户看见的内容 | 必须留痕 |
|---|---|---|
| 证据页 | 指标、时间、样本、图表或项目事实 | 来源、证据编号、指标 |
| 决策页 | 已选方案、放弃项、触发阈值 | 决定、负责人、日期 |
| 产品证明页 | 户型/总图/材料/动线与可核对尺寸 | 图纸或照片编号、证据编号 |
| 客户原声页 | 原话、访谈片段或行为样本 | 样本来源、日期、原话 |
| 运营动作页 | 对象、动作、责任人、完成时间、验收物 | 动作、负责人、日期、交付物 |
| 概念页 | 项目独有场景与产品做法 | 上游事实、场景或空间证据 |
| 附录 | 来源、口径、缺口、敏感性、备选 | 附录编号 |

## 直接删除的页面

- 标题说“风险、纪律、锚点、节奏、原则、方法”，正文只列几个词；
- 用01—05流程图代替真实客户路径、样板路线或销售动作；
- A/B/C批次只写角色分工，未写房号范围、价格、成交样本、负责人和释放日期；
- 四种价格只做名词解释，未展示每套的价格表、权益折算、审批人和生效时间；
- “必须、先、不得、真正、看不见、建立、回到”构成标题主干，却没有项目对象和可核验证据；
- 卡片只换了标题，删掉项目名仍可用于任何楼盘。

## 改写原则

把抽象判断压回对象和动作。比如价格页直接放“3单元 3-02-1802：表价、付款折算、渠道费、车位权益、签约净价、审批单号”；样板页直接放“车行入口至入户门的实拍节点、每段时长、噪声读数、遮挡点与整改责任人”。

数据不足时，外部交付降为研究诊断或附录材料。不得用流程、口号或推测补足页面数量。
