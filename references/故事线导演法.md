# 故事线导演法

## 内部工作与外部故事

本文件中的三重审查、原始方向、四强决选、修复卡、删除测试等均是内部生产字段。外部提案不得照搬字段名、审查状态或比赛过程。

外部只呈现一条连续推导：

`外部趋势 → 城市板块与土地 → 消费阶层/人物代价 → 竞争旧答案 → 产品战略比较 → 产品/空间任务 → 经营价格 → 项目定位 → 核心概念 → 推广案名 → 分众传播 → 首开行动`

听众应看见概念为什么必然出现，而不是策划团队如何做创意管理。

## 一条完整故事线的骨架

`趋势与土地的真实矛盾 → 消费阶层想完成的生活进步 → 竞争旧答案 → 产品机会与三种结构比较 → 唯一产品/空间任务 → 货值价格校验 → 项目市场角色 → 核心概念 → 案名与分众翻译 → 可运营价值IP → 成交证据`

进入本阶段前，市场趋势、消费行为、产品战略、设计任务和经营价格必须先成立。随后主概念通过创意总监、地产经营负责人和苛刻甲方三重隔离审查。故事线导演负责组织已成立的前策结论，不负责用概念反向规定产品。

顺序不能倒置。概念和案名是产品经营选择的压缩与识别，不是产品的上游依据。

## 用薯田埔方法理解“精神”

好的精神把已经成立的前策取舍翻译成共同相信的活法。名言只能解释价值，不能迫使空间或产品配合创意。例如：

- 土地从农田、工厂到智造城；
- 项目有高容、轨道、连廊、河岸等真实规划机制；
- 人群处于扎根、建立附近、下一代成长的处境；
- 先由行为、工程和经营比较形成空间系统；
- 再把这一选择集中为自由/社区/成长等精神。

关键不在复用“美式”“生长”或任何视觉风格，而在每个项目都完成自己的事实—精神—空间转译。

## 内部页面价值判定

一页有效，当且仅当至少完成一件事：新增事实、揭示矛盾、提出选择、命名空间结构、落位IP/场景、解释价差或让客户完成一个判断。

以下通常无效：

- 把“目标客群/核心信息/线上/线下/预算/负责人”拆成单页；
- 只用名言或形容词营造气氛；

当用户或标杆要求精神引文时，每条必须完整记录：原文、作者、原文出处、核验日期、项目组译、它打开的价值判断、它改变的空间或产品决定。没有后两项就是装饰性引文，删除。
- 无落位、无频率、无动作的生活方式清单；
- 没有空间依据的“景观/圈层/品质”溢价。

## 内部结构化底稿最低字段

- 土地事实：事实、来源、时间、影响；
- 人物处境卡：人群、生活冲突、精神渴望、拒绝什么、对空间的要求；
- 原始方向：方向、事实支点、人物共鸣、空间后果；
- 四强决选：名称、反命题、空间原型候选、决选/排除理由、六角色对抗后的修复；
- 空间组件：名称、位置、连接、日常使用、溢价机制；
- IP场景：名称、位置、使用者、频率、动作、客户价值、项目价值；
- 标题链：标题（即核心判断）、页面任务、新增内容、视觉证据、决策后果、删除测试；
- 价值兑现：产品、价格、营销分别写母题/原型、动作与证据。
- 价值推导：16项推导责任、章节情绪卡、场景单元、意象系统、3—5个价值支柱、证据级别、支付理由与经营后果；
- 人文传播：当代矛盾、项目立场、生活实践、四类受众翻译、内容五章与验证计划；
- 文学主线：情绪母线、8个以上逻辑文学节点、概念集中、国内表达审校与可选多语命名；

任何字段若只写“A/B/C”“高级/松弛/自然”“待核实”或重复项目名称，不算完成。

空间原型必须标注最新总图或规划机制依据。只有历史媒体效果图、生成式图片或文字想象时，不得把其写成已确定产品；对外只能以“设计任务书/待规划验证”呈现。优先读取 `客群驱动的产品与空间.md`，从人物任务反推空间，禁止默认复用围合、连廊、天际会所、地下通道等组件。

行文约定：底稿字段名保持不变，提案行文用国内策划惯用语——“删除测试”行文称“合并测试”（如果与邻页合并后不损害论证，就不该硬留一页）；“溢价机制”行文称“溢价逻辑”，即这一组件凭什么贵、贵在哪一处空间；“价值兑现”区块的内容在提案里讲“价值落地”。

## 标题链自测

听者读完标题，应该能复述：

1. 这块地有什么不能被别处替换的矛盾；
2. 谁在这里想完成怎样的生活进步；
3. 竞争中的旧答案为什么不够；
4. 项目牺牲什么、选择怎样的价值立场；
5. 每个价值支柱由什么机制与证据证明；
6. 人文概念如何被不同受众理解、转述和参与；
7. 这个立场被画成了哪种空间；
8. 人每天在哪里、怎样使用它；
9. 因此为什么它值得被选择与支付。
