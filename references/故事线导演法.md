# 故事线导演法 · 11.3
用于完整项目故事线、价值提案与主题延展；专项只承担所需责任。采用《项目特征与创意生长》的连续推导，不机械复用前策章节。
完整提案先按[完整提案的推导与展开](完整提案的推导与展开.md)形成关键论证单元，再编排汇报。研究、客户与产品均须有实质内容，不能从章节标题直接跳到主题。

## 五层分工
| 层次 | 任务 |
|---|---|
| 项目定位 | 为谁、在哪个竞争范围、凭什么被选、舍弃什么 |
| 核心购买理由 | 客户为什么选择本案，主卖点和支撑体系分别是什么 |
| 故事线主题 | 用一个有记忆的认知或向往统领项目，可用概念名或完整句子 |
| 章节主线 | 让听众逐步理解、相信并形成选择；各章有新增判断和证明 |
| 阶段传播 | 根据当前客群、库存与顾虑选证据和动作，承接总主题 |
案名和产品命名按需附在对应层，不与主题混用。不强制每个项目增加精神内核等抽象层。

## 三种顺序分开
研究从目标、市场与特征开始，可以通过证据回退。汇报通常先给推荐和关键前提，再证明。面向客户的传播从其关心的购买入口进入。
前策可比较产品方案，已定案项目则在锁定边界内选择价值、展示和营销；现房尾盘围绕实际房源，不重做一套与库存无关的城市史诗。不能用固定上游顺序禁止有效迭代。

## 组织一条连续主线
内部先用平实中文串起：市场机会是什么，本案最强条件是什么，谁重视它，怎样形成购买理由，推荐何种主题，分别用哪些产品和经营证据证明，下一步如何执行。
再安排章节。每章记录要建立的判断、相应特征/价值与证据、图文承担的任务、如何接下一章。章节长短和顺序随听众与信息变化，不凑固定节点。
典型推进可为“机会判断—项目选择—价值证明—主题集中—营销落实”；有强建筑作品的项目可先展示作品与主题再展开证明。主题不必逐页重复，后文要不断增加可信依据。
检验章节的依赖关系：上一章证明了什么，因此本章必须决定什么，本章又给后章增加什么条件。若城市、园林、户型、服务交换顺序后完全不影响理解，可能仍是卖点并列；可保留为价值说明，但核心故事需补足项目选择和逐步建立认同的过程。诗性段落不必逐段做因果推理，整篇战略依据必须能回查。
人物精神不能只列“高净值、成功人士、追求品质”。由真实财富来源、城市经历、家庭阶段和生活选择形成认同，再通过空间与服务表达。高端语气可以昂扬，不能把客户写成统一的人格或已完成事业的人。

## 内容延展
主卖点分别翻译为：对内决策解释、对客理解、产品演示、媒体故事、案场讲述及阶段动作。说明每种形式多证明了什么，避免同一句口号换平台。
长期项目区分稳定主张与阶段重点，阶段主题围绕新的客户顾虑或房源任务变化。营销排期优先用共享横向时间轴、纵向业务分线，并保留策略内容。

## 完整故事线交付
按《11版数据契约与验收》的11.3条款交付故事线底稿、可读稿和论证展开审阅。至少能找到市场机会、特征取舍、主次卖点、主题推荐及理由、章节链、证明与传播延展。
正文写具体判断，不照搬内部字段、评分和审查角色。只有题目清单、卖点罗列、漂亮口号或空壳图解时继续完成内容，不报完整交付。
主题、宣言、关键故事与传播样稿需实际写成；“后续制作一支视频/举行一次发布会”仅是执行意向。按任务提供关键场景、表达内容和证明动作，不能将待创作清单当完整故事线。

## 冷读验收
只读标题能否复述推荐和理由？章节是否在推进同一主题而各有新内容？最强短板有没有交代？重点图是否帮助理解？换项目后整套内容是否几乎不变？
合格结构只证明逻辑可检查。语言、图像、页面和客户效果分别验收，未完成的部分如实说明。
