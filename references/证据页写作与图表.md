# 证据页写作与图表

## 一页完整证据的构成

标题给出判断，正文把判断讲透。每张市场、竞争、价格、经营或客户证据页必须包含：

1. **事实**：指标、对象、地域、统计期、样本或口径；
2. **比较**：同比、环比、竞品、历史区间、预算线或目标线中的至少一个；
3. **图表/表格**：用来承载比较，不把数字排成装饰卡片；
4. **解释**：两到三句说明变化来自什么、限制在哪里；
5. **项目后果**：明确改变哪项产品、价格、供货、案场或营销决定；
6. **来源脚注**：机构/文件、发布日期、抓取日期和口径。

## 图表怎么选

| 要回答的问题 | 图表 |
|---|---|
| 趋势是否反转、速度如何 | 月度/季度折线图，标出政策或供货节点 |
| 本项目在哪个价格带 | 散点图或价格带分布图，标出本案、竞品和成交样本 |
| 供应、去化、库存的关系 | 柱线组合图或瀑布图 |
| 单套价格为何不同 | 房号级价格拆解表：表价、折算权益、渠道、车位、签约净价 |
| 客户为什么犹豫 | 访谈原话表：样本身份、触发事件、原话、对应产品/销售动作 |
| 样板、动线或产品是否成立 | 平面图/实拍序列，标尺寸、时长、噪声/视线/遮挡点和整改责任 |

每张图只回答一个问题。没有可比较的数据时，写成研究诊断或附录，不伪造趋势图。

## 卡片的边界

数字卡片可以用来提炼图表结论，最多占页面三分之一；卡片下面必须有图、表、原话、图纸或实拍材料。机构名称不能替代来源说明，结论句不能替代解释。

价格和经营页尤其要落到对象：楼栋、单元、房号或货包；对应的价格口径、权益折算、成交样本、审批人与生效日期。任何“价格锚”“有效成交价”“分批释放”都要放回这张明细表里解释。
