# 价值叙事与文学表达

## 目的

文学表达让听众在同一条因果上同时完成理解、想象和情绪变化。完整方案始终运行两条相互校验的轨道：

- **证明轨**：事实 → 机制 → 人物代价 → 产品选择 → 可感知结果 → 支付与经营 → 定位与概念；
- **体验轨**：看见一个人 → 进入一个时刻 → 感到摩擦 → 意识到旧答案失效 → 看见新的生活动作 → 产生期待与认同。

体验轨不能越过证明轨，证明轨也不能只剩没有人的数据。去掉文学句，因果仍须成立；去掉图表，人物处境仍须具体。

定位收束到核心概念时，加读 `概念文学跃迁与终审.md`。文学表达是概念生成的必经中轴：先把事实转成人物经验，再把人物经验压缩为新判断。若外部稿只有分析结论和最终金句，中间没有人物动作、摩擦、项目取舍、改变后的动作与意义上升，视为推导断裂。

## 刚需项目的文学尊严

刚需、首置、首改项目不使用“豪宅语言降配版”。感染力来自被准确看见，而不是被许诺身份跃迁：

- 写硬约束中的清醒选择，不写“终于上岸、从此逆袭”；
- 写客户已拥有的判断力，不把客户塑造成等待项目教育的人；
- 写日常中值得守住的关系、秩序与自由，不用贫乏叙事换廉价煽情；
- 写项目真正付出的代价，不用“懂你、宠你、不辜负”代替机制；
- 允许生活有压力，但不把焦虑变成逼单工具。

格调公式为：

`洞察精度 × 道德姿态 × 表达克制 × 地方质感 × 证明密度`

任何一项接近零，罕见词、外语、诗句和大画面都不能补救。

建立一张 `表达调性表`：只选一个主温度、一种叙述姿态和一种主节奏；列出允许词、禁用词、事实意象源、声音边界。概念、30秒复述、销售话术、视频旁白、活动主持和案场文字必须保持同一调性。

同一思想形成三种长度，而非三套逻辑：

- **5秒**：一个能被客户准确回述的新判断；
- **30秒**：人物两难—项目选择—客户变化；
- **长文**：用事实、动作、细节、关系和回环把同一判断展开。

## 场景单元

重要价值至少写一个场景单元：

`人物身份与关系｜具体时刻｜正在做的动作｜一个可见物件或感官细节｜受到的阻碍｜付出的时间/关系/安全/尊严代价｜项目机制｜动作如何改变｜客户何时亲手验证`

“更松弛、更高级、更有温度”不是场景。合格场景要让人看到门在哪里、手在做什么、谁在等谁、为什么此刻难受，以及空间怎样改变下一步。

场景优先写“过程”而非只写结果：写下班回家、放下什么、谁先看见谁、家务如何消失、一次谈话如何重新发生。结果由过程自然显现。

## 情绪曲线

每一章先确定一个情绪任务，整案形成变化而非同调：

`察觉变化 → 不安/疑问 → 认出自己 → 说破代价 → 对旧答案失望 → 看见选择 → 亲手验证 → 形成确信 → 愿意行动 → 产生归属`

这不是固定十段模板。项目应根据人物和主题重写情绪词，但必须出现转折、缓急和回落；不能70页都“宏大”，也不能每页都“治愈”。

章节情绪卡记录：

- 入章时听众相信什么、感受什么；
- 本章要制造的张力或认知冲突；
- 哪个事实或场景构成转折；
- 离章时听众应产生何种新感受；
- 下一章承接的未解问题。

## 意象系统

从土地前史、气候、光影、材料、产业动作、家庭动作或空间结构中选择1个主意象、2—4个辅助意象。主意象须随叙事改变含义：

`第一次出现：事实或环境 → 第二次：人物处境 → 第三次：产品机制 → 最后：概念与行动`

意象不能从奢侈品牌、诗词库或“高级词库”借来。若意象无法回到项目事实或产品动作，删除。

## 七种表达动作

按页面责任择一使用，不必每页都用：

1. **微场景**：用一个动作代替一组空泛人群标签；
2. **对照蒙太奇**：把旧生活和新动作并置，让差异被看见；
3. **物件特写**：鞋、书包、轮椅、机器人基站、餐桌或一束光，必须连接真实机制；
4. **内心问题**：提出客户正在权衡、却很少被行业说出的疑问；
5. **留白与克制**：在损失、风险、价格和承诺前少说，让事实承担重量；
6. **长句推进**：只在矛盾集中或概念跃迁时使用，通过连续动作形成节奏；
7. **回环照应**：结尾返回开篇人物或意象，但此时动作已经改变。

## 文学密度

- 市场、政策、成本、利润、排期：0—1个表达动作，准确优先；
- 客户、土地矛盾、产品转场：1—2个表达动作，判断与场景并重；
- 价值集中、概念长文、核心场景、结尾：2—3个表达动作，可提高节奏和意象密度；
- 同一页最多一个主比喻；连续三页句式或情绪相同必须改写。

文学密度不是字数。短句、停顿、数据后的沉默，也可以比堆叠辞藻更有感染力。

## 标题与转场

主标题必须同时拥有“判断”和“人物后果”。建议结构：

- `事实发生了什么，因此人物失去了什么`
- `旧答案解决了什么，却留下了什么`
- `项目选择做什么，让哪个动作重新发生`

章末转场写三句：

1. 已经证明的判断；
2. 人物此刻仍未解决的疑问；
3. 下一章必须给出的答案。

不能用“时代迭新、美好进阶、重塑想象、臻境归心”等可换项目套话代替推进。

## 价值层级

每项核心价值从下向上推导，但不机械重复三遍：

1. **功能结果**：动作更快、更安全、更安静、更易维护；
2. **关系结果**：谁与谁因此减少冲突、增加陪伴或保留边界；
3. **身份与意义**：客户因此成为怎样的人、守住怎样的生活选择。

身份价值必须由功能和关系结果托住。若空间动作没有改变，不能直接跳到“精神共同体”。

## 完整价值章节责任

完整提案通常用12—18个有效页面完成以下认知责任，可合并但不能省略因果：

1. 外部变化进入人物生活；
2. 本地市场的分化和旧参照；
3. 一个核心人物的具体一天；
4. 当前生活真正付出的代价；
5. 竞品为何只能回答一半；
6. 土地能力与人物需求在哪里相遇；
7. 产品决策分叉如何生成；
8. 推荐产品选择放大什么、放弃什么；
9. 项目机制怎样改变动作；
10. 改变后的同一天；
11. 功能—关系—身份价值如何上升；
12. 最强反事实与不适用边界；
13. 项目在市场中承担的角色；
14. 价值支柱如何共同完成同一个改变；
15. 最后一跳到核心概念；
16. 概念长文、销售复述与客户行动。

页面数量随项目复杂度调整；不得用同一张“价值金字塔”替代这些责任。

## 文学质检

完成后依次执行：

1. **标题链朗读**：只读标题，是否既能复述因果又能感到情绪变化；
2. **去修辞测试**：删除比喻与形容词，事实、机制和决定是否仍成立；
3. **场景测试**：人物是否有时刻、动作、物件、阻碍与改变；
4. **情绪波形测试**：是否有张力、转折、克制与回响，而非句句同调；
5. **意象溯源测试**：每个主意象能否回到土地、人物或产品事实；
6. **套话迁移测试**：换给两个竞品是否仍成立；成立则重写；
7. **声音一致测试**：数据页克制、人物页可感、概念页集中，像同一作者而非拼贴；
8. **承诺边界测试**：文学是否把规划、意图或待验证项写成已兑现事实。
9. **尊严测试**：是否怜悯、教育、炫耀或羞辱预算有限的客户；
10. **口语回述测试**：客户能否用自己的话说出，而不是只能由策略师解释；
11. **证明密度测试**：每句核心文学表达能否至少回到一项项目机制；
12. **调性统一测试**：是否同时温暖、反叛、奢华、治愈，导致表达失焦。
