# 整合营销战役与创意动作

## 起点

营销动作不得从“做小红书、拍视频、办圈层活动”出发。先建立：

`市场阶段与库存问题 → 本阶段主题 → 目标人物与决策阶段 → 当前客户顾虑 → 必须被看见/亲手验证的证据 → 渠道分工 → 线上线下动作 → 私域与销售承接 → 转化/复盘`

主题决定营销围绕什么长期积累，客户决定谁在何时需要什么证据，市场和库存决定资源优先级。平台、活动和圈层只是任务分配后的载体。

## 一次战役的完整结构

每个关键阶段建立一张阶段营销总表：

- **战役命题**：继承核心概念，但必须对应当期经营问题；
- **目标库存/产品**：具体楼栋、面积、总价或招商单元；
- **核心人物与决策组**：购买者、共同决策者、影响者、阻挡者；
- **客户顾虑**：此刻为何不搜、不留资、不到访、不复访或不签约；
- **主证据**：参数、实景、工程、客户行为、价格结构或服务制度；
- **核心动作**：让客户最集中地验证承诺的核心事件/内容；
- **内容连载**：为核心动作预热、解释、追踪和沉淀；
- **线下验证**：让客户从“听说”走到“亲手确认”；
- **圈层路径**：通过何种可信关系进入目标人群；
- **私域养成**：标签、内容节奏、顾问动作和下一次邀请；
- **成交请求**：何时提出预约、复访、冻资、认筹、签约或转介绍；
- **数据与切换**：领先指标、成交指标、停止/加码/改向信号。

核心动作必须改变客户判断或产生可复用证据；只有热闹、照片和到场人数的不成立。

## 渠道的职责边界

根据目标客户真实使用习惯选择，不要求全上：

| 渠道/触点 | 可承担的职责 | 不应独自承担 |
|---|---|---|
| 官方账号/官网/公众号 | 权威事实、长期档案、政策工程与品牌承诺 | 单独完成破圈 |
| 搜索与地图/LBS | 承接主动需求、竞品比较、到访路径 | 制造深层情感认同 |
| 小红书/KOS/KOC | 生活问题、场景验证、搜索占位、真实经验 | 无证据的硬广和伪素人 |
| 抖音/视频号/直播 | 高频解释、现场带看、即时答疑、行动入口 | 用观看量代替有效线索 |
| 垂直媒体/本地媒体/PR | 市场解释、专业背书、公共议题 | 代替销售跟进 |
| 私域/企业微信/社群 | 分层养成、家庭决策、复访和节点提醒 | 无标签群发 |
| 案场/样板/工地/实景 | 产品验证、共同决策、价格比较 | 只承担拍照打卡 |
| 渠道/经纪/合作机构 | 精准触达、信任转移、快速组织 | 掩盖产品与价格问题 |
| 已购客户/业主 | 真实证言、转介绍、共同建设 | 编造口碑或强迫转发 |

每个渠道写清“接住哪一个客户决策阶段、交付什么证据、把客户送往哪一步”。若两个渠道职责完全相同，合并预算。

## 线上—线下—线上闭环

默认形成：

`议题内容/客户场景 → 搜索与短视频解释 → 直播或私信答疑 → 有效留资与标签 → 个性化预约 → 线下亲手验证 → 家庭/组织共同决策 → 顾问48小时内证据回传 → 复访/房源匹配 → 成交 → 业主共创内容与转介绍`

具体时限按项目客群和组织能力设定，不机械套用48小时。必须建立：

- 线索最少字段：来源、人物类型、预算、面积/业态偏好、决策阶段、共同决策者、第一否决点、下次动作；
- 销售响应SLA；
- 内容与销售共用的问题标签；
- 到访后的个性化证据包；
- 未成交原因回流产品、价格、内容和渠道的机制。

## 圈层营销

圈层不是“高端人群”标签，也不是饭局名单。先验证目标客户是否存在真实关系网络，再确定：

`圈层任务｜关系载体｜信任来源｜共同议题｜进入方式｜客户获得什么｜项目可验证什么｜隐私/合规｜销售承接｜长期关系`

关系载体可以是雇主、园区、校友、专业协会、银行/财富顾问、医疗教育机构、设计师、运动俱乐部、文化机构、宠物/亲子/银发服务组织或既有业主，但只能选择与目标消费阶层行为证据相符的路径。

圈层创意应围绕共同任务：

- 家庭如何重新分配时间与照护；
- 专业人士如何兼顾工作、恢复与社交；
- 三代家庭如何保留陪伴和边界；
- 真实设备、收纳、健康或适老问题如何被解决；
- 资产与居住选择如何在不确定市场中建立确定性。

禁止把红酒、豪车、名表、明星、名医、艺术展当万能高端符号。若参与者无法亲手验证项目承诺，或活动结束没有下一步关系动作，否决。

## 创意动作的五条资格

一个动作至少满足三条，核心动作须全部满足：

1. 只属于本项目的事实或机制；
2. 让目标人物完成一个有意义的动作；
3. 解决当前明确的客户顾虑；
4. 产生可复用的内容、客户洞察或成交证据；
5. 能被销售和私域承接为下一步。

创意来源顺序：

`客户矛盾 → 项目机制 → 可验证动作 → 戏剧结构/媒介形式 → 名称`

不要从活动名称或网红形式倒推内容。

## 营销动作单

每个动作记录：

- 动作名称与一句创意命题；
- 来源洞察、对应主题与目标库存；
- 主受众、共同决策者、客户决策阶段和客户顾虑；
- 要验证的项目承诺与证据级别；
- 客户亲手完成的动作；
- 线上预热、内容脚本与搜索关键词；
- 线下体验流程、空间/物料/人员；
- 圈层关系载体与合作方；
- 留资字段、私域标签、销售话术和下一步；
- 执行步骤、日期、场地、负责人、协同方和响应SLA；
- 预算上限、核心KPI、业绩认定方式；
- 风险、隐私与广告合规、天气/系统/舆情预案；
- 停止、加码、改向信号；
- 复盘结论与可再利用内容资产。

营销动作单只是地图，不是执行稿。每个阶段至少3个动作，但必须至少选1个核心动作形成 `重点动作执行方案`；产品证明期、家庭决策期、首开当周和持销期至少各有2个重点动作执行方案。其余动作可用简版动作单，避免所有动作平均用力。

## 重点动作执行方案：禁止只交几个字

每个重点动作执行方案必须让不参与策略会的人也能照单执行，至少包含：

1. **任务定义**：经营目标、目标库存、主受众/共同决策者、客户决策阶段、客户顾虑、本阶段要讲透的价值、主证据；
2. **动作设计**：客户亲手完成什么、为什么只有本项目能做、现场转折、产生什么可复用证据；
3. **预热内容表**：至少3条内容资产，每条写渠道、发布时间、标题/钩子、核心证据、脚本段落、CTA、负责人、完成标准；
4. **现场流程表**：至少6个步骤，每步写开始/结束时间、空间、客户动作、工作人员动作、物料、交付物、验收标准；
5. **人员RACI**：总负责人、执行负责人、销售、内容、设计、产品/工程、合作方；谁负责、谁审批、咨询谁、通知谁；
6. **物料清单**：名称、规格、数量、到位时间、责任人、替代方案；
7. **线索与数据**：采集字段、授权方式、标签、来源码、首触/关键触点/成交触点记录；
8. **销售承接**：响应SLA、首句、需要回传的个性化证据包、下一步请求、未响应升级路径；
9. **预算拆分**：场地、搭建、内容、媒体、人员、合作、技术、保险/安保、机动费；写金额或可计算公式，不能只写“按阶段审批”；
10. **KPI表**：基线、目标值、统计周期、数据源、责任人；曝光只作领先指标，至少含一个客户决策阶段转化指标；
11. **应急触发**：天气、系统、客诉、舆情、安全、嘉宾/供应商缺席的触发阈值、替代动作与决策人；
12. **会后72小时**：客户分层、证据回传、复访请求、内容二次分发、销售反馈、未成交原因和产品/价格/内容纠偏；
13. **复用资产**：视频、问答、客户原话、工程证据、搜索词、销售工具怎样进入下一阶段；
14. **加码/停止/改向**：达到什么数值继续，连续多长时间低于什么阈值停止或改向。

### 执行步骤最低结构

每个步骤都要有：

`序号｜起止时间｜负责人｜客户动作｜工作人员动作｜交付物｜完成标准｜异常处理`

“线上预热—线下活动—私域跟进”只有三个阶段名，不算步骤。

### 内容资产最低结构

每条内容都要有：

`渠道｜发布时间｜目标人物与状态｜标题/开头钩子｜证据｜脚本或图文结构｜行动入口｜负责人｜审核人｜完成标准｜追踪码`

“发小红书、做直播、公众号推文”只有媒介名，不算内容策略。

### 预算与KPI纪律

- 预算必须可相加，金额未知时写计算公式、报价责任人与锁价日期；
- KPI必须有数值、分母、周期和数据源；“提升曝光、促进转化”无效；
- 第一次执行没有基线时，写测试样本、观察窗和第一次复盘如何建立基线；
- 不得复制行业案例的曝光、到访、成交数据作为本案目标。

## 分阶段铺排

十二项全周期责任仍须覆盖，但资源不平均分配：

- **产品验证期**：访谈、户型/业态盲测、设备共研、价格敏感；结果能改产品；
- **价值定调期**：市场议题、事实档案、主题首章；建立权威解释与搜索底盘；
- **客群识别期**：人物内容、关系网络、KOS/KOC测试、私域标签；识别真正的目标客户；
- **产品证明期**：发布、样板、工程、直播、第三方与场景连载；集中回答“凭什么”；
- **家庭/组织决策期**：共同决策专场、一对一证据包、付款和风险解释；
- **承诺转化期**：房源/单元匹配、规则、登记、冻资/意向、每日漏斗；
- **首开/发布当周**：现场运行、直播、媒体、签约、舆情与应急；
- **后首周/首月**：真实成交证据、未成交抢救、库存和内容重排；
- **持销期**：按具体库存和否决点组织“一席一理由”月度战役；
- **尾盘/现房期**：实景、交付标准、一房一策和定向关系路径；
- **交付/运营期**：问题闭环、业主共创、真实入住、转介绍和品牌资产。

每个阶段至少有线上触达、线下验证、私域/销售承接三类责任；若某类确实不适用，必须写替代路径。

## 指标与归因

指标按客户决策阶段分层：

- 内容：有效观看、搜索进入、收藏/咨询主题、内容完播与问题分布；
- 线索：有效线索率、预算/面积匹配率、响应时长、预约率；
- 体验：到访、共同决策者到访、重点证据感知、复访；
- 承诺：登记、冻资/意向、认筹、房源重叠、弃筹原因；
- 成交：成交、签约、回款、获客成本、渠道归因、库存结构；
- 长期：交付满意、问题关闭、真实内容、转介绍与品牌搜索。

曝光和到场只能作为领先指标，不能冒充成交贡献。归因至少保留首触、关键触点和成交触点，避免把全部功劳给最后一个渠道。

## 外部提案责任

营销部分通常需要18—28页主稿，另附执行手册；项目简单时可合并，但必须让管理层看见：

1. 主题如何继承前策和概念；
2. 市场阶段、客户决策阶段和库存问题；
3. 全周期总图与预算优先级；
4. 关键阶段营销总表；
5. 线上内容与搜索/直播/私域铺排；
6. 线下案场、城市触点与体验铺排；
7. 圈层关系路径和合作机制；
8. 销售承接、SLA与家庭决策；
9. 漏斗、归因、KPI和切换；
10. 持销、尾盘、交付和业主共创；
11. 组织、排期、风险与应急。

不能用“一页媒介矩阵+一页活动排期+一页圈层清单”冒充完整营销方案。

外部主稿展示全周期逻辑、关键阶段和资源取舍；执行手册必须展开重点动作执行方案。若交付物只有活动名、主题短句和一段说明，营销部分直接退回，不以页数或视觉完成度补救。
