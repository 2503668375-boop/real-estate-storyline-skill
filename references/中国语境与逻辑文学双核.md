# 中国语境与逻辑文学双核

## 使用顺序

在研究事实基本成立后、页面编排前执行本规则；成稿后再逐页复核。中国语境、逻辑、文学和页面有效性任一项不通过，都不得用视觉包装补救。

## 一、中国语境

中国语境要求判断符合国内城市、房地产经营、家庭资产和汇报决策的真实机制，避开四字词堆砌、地产黑话与宏大口号。

### 必须做到

- 政策、市场、客户和价格判断写明城市或板块、时间、对象与适用边界；全国新闻不能直接替代本地证据。
- 区分 `已核验事实`、`项目组判断`、`前策估算`、`策略建议`、`创意命名`，不得把后四者伪装成事实。
- 客户从家庭结构、现居与持有资产、置换链、首付或全款能力、通勤教育照护、触发事件和第一否决点来写，不写悬空的“高净值精英”。
- 使用国内策划与经营常用语，但保持普通决策者能听懂。提案用“溢价逻辑、价值落地、合并测试”；底稿字段仍保持统一契约。
- 涉及学区、落户、限购、限售、贷款、税费、预售、交付标准等易变事项，必须核验日期与当地口径。

### 必须退回

- 翻译腔或欧化空句，如“基于……之上”“去进行……”“对于……而言，我们相信……”“作为一个项目，它将……”；改成明确主体和动作。
- 港台或境外语义未经转换就进入内地项目，如用“呎价、会所住客、样品屋”等替代当地惯用口径。
- 把“改善、豪宅、高知、圈层、松弛、高级、国际化”当作客户证据或战略结论。
- 把政府规划愿景、媒体报道或竞品宣传语直接写成项目已兑现能力。
- 只讲审美趣味，不回答总价、产品、交付、物业、通勤、教育、家庭决策或经营约束。

## 二、逻辑核

所有核心判断沿同一条链推进：

`事实 → 矛盾 → 判断 → 取舍 → 空间/产品动作 → 客户价值 → 经营结果`

不要求每页写完整七段，但每页必须说明自己接住哪一段、推出哪一段。标题是结论，正文给依据，图像承担证据或解释。

### 六项检查

1. **主体**：谁判断、谁行动、谁受益或承担代价；
2. **口径**：数据的时间、范围、单位、样本与来源；
3. **比较**：相对谁更好、更稀缺或更贵，比较基准一致；
4. **因果**：证据是否足以支持“因此”，相关性不得冒充因果；
5. **边界**：结论在什么客户、产品、价格或情境下成立；
6. **后果**：该判断具体改变哪项取舍、空间、产品、价格或营销动作。

### 硬失败

- 用箭头、排版或文学句连接两件没有因果关系的事；
- 偷换概念，前文谈资源，后文直接得出溢价；
- 结论没有比较对象，或比较对象在页内改变；
- 数据只能证明现象，却直接推出客户意愿、成交或价格；
- 同一结论在一页纸、详细章节和营销主题中口径不一致；
- 只有正确的常识，没有针对本项目的决策后果。

## 三、文学核

文学性负责把真实判断变得准确、可感、可记，不负责制造事实或填补逻辑。意象只能从项目的土地前史、地貌气候、产业生活、地方材料、人物动作和空间结构中生长。

完整故事线还必须读取 `国内文学主线与多语命名.md`，为价值推导同步建立情绪母线与逻辑文学链。禁止先写完理性策略，再把所有标题交给文案统一诗化。

### 合格表达

- 先写清判断，再压缩成标题或原创判断句；
- 一个句子只保留一个主判断，动词优先于形容词；
- 抽象词近旁必须有可见场景、人物动作或空间后果；
- 对仗、比喻、节奏和留白服务于含义，不为“高级感”牺牲准确；
- 全案保留少量真正有记忆点的句子，其余页面用清楚、克制的表达托住。

### 不合格表达

- “时代封面、世界审美、重塑想象、定义未来”等宏大词承担主要结论；
- 同义词排比、名词堆叠、无主体长句或伪哲学问句；
- 标题很美，但无法翻译成空间、产品、价格或运营动作；
- 为押韵、对仗或情绪强度篡改事实；
- 每页都像广告文案，导致研究、经营与风险失去可信度。

## 四、空页与废页拦截

完整方案的页数区间是覆盖完整后的参考，不是凑页命令。内容不足时标注缺失模块并返回研究或决策，不得拆句、放大字号、重复图片补页。

每页在页面预算表中必须具备：

1. `核心判断`：本页要让决策者相信什么；
2. `新增内容`：相对前页新增事实、矛盾、选择、结构或证据；
3. `证据或视觉任务`：数据、地图、总图、剖面、动线、人物行为或机制图；
4. `决策后果`：影响哪项取舍、产品、价格、供货、营销或风险；
5. `合并测试`：删除或与邻页合并，论证是否受损。

以下任一情况判为废页并删除、合并或重做：

- 只有标题、名言、情绪图片、章节编号或不承担转折的过场；
- 正文只是标题的同义改写，没有新增信息；
- 与其他页面的核心内容高度重复；
- 主要内容只有形容词、通用价值词或项目名；
- 图片只是装饰，无法说明事实、关系、空间或使用方式；
- 删除后不影响标题链、决策链或信息完整性；
- 为满足最低页数，把一个完整判断机械拆成多页。

章节幕可以少字，但必须承担明确转折：总结上一章已经证明什么，并提出下一章必须回答的问题。封面和必要目录不按内容页字数判断，仍不得重复设置。

## 五、成稿逐页审核卡

逐页回答并记录 `通过/退回`：

- 这句话像国内真实决策者、客户或专业团队会说的话吗？
- 事实、判断、建议和创意是否被清楚区分？
- 本页从什么依据推出什么结论，有没有偷换或跳步？
- 文学表达是否让判断更准确，而非更含混？
- 本页是否增加信息或推动决策？
- 删除或合并后是否更清楚？如果是，立即删除或合并。

自动脚本只拦截空白、过短、重复、套话密度和明显表达风险；逻辑与文学质量必须再做人工逐页复核。
