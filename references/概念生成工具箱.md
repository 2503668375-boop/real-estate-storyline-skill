# 概念生成工具箱（P2）

> 11.0适用说明：本文件保留创作方法、历史案例或旧格式经验；固定页数、字数、候选/支柱数量、词性和旧脚本门槛仅作历史参考。新任务按SKILL.md、《价值提炼与推导》及《11版数据契约与验收》执行。关键假设进入决策正文，公共技能不随项目操作自动回写。

> 现有流程的四硬审是**否定式**（防烂）；本工具补上**肯定式**生成路径——从两难困境到概念候选的结构化推导，不靠文学天赋硬凹。
> 配合统一规则.json 的 12 个「概念切入角度」使用；生成后仍须过四硬审（新/准/真/亮）与换盘校验。

## 生成总路径

```
项目两难困境（取一个最尖锐的）
  → 项目为它做了什么取舍（证据）
  → 客户在取舍中获得的具体改变（人物+动作）
  → 用切入角度放大成一个概念命题
  → 概念命题 → 推广案名 → Slogan → 产品/空间命名
```

先定「困境—取舍—改变」三件套，再谈文采。没有三件套的漂亮句子一律不上桌。

## 12 个切入角度（统一规则已有，给出用法）

| 切入角度 | 怎么用 | 反面提醒 |
|---|---|---|
| 反常识翻转 | 把行业惯例倒过来："别人做最大的，我们做最顺手的" | 为反转而反转 |
| 矛盾加压 | 把客户的两难推到极致再给出路 | 只加压不解决 |
| 取舍显影 | 把项目放弃的东西亮出来："砍掉会所，把钱给收纳" | 无真实取舍支撑 |
| 身份重命名 | 给客户一种新的自我称谓："不是换房，是换一种过法" | 称谓空洞 |
| 关系重构 | 重新定义家庭关系："两代互不打扰，就是最好的相处" | 假关系 |
| 时间改写 | 改写客户的时间观："把通勤 40 分钟还给早餐" | 无时间证据 |
| 空间做法 | 用具体空间动作说话："玄关整墙系统，回家三步放空" | 无产品接口 |
| 城市角色 | 项目在城市里扮演什么："这座城市给奋斗者的第一张答卷" | 城市黑话 |
| 地方文化 | 用在地文脉做识别："老城墙下，新式院子" | 贴标签 |
| 自然条件 | 用景观/气候做独占："一线海景，三面公园" | 无独占证明 |
| 品牌能力 | 用开发商的兑现能力背书："央企交付，敢写进合同" | 品牌自嗨 |
| 跳出行业常规 | 对标行业外的体验："把酒店式服务搬进家" | 抄业外概念 |

## 三件套模板（结构化填写）

```
1. 两难困境（一句话）：
   例：要三房就得挤在 100㎡，要舒适就得超预算。

2. 项目取舍（证据，至少两项）：
   例：① 砍掉样板房虚荣面积，把预算给收纳与家政间；
       ② 压缩公摊，把 105㎡ 做出三房两卫。

3. 客户获得的改变（人物+动作）：
   例：一家五口不再抢卫生间；婆婆的茶具和你的书都有地方放。
```

三件套成立后，选 1-2 个切入角度生成 3-5 个概念候选，再比选。

## 候选检查（进入比选前）

- 概念句删去项目名，换到两个竞品盘仍自然 → 淘汰；
- 概念只有形容词没有动作/物件 → 淘汰；
- 概念不能带出产品、价格或营销动作 → 淘汰；
- 概念与两难困境无关，只是通用口号 → 淘汰。

## 与四硬审衔接

生成 → 初筛（上述四条）→ 四硬审（新/准/真/亮）→ 换盘校验 → 概念对比选 → 文学跃迁（若需要）。工具不替代评审，只保证评审前有足够的、有结构的候选可评。
