# 跨城市工具包（P1）

> 四个与城市无关的标准化工具：客户三通道导入、24h 客户地图、面积段×总价带矩阵、竞品价格锚点表。
> 任何城市、任何项目通用——城市不同只换数据，不换方法。工具给**起点与结构**，结论一律由证据收窄（与「客群驱动的产品与空间」的决策分叉纪律一致，不产出固定菜单）。

## 工具一：客户三通道导入（万科逻辑）

用途：回答"客户从哪来"。项目所在的板块能导入什么客群，决定产品与服务。

| 通道 | 判断依据 | 客群结果 |
|---|---|---|
| 板块导入 | 板块内楼龄10年+小区的置换需求（蓄水池） | 在地改善客：卖旧买新 |
| 交通导入 | 地铁/快速路/高铁的通勤半径 | 外溢通勤客：城区挤压出来 |
| 商业/配套导入 | 学校、医院、产业、商圈吸附力 | 资源追逐客：为孩子/老人/工作 |

步骤：
1. 三通道各列 2-3 条证据（数据或事实）；
2. 判断哪条通道是主力（决定客户卡主画像）；
3. 按主力通道反推产品接口（通勤客→近地铁动线；置换客→收纳与适老；资源客→学区/医疗配套证明）。

边界：三通道是**起点假设**，客户结论仍需竞品数据与原声验证环确认。

## 工具二：24h 客户地图

用途：回答"客户每天怎么过"，为产品、样板间动线、概念生成提供人物场景。

步骤：
1. 选 1-2 组目标客户画像（如：双职工三代家庭）；
2. 拆解一天：6:00-9:00 晨间 / 9:00-18:00 日间 / 18:00-23:00 晚间 / 周末；
3. 每个时段写：谁、在哪、干什么、此刻最想解决什么；
4. 圈出 2-3 个"高摩擦时刻"（如：早高峰两代人抢卫生间、晚归后没地方放包放钥匙）。

输出：高摩擦时刻 → 空间/设备接口（双台盆、玄关收纳、家政间）→ 概念人物场景（"婆婆在阳台有茶角，你在书房有工位"）。

边界：地图是**假设的具象化**，必须有原声或行为证据支撑，禁止凭空编生活。

## 工具三：面积段×总价带矩阵

用途：给面积段配比一个**起点参考**，再按证据收窄。不是固定菜单。

用当地成交分布建立面积×总价矩阵，写时间、样本与套数占比；再结合旧房净回款、可贷额、家庭保留资金和供货/折扣后的去化比较。不同城市同名“改善”并不代表相同预算，取消全国固定总价档。
配比由客户支付与产品战略分叉决定；同一面积多种用途、单一面积段均可验证。

## 工具四：竞品价格锚点表

用途：为定价建立**锚点体系**，避免价格拍脑袋。

| 锚点 | 内容 | 用途 |
|---|---|---|
| 备案锚点 | 竞品备案价（政府口径） | 当地备案规则和申报价参照，不自动视为市场天花板 |
| 折后锚点 | 竞品实际成交折扣与折后均价 | 市场可实现价格 |
| 总价锚点 | 竞品主力总价带与卖得最好的总价段 | 本案总价定位 |
| 二手锚点 | 板块二手挂牌/成交价（新旧价差） | 置换客的算账基准 |

步骤：
1. 选 2-3 个直接竞品，逐项填锚点（口径、统计期、来源）；
2. 画本案与竞品的「价格-面积」散点位置，找空位；
3. 由锚点差 + 本案资源差异推导本案折后价区间（进取/基准/防守）；
4. 全部锚点记录进附录台账，正文只呈现已确定口径。

边界：锚点是参照不是答案；竞品数据不足时价格只能给条件化区间，不得宣称唯一首开答案。
