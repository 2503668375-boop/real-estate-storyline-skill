# 完整提案的推导与展开 · 11.3

用于完整定位、故事线、产品价值及整合营销提案；专项按本轮责任选用。方法来自提案比较中暴露的具体问题：章节齐全却缺少判断、参数算清却缺少依据、主题有名字却不能统领产品。抽象研究和创作的方法，不继承任何个案的口号、城市理论、客群标签、面积、配比或价格。

## 一、先确定要作出的选择

完整方案先明确本案要赢得什么选择：谁原本会买哪里、继续住哪里或不买，我们用什么足以改变他的决定，同时实现什么经营目标。定位语是这个选择的归纳。

把争议写成能改变项目的具体问题。例如：保持较低总价扩大客源，还是集中更大的主力户型争取升级需求？把预算放到户内尺度、可用园林还是运营服务？已经锁定的产品则比较展示、推货、价格和传播路径。选项要真实可行，不设置明显弱的陪衬。

记录本轮推荐、最强备选、取舍原因及改判条件。可以先探索主题，但不允许先爱上一个词，再选资料替它证明。

## 二、让各路研究完成不同任务

| 研究对象 | 要解释的问题 | 应交出的项目判断 | 常见浅写 |
|---|---|---|---|
| 市场与时代 | 购买行为、供应和兑现偏好发生了什么变化，影响哪些预算段 | 此时适合争取何种需求，哪些旧做法失效 | 政策和宏观数据罗列后直接“机遇到来” |
| 城市与板块 | 财富怎样形成，工作生活怎样组织，资源与竞争位置如何变化 | 本案所在位置对特定人群的真实意义 | GDP大，所以房价高；成熟，所以必然升值 |
| 土地与项目 | 权属指标、城市界面、空间和一期关系提供什么，限制什么 | 哪个问题要通过规划、空间、管理或交易解决 | 地段好、配套全、园林美 |
| 客户 | 钱从哪里来，为什么现在换，什么不愿失去，预算怎样兑现 | 主次客群、必要功能、可接受代价及退出原因 | 高净值、企业主、改善家庭等标签 |
| 竞争 | 客户实际比较的新房、二手、其他板块和不买，各提供什么 | 本案可赢的组合、必须补齐的门槛和不值得争夺的需求 | 只比单价、只列项目优点或贬低对手 |

研究不必平均用力。影响主张、产品或价格的分歧要深入；不会改变决策的城市史和案例不扩写。低成交同时查供应、去化和口径；所谓市场空白同时查支付力与替代行为。缺少供应分母时，不能把成交分布直接写成需求偏好。

## 三、把研究推成命题

先用平实语言完成这段论证：对这类客户，现有选择提供了什么，又让他承担什么；本案哪项条件或组合能改善结果；改善需要怎样的产品和组织投入；与最强替代相比，为什么值得选择。

命题可以来自未满足需求、已有优势的新组织、作品与审美向往、服务兑现或交易效率。不强制每盘制造冲突、反转和阶层升级。

需要跨尺度时补足中间环节：

- 城市资源 → 与目标客户的关系 → 实际可达、可用和使用频率 → 本案能够承接的生活。不能从全市资源直接跳到家门口专属。
- 财富来源 → 家庭与事业阶段 → 具体生活诉求 → 产品和支付选择。收入职业与套数份额不是同一数据。
- 空间限制 → 可实施的空间机制 → 可感知的改变 → 选择优势。改变高差、动线或景观不自动消除噪声、共有关系等全部问题。
- 客户向往 → 项目坚持的原则 → 具有识别度的主题 → 能兑现的空间、服务和行动。文化比喻可启发创作，不充当市场因果。

主体、时点、范围和条件保持一致。每次引入新资料，检查它会不会推翻既有项目基础、核心客群、价格口径或容量测算。

## 四、用论证单元解决“只有几句话”

论证单元是一个重要问题的完整回答，可以占一个章节、连续几页或数段正文。摘要可以短，支持摘要的正文必须足够让未参会者理解。

一个成熟单元通常包含以下内容；根据问题组织成自然文字和图表，不把每页做成六格表：

1. **判断和范围**：要回答什么，针对哪些产品、客户和时期。
2. **具体材料**：同口径数据、实际案例、图纸关系、行为记录或明确标记的假设。写出关键内容，不能只有一个来源链接。
3. **机制解释**：材料如何支持判断，客户会得到什么、付出什么；相关性与因果分开。
4. **比较与反方**：最强替代和另一种解释是什么，为什么目前仍推荐此方向。
5. **项目决策**：影响哪项定位、产品、尺度、配比、价格、预算、展示或运营，舍弃什么。
6. **成立边界与承接**：未知项会如何改变结论；本单元解决后，下一章还要解决什么。

仅有“证据待核、客户待访、成本待算”时，作者尚未完成分析。应利用现有证据提出条件方案，说明不同结果分别导致什么调整，继续把不依赖缺口的内容做完。缺原始数据不能靠编造样本、原声、精确份额或溢价系数填满。

详实的检查对象是信息贡献：

- 新增事实是否改变理解？
- 比较是否解释了一个实际取舍？
- 场景是否揭示了空间、服务或购买机制？
- 数字是否有来源、单位、分母及决策用途？
- 段落是否推进了下一步？

大量字数仍可能只是重复口号；精确图表配充分解释也可以简练而完整。不设置所有项目统一的页数、字数、案例数量或段落长度。

## 五、完整方案各部分展开到什么程度

| 内容 | 不能停在 | 足够展开的表现 |
|---|---|---|
| 城市与机会 | 区位标签、发展成绩 | 解释资源与财富如何关联目标需求，说明本案在竞争中承担什么角色 |
| 项目条件 | 指标表与优缺点 | 从指标、权利和现场界面推到空间做法，交代限制和产品代价 |
| 客户 | 人群名与一句痛点 | 财富/资产来源、家庭结构、现住缺陷、换房触发、必要功能、支付路径、犹豫与放弃原因相连 |
| 定位 | 一句高端定位语 | 客群与竞争范围、核心机会、主张、主次价值、舍弃项及支持条件完整 |
| 故事 | 五个漂亮章节名 | 每章新增一个判断，上一章提出的问题由下一章解决；主题的来历和承接清楚 |
| 产品 | 大堂、园林、会所等清单 | 关键体验有使用者、空间组织、尺度依据、可见特色、实现条件、维护与展示方法 |
| 价格与配比 | 一个均价和百分比 | 可比口径、支付预算、面积与总价、绝对套数、货值、客源容量及去化周期联动 |
| 创意传播 | “做视频、做圈层、做发布会” | 实际主张与文案、核心场景/脚本、传播对象、证明内容、到访与成交承接 |
| 运营执行 | 活动表与费用总额 | 谁提供、谁使用、容量频次、收费与持续预算，及责任、节点和调整条件 |

完整范围由用户任务决定。已定产品的故事线不强加拿地模型；完整定位若包含价格与配比，就不能只完成营销文案。

## 六、从主题进入产品，保留应有的想象力

主题至少能解释三种关系：它从本案何处来，客户为什么在意，它要求项目怎样做。重点产品可以通过归家、空间尺度、景观、声音、光、材料、服务与人物活动承接；数量由可实施方案决定。

对每项关键产品特色，写清：

**服务对象与时刻 → 空间/服务动作 → 可识别的体验 → 设计与运营接口 → 成本和权利边界 → 客户怎样验证。**

基础品质负责长期好用，特色空间负责识别、向往和到访记忆；两者共同承担价值。不能用满篇维护、边界和风险检查取代建筑作品感，也不能把国际案例、效果图和命名直接当成溢价。

参考项目时分解“条件—机制—体验—结果”。说明本案借鉴哪种组织方法、如何适配密度气候预算、哪些不采用。奖项不能单独证明市场溢价，外地城市空间比喻不能推成普遍发展规律。

创作完成后反推实际期待：客户听到这个主题，会期待哪条路径、哪种空间和服务？现有设计能否承接？主题不依赖任何项目做法时继续重写；独特做法不成立时调整产品或降低主张，不捏造独有性。

## 七、经营推导不能停在“公式算对”

按《经营测算与价格推导》统一备案、表价、折后成交、净签约和资金实收的定义，注明装修、赠送、车位及费用。报告里的“实收价”先核业务含义，不能自动等同已到账现金。

推荐价格至少解释可比成交、产品差异、客户支付和货量时限之间的关系。基准价加若干配置溢价只是待测假说；没有带价选择或成交证据，不能称为“市场证明”。

户型组合沿着预算和任务推导，并回算：

`类型总价 = 类型面积 × 同口径单价`

`均套面积 = Σ(类型面积 × 套数占比)`

`概算套数 = 可售住宅面积 ÷ 均套面积`

`类型货量 = 总套数 × 套数占比`

`面积加权均价 = Σ(类型套数 × 类型面积 × 类型单价) ÷ Σ(类型套数 × 类型面积)`

概算需按标准层模数、楼栋与整数套数校正。小比例也可能是大货量；“限量”须说明绝对套数、目标客户和预计销售时间。主力、入门和旗舰分别承担什么经营任务，不能只靠命名解释。

会所等配套同时核面积、可使用人群、峰值容量、功能强度及运维。每户面积的分母要说明商品住宅、回迁、其他合法使用人是否计入；不以不同分母制造配置领先。

缺少关键数字时给出明确建议区间或情景及调整规则，避免假精确，也避免只交待研究清单。

## 八、写作与制作顺序

1. 先有项目判断和论证正文，允许研究、概念和设计之间来回校准。
2. 将已成立的判断组织成连续主线，补上跨章缺失的中间结论。
3. 完成主题、宣言、产品特色和关键传播样稿。交付实际内容，不只描述打算创作什么。
4. 再把长论证转成适合汇报的页组。概念页可以短，研究页和产品页应保留足够材料。
5. 检查最终阅读路径，避免实质推导只在隐藏备注、附件或底稿中，而主文件仅有口号。

可用“判断页 → 证据与比较页 → 本案决策页”组织一个问题，也可以在一张图表中完成；不要求固定三页。对外正文应可独立理解，附件承载明细和原始材料。文案长短服务论证，不受聊天回复的默认简短偏好支配。

## 九、合成示范：同一句建议怎样展开

以下是虚构教学设定，数字只用于展示方法，不是任何真实项目结论。

**浅写：**“项目位于成熟城区，客户重视改善，建议打造有边界的园林大宅，提升产品溢价。”

这句话无法解释客户为何换、本案如何胜出、投入什么、何时不成立。

**展开后的一个论证单元：**

本案应优先争取生活重心仍在老城、已有住房但家庭使用关系发生变化的置换家庭。教学设定中，三类可比选择分别提供不同利益：成熟二手保留学校与亲属联系，外围新房提供更完整的社区，原房改造保留较低的资金支出。因此，本案的竞争问题是如何同时保留熟悉的生活联系，并提供足以抵偿置换成本的空间改善。仅凭“成熟地段”难以说服客户，因为继续住在原房同样享有这项便利。

假设项目可售面积为60000㎡，街道界面便利但穿行较多，内部庭院可以重新组织。此时存在两条可行产品路线：增加小面积产品，以较低总价扩大覆盖；集中家庭大宅，以动静分区、完整餐厨和独立归家提高改善幅度。前者增加潜在客源，也会增加户数与公区负荷；后者保持社区容量，却要求客户同时承担更高首付款和旧房处置压力。两者必须比较总价和销售时间，不能只比较单价。

如果暂定均套180㎡，概算约333套；均套降至150㎡，则约400套，相差约67户。这个差异会改变电梯高峰、停车、会所和儿童活动空间的服务容量。若将高总价旗舰设为5%，前一组合仍有约17套，不能仅凭比例称作“极少量”。在尚无相应预算客户记录时，旗舰应比较降低绝对套数、降低总价或分期推出的不同方案，并算出剩余货量如何重新分配。

空间上，建议把公共穿行与家庭停留分开，形成从便利街道进入安静庭院、再进入家庭公共空间的连续路径。园林投资先解决可停留、可遮阴、可照护的使用关系，再决定景观表现。户内重点为待客与家人休息能够并行、长辈房靠近必要服务、家政动线避开主要活动区。它们共同承担“家庭相处更有余地”的购买理由。声学效果仍需要门窗、构造和设备协同，庭院与绿化只能承担部分空间及感受上的缓冲。

据此可以探索“熟悉的城市，舒展的新家”这一工作主题。它保留老城联系，也提出可检查的产品承诺。样板展示应让客户带着真实家具尺度和家庭成员关系走完一次生活模拟，比较原住房与本案如何安排同一天的会客、休息与照护。主题尚不等于正式案名；如果场地无法形成连续庭院或样板显示空间改善有限，应调整主张。

当前可推荐的是主力改善路线及相应空间任务，尚不能确认溢价幅度。下一步用同总价的二手和外围新房作为替代选项，核对家庭净资产、卖旧周期与实际选择：若客户主要被资金缺口阻挡，优先调整面积、付款和推货；若支付可行但改善感不足，回到户内和公区重做。这个检验将决定价格与配比，避免把每项新增成本都直接加到售价上。

**本示范为什么比摘要更充分：**它区分了真实替代，解释了机制，算出了货量和容量影响，给出了空间任务、主题来历与展示动作，并说明何种反馈会改变建议。它仍只是一个单元，不能包装成完整项目方案。

## 十、冷读与复核

先读正文，再看字段；用具体段落证明判断：

- **任务覆盖**：用户要求的定位、故事、产品、价格等在哪里完成，是否被缩成了目录。
- **论证深度**：关键问题有没有事实/边界、机制/比较、本案决策；是否只有两三句结论和待办。
- **主线连续**：前一章如何推出下一章，是否把并列优点误当故事递进。
- **创作完成**：是否真的写出主张、核心故事和关键体验，是否具有项目针对性。
- **经营一致**：客群排序、总价、配比、绝对货量、配套分母和成本口径是否前后一致。

给每个关键问题一个具名审阅结论：已充分展开、有条件展开、未展开，并摘出支持该判断的实际正文。没有外部证据可以是有条件展开；只有“待研究”属于未展开。作者自审如实标注，不能冒充客户或独立意见。

自动检查仅核正文版本、摘录和覆盖引用，不按字数判好坏，不输出“深度认证”或市场有效性。机器记录通过后仍要实际冷读；发现关键单元未展开就继续写。向用户交付可读方案，审阅记录留作项目资料，不能让整理记录挤占创作。

迁移到其他项目时再次检查：郊区、首置、文旅、办公或尾盘是否有不同的竞争问题；不要把成熟中心、大宅、抬板或某一类财富人物固定成通用答案。
