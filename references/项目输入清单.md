# 项目输入清单（L0 输入层）

> 开工第一件事：把这张表给用户填。一次给全，AI 直接进入调研与推导；缺项按「缺项降级规则」处理，不阻塞、不硬编。
> 用户能提供多少给多少；给不了的，由市场调研与客户推导补位，并在附录标注「资料缺口」。

## 一、土地与规划条件

| 输入项 | 说明 | 必填 |
|---|---|---|
| 宗地编号 / 位置 | 城市、区、板块、地块编号 | 必填 |
| 用地性质 | 住宅/商住/商业/办公/综合 | 必填 |
| 容积率 | 规划容积率 | 必填 |
| 计容面积 | 可售计容面积（㎡） | 必填 |
| 建筑限高 / 密度 | 如有 | 选填 |
| 配建要求 | 学校、保障房、道路、公共设施 | 选填（影响货值与成本） |
| 限价 / 指导价 | 备案价上限或政府指导价（2026-08 起多城已放开，AI 复核） | 选填（强二线以下常有） |
| 出让条件 | 自持比例、销售限制、装配式要求 | 选填 |
| **建设工程规划许可证时点** | 是否已取得、取得日期（2026-08-28 前后决定销售制度轨道） | **必填（v10.0）** |
| **销售制度状态** | A 轨取证老盘 / B 轨封顶预售 / C 轨现售（判定规则见《2026销售制度与新规应对.md》第 2 节） | **必填（v10.0，AI 判定）** |

## 二、经营约束

| 输入项 | 说明 | 必填 |
|---|---|---|
| 楼面价 | 拿地成本（元/㎡） | 必填 |
| 目标利润率 / 现金流 | 公司对该项目的经营底线 | 选填 |
| 首开时间节点 | 计划取证/开盘时间；C 轨为竣工备案/销售启动时间 | 选填（决定营销倒排） |
| 主体封顶/竣工节点 | B 轨封顶时间、C 轨竣工备案时间（现金流回款起点） | 选填（v10.0 新增） |
| 全年销售目标 | 回款/签约目标 | 选填 |
| 融资与付款条件 | 如有特殊要求 | 选填 |

## 三、市场线索（可后补，由 AI 调研）

| 输入项 | 说明 | 必填 |
|---|---|---|
| 板块范围 | 项目所在板块名称 | 必填 |
| 周边3km竞品 | 案名、位置、推货节奏 | 选填（无则由 AI 调研） |
| 已知市场数据 | 成交、库存、去化等已有数据 | 选填 |
| 政策环境 | 限购/限贷/限价最新情况 | 选填 |

## 四、客户线索（可后补，由 AI 推导）

| 输入项 | 说明 | 必填 |
|---|---|---|
| 已知客群画像 | 已明确的客群类型（如有） | 选填 |
| 已有访谈/成交记录 | 访谈原话、成交复盘 | 选填 |
| 公司客研结论 | 集团/区域已出的客研报告 | 选填 |
| 老业主结构 | 本项目或同区域老项目业主特征 | 选填 |

## 缺项降级规则

| 情况 | 处理 |
|---|---|
| 缺土地规划条件 | 无法判定产品约束 → 降到 C 级研究诊断，补证计划列明取证路径 |
| 缺楼面价/经营约束 | 价格与经营只能给条件化区间 → 正文不得宣称唯一首开答案 |
| 缺竞品与市场数据 | AI 主动调研补齐；调研不到 → 降 B/C 级，缺口入附录 |
| 缺客户画像 | 由竞品开盘数据、二手置换链、产业人口三类行为证据反推，标注证据类型 |

## 交接动作

1. 用户填完表，把 `项目输入清单.json` 写入项目目录；
2. 对照「资料等级判定」给整体资料定级（A/B/C）；
3. 启动步骤②市场调研，缺口项进入附录「待验证清单」。

> 注意：清单里的输入是**起点材料**，不是结论。客户、面积段、户型、价格永远由证据推导，不能因清单给了某个字段就跳过推导。
