# 市场数据取数与口径矩阵（9.0）

## 先回答决策，再找数据

完整前策不以“找到多少报告”为目标。先写清下面五个问题，再取数：

1. 城市此刻是由新房还是二手房主导交易，价格和成交各在发生什么；
2. 板块的新房供应、成交、库存和去化是否支持入市节奏；
3. 在地置换客卖旧房的速度、议价和可动用总价，能否支撑目标产品；
4. 直接竞品的推货、认购、开盘去化、折后价格和剩余货源，哪一个会抢走本案客户；
5. 哪些已知数字会改变面积段、总价、首批货量、付款方式或上市时间。

没有对应决策的问题，数据不进主稿；没有数据支撑，结论不进入产品、价格或概念。

## `市场数据包.json` 是A级硬前提

与 `研究底稿.json` 并行建立 `市场数据包.json`。完整前策覆盖以下六类；专项按决策选择维度。数量不设固定12条，独立来源和项目层证据需真实覆盖关键判断：

| 维度 | 最低指标 | 对项目的作用 |
|---|---|---|
| 城市基线 | 新房成交或供应、二手成交或价格 | 判断需求在哪一侧发生 |
| 板块供求 | 新房供应、成交、库存或去化之一 | 判断入市与供货压力 |
| 二手置换 | 挂牌、成交周期、议价、总价或面积结构之一 | 判断卖旧买新和支付边界 |
| 竞品开盘 | 推售、认筹、去化、备案/折后价或余货之一 | 判断真正的竞争对象 |
| 竞品成交 | 至少两项目的量价、产品或成交表现比较 | 判断产品空位，不能只列案名 |
| 项目法定 | 土地、规划、预售/交付或公共服务节点之一 | 判断项目能兑现什么 |

单个数字不可跨层补位。例如全市均价不能代替板块价格，竞品挂牌价不能代替开盘去化，规划学校不能代替客户支付能力。

### 数据记录结构

每条记录必须具备（示例为格式示范，城市/机构/口径按实际替换）：

```json
{
  "证据ID": "M-01",
  "维度": "板块供求",
  "指标": "新建商品住宅网签",
  "数值": "2139",
  "单位": "套",
  "统计期": "2025-01至2025-04",
  "地域": "某市·某板块",
  "口径": "新建商品住宅网签销售，不含二手与商业",
  "比较": "同比+148%",
  "来源机构": "某区住建局",
  "来源链接": "https://...",
  "发布日期": "2025-05-13",
  "抓取日期": "2026-08-03",
  "证据级别": "权威媒体",
  "允许推断": "支持短期供货加速，不证明长期涨价",
  "对项目决定": "首批货量按月度来访和竞品余货分段释放"
}
```

数值可以是区间、比例或文字化指标；指标、统计期、地域、口径、来源机构、链接和项目决定不可为空。机构监测与政府口径不同，必须保留原始口径，不可平均。

## 数据源角色与交叉验证

| 来源 | 最适合回答 | 使用边界 |
|---|---|---|
| 政府住建/交易平台、统计局、规划资源局 | 网签、预售、土地、规划、政策 | 法定事实和城市/区级基线优先；不一定给到竞品去化 |
| 本地中介研究机构（如深圳乐有家、上海链家研究院等） | 二手成交、录得量、议价、挂牌、总价/面积与楼龄结构 | 强于存量市场和买方行为；注明网签、录得或平台样本 |
| 本地中原/当地主流代理研究部 | 新房预售/现售、供应、成交、二手过户与月度节奏 | 强于新房结构与月度变化；分清预售、现售和全口径网签 |
| 克而瑞 | 供应、库存、去化、房企/项目排行、开盘推售 | 强于项目级与供求比较；注明监测边界、是否含现售/保障房 |
| 贝壳研究院/中指 | 二手挂牌、成交、库存与跨机构交叉验证 | 样本、挂牌和成交不混用；不替代官方网签 |
| 项目预售证、售楼处价目、开盘公示、渠道回执 | 推售、价格、认购、余货和产品 | 仅证明对应项目和时点，必须记录采集方式 |

### 城市分级取数矩阵（全国通用）

不同能级的城市，可得数据源差别很大。先定城市能级，再按对应行取数；优先核官方法定/交易口径，并采用能覆盖相关市场的独立机构或有记录的项目调查交叉验证。机构缺位时允许本地实地证据，不强制机构家数。冰山指数、趋势动物、券商观点不得替代以下任一数据位。

| 城市能级 | 官方口径（必取） | 机构口径（至少一家） | 兜底方案 |
|---|---|---|---|
| 一线（北上广深） | 住建局网签/备案、规划资源局、统计局 | 本地中介研究（如乐有家、链家研究院）、中原、克而瑞、贝壳 | 机构缺位时用贝壳+中指双源交叉；记录失败原因 |
| 强二线（杭州/成都/武汉/南京等） | 住建局网签/备案、统计局、规划局 | 克而瑞、中指、贝壳研究院、本地代理研究部 | 克而瑞+中指为主；缺项目级数据时回退房管局备案+实地 |
| 普通地级市 | 房管局备案/预售公示、统计局、自然资源局 | 中指、贝壳城市站、本地主要中介 | 以房管局+贝壳为主；无机构监测时用备案价与网签直接统计 |
| 县城/县级市 | 房管局备案、预售证公示、自然资源局 | 本地中介（走访） | 以备案+实地走访+售楼处采集为主，标注样本局限 |

取数顺序统一为：**先官方后机构、先成交后挂牌、先项目级后城市级**。机构数据不等于官方成交，不同口径不得合并成单一数字。

示例（格式示范，城市与机构按上表替换）：`某区新建住宅网签 2139 套（区住建局，2025-01至04），同比+148%——这只能证明区级成交提速，不代表板块内全部项目同速去化；首批推货量以竞品近三月余货和来访转认筹共同决定，不把区级回暖直接翻译为提价。`

## 数据冲突处理

常见冲突包括“预售成交”与“预售+现售网签”、“录得”与“过户”、“住宅”与“全物业”、“近6个月去化”与“近12个月去化”。处理顺序：

1. 不做无声平均；
2. 同页并列口径、样本和统计期；
3. 为当前决策选一套口径，并说明选用理由；
4. 用另一套口径作为敏感性或撤回信号；
5. 不能解释的冲突进入附录，不得转写为确定性结论。

## 写进页面的方法

市场页不允许只写“回暖、分化、压力、锚点”。每页必须明确：

`指标与口径 → 比较对象/时间变化 → 原因或边界 → 改变哪项产品、价格、供货或营销决定`

例：`2025年1—4月某区新建住宅网签2139套，同比增加148%，但这只是区级成交，不代表板块内全部项目同速去化。首批住宅以竞品近三个月余货和来访转认筹共同决定推货，不把区级回暖直接翻译为提价。`

## 失败即降级

- 缺城市、板块、二手或竞品任一核心维度：不能交A级完整方案；
- 只有政策、规划或挂牌价：只能交土地与方向诊断；
- 机构报告打不开：写入资料缺口并改用其他机构/官方口径，不许拿“指数不可得”当作跳过市场研究的理由；
- 未能取得项目级去化：产品和价格只能给条件化区间，正文不得宣称唯一首开答案。

## 竞争与统计补充（11.0）
销售制度按楼栋实际方式核定；新房、二手及其他合法替代供给共同比较，轨道只作解释变量。分别统计获证未推、在售、已认购未签、净签约、退订、不可售与未来供应。
同面积/总价/楼栋条件与同统计期比较，区分均价结构变化与同类价格变化；去化给分母和观察天数。转载同源不算独立证据，客户和房源去重。
“竞争空位”同时检验需求、支付、规模、成本和复制速度；竞品失败应排查价格、信誉、供货和渠道等替代原因。
