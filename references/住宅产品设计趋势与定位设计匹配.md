# 住宅产品设计趋势与定位设计匹配 · 11.0
本文件提供设计选择与验证方法，不保存全国通用的当年强制尺寸、成本或标配。结构与设备实施须有相应专业设计和报批依据。

## 1. 先核真实约束
核最新规划条件、土地合同、用途、容积率/限高、日照与消防、计容/可售/使用面积、结构机电条件、销售与交付标准、分期及设计锁点。
区分法规底线、地方技术规则、项目任务书和竞争优化项。层高、得房、赠送、抬板、风雨连廊等具体能否实施按本地及项目核验；媒体“新规住宅”不能证明项目报批许可。

## 2. 由客户任务选择设计
客户的家庭事件、日常行为、预算和第一否决点对应设计任务；小户型/改善/豪宅标签不能自动决定房间数与装标。
先比较可行的产品结构：同面积不同房间关系、套数与户均资源、配置与总价、公共设施与持有费用。若只一个方向可行，记录被排除的方案原因；单一面积段也可以成立。
三代短住、双职工、独处、成长、适老、宠物与家政应从本项目行为证据选择，不能全部必配。

## 3. 面积与总图联算
建立建筑/计容/可售/实际使用的面积账，套数×各面积段与楼栋资源勾稽；不将使用效率和销售得房口径混用。
评估核心筒、梯户、走廊、设备井、储物、家务与停留空间怎样影响可售效率、建造成本及实际功能。房间数量不能遮蔽家具摆放、净尺寸、采光通风和动线问题。
总图比较日照、噪声、步行、车行、消防、归家/配送、儿童活动、老年可达、停车与分期施工干扰。有限预算先解决高频、严重且可改善的问题。

## 4. 定位与设计匹配
价值卡中每个主张对应产品/服务接口、使用结果、成本和证据。文化或审美概念可以指导材料、尺度、光影与公共空间，但需符合真实土地和运营，不要求每个价值词都新增昂贵设施。
一项设计可支持多项体验，成本只计一次；多个设计若解决同一结果，不重复计算溢价。达到基础标准先视为门槛；超出标准的性能是否带来选择或支付提升需验证。
“可变户型”必须明确可变化部分、施工难度、未来成本与审批，不用示意图承诺任意拆墙。

## 5. 设计基准复核
按任务读取当前有效的国家工程建设规范、地方规划/技术规定、项目审定图纸、专业设计意见与同类实施成本。公开案例、厂家参数和行业趋势只能作候选资料。
记录：来源、发布日期/生效日期、适用地区和用途、参数及单位、核验日、影响的设计决策、与历史方案差异。记录参数有效性的触发条件，避免“本年参数全年必有效”。
发现变化先更新本项目设计基准和成本时序；公共技能更新另经用户授权、备份、验证，不在业务调研中自动回写。无法获取的数据用区间及条件表达，重要未知紧邻相关决定。

## 6. 设计模块怎么做
下表是候选菜单。每个选中模块填写做法、指标口径、专业可行性、成本区间及来源、客户作用、证明方式和舍弃代价，不以全国固定金额/比例自动填表。

| 模块 | 可研究的做法 | 要量化/核查 | 客户与经营取舍 |
|---|---|---|---|
| 声环境 | 围护窗墙、机电、管道、公共动线与卧室位置 | 实际频谱/时段、门窗条件、测试规范、通风与能耗 | 合格不保证个体满意；临路缺陷如实呈现 |
| 家庭边界 | 动静分区、短住与常住关系、可开合空间 | 家具净距、独处与交往动线、改造可逆性 | 房间数、有效面积与总价协同 |
| 收纳家政 | 玄关、清洁设备、洗晾、垃圾与配送 | 真实物品、操作尺度、上下水用电、维护 | 高频便利与成本，避免只展示空柜 |
| 光与空气 | 开窗、遮阳、采光、通风及空气系统 | 气候朝向、专业模拟、运行噪声与耗材 | 体感、能源和维护费用并列 |
| 全龄安全 | 无障碍动线、防滑、扶手预留、儿童活动边界 | 适用标准、监护视线、消防冲突、责任边界 | 按实际年龄与使用频率配置 |
| 结构与弹性 | 非承重可调整、设备预留、短住复用 | 结构/消防/机电审核、未来改造成本 | 不宣传无限可变 |
| 庭院与自然 | 保留树木、遮阴、雨水、安静停留与儿童活动 | 权属、树木保护、根系与建筑、排水、安全、维护 | 自然资产可使用且可长期维护才有价值 |
| 公共空间 | 大堂、架空层、会客、共用工作与活动 | 容量、开放时间、噪声、运营主体及收费 | 不按豪宅标签增加闲置会所 |
| 精装材料 | 触感、耐久、可修复、重点界面 | 供应、样板、环保/防火、维护与替换成本 | 有限预算按触点和生命周期取舍 |
| 智能设备 | 门禁、照明、安防、设备管理 | 稳定性、隐私权限、互通、离线与维修 | 可维护的真实功能优于设备数量 |
| 归家与交通 | 步行接驳、雨天、车行、快递和访客 | 实际路线、权利、各时段冲突、施工可行性 | 内部通勤测试与公开广告表达分开 |
| 展示与交付 | 真实房源、工法/材料、交付样板和验收 | 哪些随房交付、合同条款、实景/示意标识 | 展示投入和交付兑现同步 |

## 7. 双向验证与锁定
定位→设计：这个观念要求怎样的空间、服务或材料组织？
设计→经营：改变多少可售面积、套数、成本、费用、销售/交付时序？
经营→价值：总价与长期费用是否仍适配目标客户？增加的体验是否值得？哪部分可分级或取消？
记录主张、设计模块、参数及来源、成本、影响、验证结论、责任人和锁定节点。三种可行处理：保持主张并调整实施、降低承诺/分级兑现、回退定位或客群；选择依据明确。
设计任务书供专业深化和报批，前策建议不冒充已审定图纸；竣工后只处理真实可改项。样板、专业测试和客户体验分别留证，改变后更新相关价值卡与操盘证据。
