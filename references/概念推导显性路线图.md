# 概念推导显性路线图 · 11.0
## 五层职责
战略定位回答服务谁、在什么竞争范围、凭什么被选及舍弃什么；核心概念将取舍提升为可识别观念；案名负责身份识别；传播语让目标客户记住一个判断；证据内容回答具体顾虑。品牌精神可统领长期价值，但不强制每项目都另造一层。
定位可以用名词、陈述或角色性短语，关键是占位清楚和证据成立。案名按读音、识别、文化联想、重名及登记可用性选择，不限定末字词性。

## 推导过程
事实与限制 → 客户张力 → 竞争参照 → 项目取舍与兑现 → 价值主张 → 生活模式/观念 → 概念案名/传播语 → 产品证据与动作。
中间可以迭代，概念早期探索不代表已承诺。用图、场景或必要的比较展示关键跃迁，页数随论证，不固定6P。
执行《价值提炼与推导》的双向升维：既有足够的思想统领，也有可触摸的产品后果。不能把工程参数罗列当最终概念，不能将抽象哲学当兑现事实。

## 表达统一
统一战略和价值判断，允许不同受众/阶段采用不同意象与事实入口。项目主张可讲家庭边界，产品内容讲隔音和动线，交易内容讲预算及置换；三者各自推进选择。
Slogan可以事实表达或情感召唤，是否有效通过相关性、记忆、可信及行动验证；不强制含数字、重复定位、固定长度或同意象。
区分事实与承诺；通勤时间等内部研究转公开物料时按《公开传播与承诺审查》处理。

## 概念复核
逐项检查项目独属依据、目标客户理解、兑现与成本、最强替代、同价格选择、语言视觉、误读风险。
外部提案结论先行，关键前提同屏；用必要推导证明，保留反方和失效条件。
独立创意意见与客户测试是不同证据：代理角色自评不能冒充独立总监，模型评估不能冒充真人购买意愿；未做则标明待验证。


## 11.1 表达要求
主张与故事需有鲜明文学辨识度和记忆，不能止于功能释义或通用安心口号；读《文案写作与文学表达》。PRE正文、讲稿及实际排版统一读《去AI腔编辑与结构审校》，保持思想、节奏和项目证据。
