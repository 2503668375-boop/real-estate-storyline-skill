# 中文地产汇报与图文成品 · 11.3
目标：让项目负责人读得懂、拿得出、讲得顺，既能判断策略，又能看见项目。适用PPT、HTML和其他图文报告；纯文字专项不强制制作演示。

## 先明确这份材料的用途
管理汇报突出判断、取舍、数字与动作；定位提案充分展示市场机会、价值推导和主题；客户发布突出向往与可信证明；执行手册便于查房源、口径和流程。混合需求用主稿与附件分工，关键购买条件、风险和成立前提保留在正文。
用户有实际项目品牌模板时先读取并沿用字体、色彩、Logo和常用版式，必要时在体系内扩展。不得以通用演示替代公司模板验收。按用户所要文件形式交付，不用HTML代替已要求的可编辑PPTX。

## 先完成内容，再决定页面密度
准备一份可以独立阅读的内容稿，写清判断、依据、比较、项目含义与建议。研究中的关键事实、不同意见和推导不能因版面漂亮被删掉。现场版可以配讲稿，但购买条件和决策前提不能只留在口头。
先按《完整提案的推导与展开》完成正文；完整主文件应保留实质论证。摘要、正文、明细附件分工，不能把所有依据藏进备注、只向用户交一组短句页面。无法在一页读清的内容组成连续页组，不以缩小字号或删去解释解决。
用页面内容表安排：本页判断、正文要点、证据、图像/图表任务、与前后页关系。它是制作辅助，不强迫用户阅读或批准，也不以字段数衡量内容质量。
完整报告按任务覆盖“结论与待决策—市场竞争—客户与支付—项目特征—主次卖点—主题与章节—产品证明—价格/推货/营销—执行与风险”；无需每项独占一章。用户只做故事线时不另编财务全案。

## 图像必须承担解释和证明
| 内容任务 | 优先图文组合 | 阅读者应看懂什么 |
|---|---|---|
| 区位与市场 | 有来源的地图、空间关系图、竞品分布＋判断 | 项目在何处，与需求和竞争有什么关系 |
| 供应与价格 | 同口径趋势、分布、比较图＋出处和含义 | 哪个细分机会成立，何时可能失效 |
| 项目特征 | 实景/航拍/总图的重点标注＋特征解释 | 最重要的特征在哪里，限制在哪里 |
| 产品价值 | 户型/剖面/动线/前后比较＋使用机制 | 客户通过什么空间获得什么结果 |
| 核心主题 | 有项目依据的主图＋主题及精炼承接 | 项目想建立什么认知与向往 |
| 价格与经营 | 清晰比较、瀑布或情景表＋条件 | 价格依据、代价与现金影响 |
| 营销执行 | 横向时间轴、纵向业务线＋关键动作 | 何时、谁做、证明什么、如何承接 |

真实项目图优先。图像先找来源与使用范围，素材缺失则制作清楚标记的结构示意；不能用生成效果图冒充项目实景，不能用无刻度曲线冒充市场数据。纯文字装进SVG、图标卡片或装饰背景不算图文证据。
每张图配足以独立理解的标题、标注与必要图注；图上结论与数据/图纸对应。概念渲染用于审美方向，不能证明客户、景观、交付和经营事实。

## 详实与好看同时成立
研究页保留足够信息，概念页允许留白；详实依靠有效内容和证据，不能靠小字堆满。每页形成明确的阅读顺序，主图、正文、图注有不同分量。
评估密度时看“这个问题是否讲透”：页组可以包含判断、图表或案例比较、推导和本案取舍。概念页的简短不能扩散成整份研究的简短；增加页数、图标和重复标题不能补足缺失的内容。
版式按任务选：大图标注、左右对照、连续图解、地图、图表、精确表格、时间轴与主张页。统一设计体系，避免整套等宽卡片，也不为换版而破坏内容。
先把市场证据、价值推导、主题和执行等关键页做成可读页面并实际查看，再完成其余内容；这是内部制作检查，无需另设用户阶段确认。完成标准仍是本轮要求的全部成果。

## 中文地产汇报的语言
分析页标题直接给有范围的判断，例如“同总价竞争集中在成熟二手，本案需证明产品改善”，随后给依据。栏目名可作小标题，不把“市场分析”“客户洞察”当整页唯一结论。
策略句写清对象和动作：“首批优先展示可实看的景观房源，先验证客户对视野的接受度”，少写“以价值赋能全链路转化”。概念页可有“世界湾区”“时代封面”等气势，但正文要落到具体城市、建筑与生活。
删除套话、空转的形容词、假翻转、机械三段式、同义结论和过度解释；保留有依据的行业词、四字格、排比与文学节奏。不用错字、网络腔或故意碎句装作自然。

## 实际成品验收
先通读内容，指出最有分量的判断、最弱的推导和最像模板的一段并修改。随后看缩略图总览和每一页原尺寸：
- 正文及讲稿能否支持标题，数据、地图和产品图是否对应当前版本；
- 是否有足够的项目图与解释性图表，关键页是否用装饰替代证明；
- 是否出现错字、孤字、重叠、裁切、低清、图注看不清及不合理空白；
- 内容密度是否随任务变化，是否有整套卡片、反复口号或机械相同构图；
- 用户要求的投影、电脑、手机、离线与可编辑性是否实际检查。
PPTX逐页渲染；HTML实际打开并操作导航，阅读版测桌面与手机；图注来源与控件均不遮挡内容。记录页码、截图、具体问题及修正，不能只填“已检查”。
11.2图文提案按数据契约提交页面内容记录与素材对应关系，机器只检查交付完整性，人工/代理自审负责实际阅读与视觉判断。

## 交付时说清楚
实际文件及保存位置、完成范围、做过的内容与页面检查、仍缺的素材或验证。教学示范写明合成设定，少量试样不能包装成完整项目方案。不得报告虚构AI率、真人客研、独立评审或市场效果。
