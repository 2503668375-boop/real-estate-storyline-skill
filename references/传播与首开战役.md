# 传播与首开战役

## 1. 顺序

传播必须建立在已经确定的价值体系之后：

`核心概念 → 价值支柱 → 分众信息 → 内容章节 → 触点 → 媒介 → 案场与销售 → 首开行动`

媒介不是章节起点。活动不能代替概念，曝光不能代替相信。

同时读取 `全周期主题营销与动作系统.md`。本文件负责首开前后八个高强度窗口；完整营销还必须覆盖产品验证、持销、尾盘/现房和交付入住。

## 2. 分众转译

每类受众分别写：

- 已有信念；
- 隐性焦虑；
- 想成为谁；
- 最不相信什么；
- 需要何种证据；
- 项目只对他说的一句话；
- 最可信的讲述者；
- 最合适的触点；
- 希望他完成的动作；
- 衡量指标。

核心购买者、家庭共同决策者、市场解释者、社群种子不能收到同一套话术。

## 3. 内容五章

### 看见

让市场注意到真正发生的城市、土地或人物变化。以事实和问题起势，不急于喊项目名。

### 认出

让目标人物认出“这说的是我的生活”。用动作、代价、关系和选择，不用阶层标签。

### 相信

用图纸、参数、样板、工程、品牌制度、财务与第三方证据证明项目答案。

### 参与

让客户通过看房、体验、共创、预约、登记或社群行动亲手验证主张。

### 见证

用开放、认筹、首开、签约、交付和运营结果形成社会证明，并服务后续加推。

## 4. 首开八个时间窗

每个时间窗必须写：目标、主受众、信念任务、主内容、线上动作、线下动作、案场/渠道、货量价格、预算、负责人、KPI、切换信号和风险。

### 首开前120—90天｜定义问题

- 完成市场定调、项目叙事、概念语系和证据清单；
- 建立官方内容阵地和舆情基线；
- 做核心客群访谈、渠道访谈、老业主/一期客户唤醒；
- 确认示范区、样板间、销售物料和重大活动倒排；
- KPI以有效种子客户、内容资产完成率和关键证据补齐率为主。

### 首开前90—60天｜让目标人物认出自己

- 分众内容连续发布；
- 城市/板块/人物议题的权威、垂直和社交传播；
- 第一轮圈层闭门沟通、产品共鉴或顾问访谈；
- 渠道规则、客户保护和私域承接上线；
- 建立到访预约池。

### 首开前60—30天｜用产品证明

- 项目/案名/概念正式发布；
- 示范区、样板间、产品手册和价值证据开放；
- 媒体深度测评、大V探盘、产品直播和销售培训；
- 私域分层跟进；
- 测试面积段、总价、价格敏感与第一否决点。

### 首开前30天至开盘｜把相信转为承诺

- 价格预期管理；
- 登记、冻资、认筹、资格与合规信息；
- 一对一复访、家庭共同决策沟通、房源匹配；
- 渠道冲刺但保持客户保护和佣金纪律；
- 按日监测登记、冻资、认筹、复访和弃筹原因；
- 根据漏斗调整首推货量和价差。

### 首开当周｜组织成交

- 发布最终房源、价格、规则和流程；
- 完成选房系统压力测试、销控演练和全岗位彩排；
- 设置叫号、选房、财务、签约、按揭、客户异议、媒体、直播、舆情和应急岗位；
- 实时监控到场、选房、弃选、签约、渠道归因和库存；
- 对价格、系统、天气、交通、舆情和突发事件准备替代方案。

### 首开后首周｜把结果变成证据

- 统计到访、选房、成交、签约、复访、弃选；
- 复盘面积、楼栋、户型、总价和渠道；
- 做真实成交证据传播，不虚构“日光”；
- 回访弃选和高意向未成交；
- 调整库存、价差、渠道和内容。

### 首开后首月｜校准下一次销售

- 拆解线索成本、到访成本、成交成本和渠道费效；
- 校准价格、权益、产品展示和销售口径；
- 建立老带新、业主内容和工程进度传播；
- 准备下一批次货量和提价/守价方案。

### 每次加推｜重新判断

不得机械复制首开。重新评估市场、竞品、客户、库存、价差、渠道和舆情，再决定内容、货量和价格。

## 5. 开盘日运行书

完整提案至少有一页开盘日总流程和一页岗位/风险：

- 时间轴：到场、核验、等候、叫号、选房、确认、财务、签约、按揭、离场；
- 空间：客户流线、工作人员流线、媒体区、应急区；
- 系统：销控、叫号、直播、备份网络和纸质预案；
- 组织：总指挥、销售、财务、法务、银行、物业、安保、媒体、舆情、技术；
- 数据：实时大屏、每小时播报、异常阈值；
- 应急：系统宕机、拥堵、价格质疑、渠道争议、维权、天气和医疗。

## 6. 预算与漏斗

预算至少分为内容与制作、媒介投放、活动、案场与物料、渠道佣金、私域运营、首开执行、舆情与预备金。每项对应目标和负责人。

漏斗至少包括：

`有效触达 → 留资 → 有效线索 → 预约 → 到访 → 复访 → 登记/冻资 → 认筹 → 选房 → 签约 → 回款`

每一层写目标、实际、转化率、主要流失原因和纠偏动作。

## 7. 首开之外

首开结束不等于营销结束。完整提案必须另写：

- 持销期：围绕库存、客户障碍和证据缺口按月设主题；
- 尾盘/现房期：一房一策、实景证明、付款结构和定向渠道；
- 交付入住期：工地开放、交付预验、问题闭环、业主内容和转介绍；
- 长期复盘：把成交、流失、交付和运营反馈写回产品、价格、内容与服务。

这些阶段不能机械复制首开主题；每次重新判断市场、竞品、客户、库存、价差和舆情。
