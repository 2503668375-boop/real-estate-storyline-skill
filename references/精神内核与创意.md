# 精神内核与创意

精神内核来自项目对真实矛盾作出的不可逆选择：

`土地机制 → 人物动作与代价 → 未被说破的欲望 → 项目反对什么 → 项目相信什么 → 产品与经营如何证明`

## 发散纪律

完整要求见 `核心概念生成与比选.md`。只有市场、消费行为、产品战略和经营价格已成立后，才建立20条以上项目事实、8条以上客户难题与12条市场套话；再从12个角度形成至少60个初步方向，深化为18个方向和4个重点方向。每个方向必须准确解释既定事实、人物场景和产品经营选择，不能为了概念反向改变前策；只换“时间、生活、陪伴、附近、秩序”等词不计数。

## 主概念纪律

主概念必须是可占有的思想资产，而不是“独有 token + 通用利益”。宗地号、数字、道路名和罕见字不能单独证明原创。

必须同时产出：反命题、独有意义、意外解释、3—5个同源命名、三层传播、五章战役和至少5项产品/价格/营销改变。

## 审查纪律

先运行 `审查概念进化.py`，再运行 `审查创意总监闸门.py`，最后进入故事线导演。生成者不得独自判定通过；缺三重隔离评审时只能标记“方向待验证”。

反例：

- “B116-0059家庭回路”：行政编号制造伪专属，家庭时间利益可迁移到多数CBD项目；
- “献给懂生活的人”：客户不可识别、事实为空、不能改变产品；
- “以尺度回答时代”：对象可替换，无法指导价格与户型。
