# PPT与HTML交付规范 · 11.2
先读《中文地产汇报与图文成品》，选择一个主制作流程，按需读《发布会级视觉导演与版式系统》。用户已有项目品牌模板优先，不以页数、字数或占位比例证明完整。

## 文件与内容
按用户要求交付实际PPTX、HTML或PDF。要求可编辑时文字、图表及关键形状可编辑；不得用纯图片版冒充。价格、面积、图表和图片标注与当前底稿同源，变更后更新受影响页面与截图。
外部稿保留结论、依据、取舍、关键前提和动作；研究过程与完整来源可入附件。项目图标明实景、效果图或示意及来源。

## PPT
使用当前可用制作技能和运行环境，先检查模板、字体、图片与输出路径。实际渲染每一页，核对图形、中文、表格和讲稿；抽样打开不能代替完整逐页检查。

## HTML
UTF-8、中文语言声明；根据用户需要选择翻页演示或连续阅读。翻页型支持真实按钮/键盘/触摸操作，页码与URL hash对应实际页；阅读型可响应重排，检查桌面和手机。动效尊重减少动态偏好；离线要求下本地化依赖并检查。

## 内容与视觉双验收
通读标题、正文与讲稿，随后看缩略图和每一页原尺寸：字形、断行、溢出、遮挡、低清、来源、图表口径、节奏及重复。控件不遮正文和注脚，不用压小字体掩盖内容过量。以真实截图和问题记录为据。
按《11版数据契约与验收》提交成品及表达记录；11.2图文提案另交《中文地产汇报与图文成品》要求的页面与素材记录。机器通过只说明记录一致，语感和视觉由实际审阅判断。
旧HTML字数、属性、固定版式和六道闸门只复核旧项目，不限制新成果。正式文件按用户指定目录保存并回读；没有用户指定时遵循当前工作区约定。
