# 地产行业中文表达与案例启发

## 1. 基本要求

方法怎么推，方案就怎么说。内部底稿、审查脚本、会议讨论和客户提案尽量使用同一套地产中文，避免先套英文框架、再逐词翻译、最后又为汇报改写一遍。

判断一个词是否保留，只问三件事：

1. 项目总、营销总、设计总能否第一次听见就明白；
2. 这个词能否直接进入会议纪要、任务书和方案标题；
3. 去掉英文出处后，它在中国地产语境里是否自然。

不满足两项，就换成地产人日常会说的话。

## 2. 统一用语

| 不再使用 | 8.1统一说法 | 说明 |
|---|---|---|
| 品类旧答案 | 市场现有方案 / 行业常规做法 | 根据页面语境二选一 |
| 项目昂贵选择 | 项目取舍 | 必须进一步写“做什么、不做什么、付出什么” |
| 双重束缚 | 两难困境 | 直接说客户同时想要什么、又怕失去什么 |
| 竞品迁移测试 | 换盘测试 | 即“这句话换给竞品还能不能用” |
| 战略创意简报 | 概念推导底稿 | 避免与设计brief混淆 |
| 信息充分性与降级交付 | 资料等级判定 | A/B/C决定能下多深的结论 |
| 客户方向性盲测 | 概念初测 | 不先解释，先看客户怎么理解 |
| 通用态度警戒 | 警戒词 | 直接列词和淘汰条件 |
| 深描执行包 | 重点动作执行方案 | 名称、步骤、人员、物料、预算和转化一并展开 |
| 信念障碍 | 客户顾虑 | 写明为什么不留资、不到访、不复访、不成交 |
| 客户状态 | 客户决策阶段 | 如初识、比较、到访、复访、认筹、签约 |
| 英雄动作 | 核心动作 | 本阶段最能改变客户判断的动作 |
| 创意机制 | 动作设计 | 说明客户做什么、为什么有效 |
| 单一命题 | 核心判断 | 本次只讲透一件事 |
| 语言人格 | 表达调性 | 温度、姿态、节奏、用词与禁区 |
| 相信理由 | 可信依据 | 图纸、参数、实景、制度、客户行为 |
| 客户转变 | 客户获得的改变 | 从原来怎样，到项目建成后怎样 |
| 新评判标准 | 新的比较标准 | 客户以后用什么方式比较项目 |
| 价值证据单元 | 价值证明单 | 一项价值从决定、代价到客户结果的完整证明 |
| 竞品迁移 | 换盘 | 用最短的话表达测试动作 |
| 最后一跳 | 收束到概念 | 说清前面结论如何集中成一句话 |
| 失效信号 / 撤回条件 | 结论重算条件 | 何时必须推翻旧判断、重新测算 |
| 战役板 | 阶段营销总表 | 营销、销售、渠道、活动都能共用 |
| 归因口径 | 业绩认定方式 | 说明首触、关键触点和成交触点如何记 |

允许保留的专业词包括：项目定位、核心概念、推广案名、客户画像、产品定位、面积段、货值、去化、首开、持销、转化漏斗、设计任务书、价格敏感性、现金流安全线。它们在地产行业已有稳定含义。

## 3. 定位不是两字标签

地产定位最少回答：

`给谁做｜在什么市场里｜解决什么问题｜做成什么角色｜靠什么产品和运营做到｜明确不做什么`

外部可以压缩，但不能丢失角色和依据。建议用三层表达：

- **管理层定位句**：完整说明服务对象、市场角色和实现方式；
- **客户能记住的一句话**：用自然中文说清项目最值得选的地方；
- **案名或短句**：负责记忆和传播，不承担全部战略信息。

“高端、改善、青年、国际、全能、大盘、生活方式”都只能作为描述起点，不能单独构成定位。

## 4. 不同产品线，说法应当不同

### 首置与刚需

重点放在有限总价下最难解决的生活问题：

- 通勤、总价、得房、收纳、家务、孩子成长和交付确定性；
- 语言要平视、明白、有温度；
- 概念必须能导出户型效率、设备接口、社区使用和销售证据；
- 可用“好用、够用、以后也能用”等生活判断，少用“逆袭、圈层、上岸”。

### 首改与改善

重点是家庭关系和生活方式升级：

- 家庭成员边界、社交与独处、审美、健康、服务和长期变化；
- 既要有生活画面，也要有明确空间动作；
- 语言可以更有情绪，但必须接得上产品尺度、材料、会所和运营。

### 豪宅

重点是城市位置、稀缺资源、空间创造、定制能力、服务和长期资产：

- 不能只靠“大师、全球、顶奢、圈层”；
- 必须说明项目重新组织了什么城市资源、空间关系或服务体系；
- 越高端，越要写清项目取舍和不可复制的兑现能力；
- 文化表达必须有在地依据，不能把外来符号当高级感。

### 公寓、商办与综合体

重点是使用方式和经营角色：

- 谁在这里住、工作、会客、消费或运营；
- 解决的是住宿、商务、社交、资产管理还是城市服务；
- “一站式解决”必须拆成具体业态、服务、时段和运营主体；
- 建筑高度、复合业态和服务资源只有转成使用效率，才是定位依据。

## 5. 房企案例带来的方法启发

案例只观察表达方法，不照抄项目结论。

### 宸嘉

武汉嘉佰轩的公开表达集中在“超高层地标、高端公寓、顶尖商务人士、江景、酒店化服务和复合城市资源”。其有效之处是先说明产品是什么、服务谁，再用建筑高度、视野、会所、管家和综合体资源证明。用户提供的“超塔公寓、垂直领域一站式解决”也属于角色型定位：把建筑形态与产品作用直接相连。

### 万科

万科把不同客群直接分开：

- 拾系面向重视自然雅致和生活品质的改善客群；
- 映象系说“艺术潮奢的都心宅邸”，对应追求时尚表达的改善客群；
- 锦系用“风雅烟火，摩登东方”面向25—35岁的首置首改人群。

启发不在这些短句，而在短句后面都有明确客群、产品特点、模块和落地项目。概念短，证明不能短。

### 金地

金地长期按客户价值观和家庭生命周期组织格林、褐石、风华、世家、峯汇等产品线。褐石强调经典、优雅、浪漫，并落到红砖、坡顶、八角窗、开放街区和转角咖啡等稳定产品语言。

启发是：产品线表达要让客户价值观、建筑语言和空间细节长期一致，而不是每个项目重新造一套抽象词。

### 华润置地

行业研究把华润住宅归纳为润、悦、瑞、时光和小公寓等不同方向：润系偏温润、雅致、均衡；悦系偏精致、仪式；瑞系偏先锋和高端；时光系偏温情、人文、烟火；小公寓回应都市青年的阶段性居住。

启发是：不同档次对应不同的客群任务、产品精神和硬核模块，不能只替换一组形容词。

### 中海

中海“萬方安和”把四条线直接对应不同人群和生活方向：“萬”面向全球精英，“方”强调可传承的艺术资产，“安”从特定高端客群的生活形态做定制，“和”回到家庭和日常。

启发是：高端与主流产品可以共享企业底盘，但必须拥有不同客户、不同场景和不同产品证据；不能用同一套豪宅语汇覆盖全部项目。

## 6. 方案标题与正文

标题优先使用：

- 市场正在发生什么，因此本案应该怎么做；
- 客户最难解决什么，本案用什么产品解决；
- 行业通常怎么做，本案为什么不这样做；
- 这项设计决定，让客户具体得到什么。

正文优先使用短主语和主动句：

- “我们建议主力做110—125㎡”，不要写“基于综合研判所生成的主力面积策略为……”；
- “这句话换给竞品仍能用，必须重做”，不要写“项目占有性不足”；
- “客户听不出在说谁”，不要写“受众相关性未达到阈值”；
- “资料不足，只能定方向，不能定案名”，不要写“执行降级交付”。

## 7. 中英文边界

可以保留已经行业化的英文缩写，如TOD、SLA、KPI、CRM、RACI，但第一次出现要给中文解释。非必要不使用 category、proposition、RTB、double bind、salience、hero action 等英文及其生硬直译。

梵文、英文、法文等只用于命名候选和文化研究，不能进入中文策略主链，更不能用外语掩盖定位不清。

## 8. 终审

交付前连续朗读三遍：

1. **项目总听法**：能否立刻判断做什么、不做什么、赚什么、担什么风险；
2. **营销总听法**：能否直接转成案场、传播、活动和销售动作；
3. **客户听法**：是否像在说真实生活，而不是策略公司内部黑话。

任何一句需要另一个人“翻译一下”，都要重写。
