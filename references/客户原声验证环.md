# 客户原声与支付验证 · 11.0
深访发现任务和顾虑，含真实总价与替代品的选择测试验证取舍，实际预约/复访/交易验证行动。三类证据互补，不能让单条原声自动压倒交易数据。
样本覆盖目标客户、买竞品者、未购买者、放弃或延后者及共同决策人；按客群差异和信息饱和安排数量，10—15组只能是定性研究起点，不能代表城市购买比例。

## 访谈
问具体最近事件：现居摩擦、换房触发、看过和放弃哪些盘、谁付款与拍板、最不愿牺牲什么、预算资金如何到位。展示产品时使用可比总价与选项，避免先讲概念引导赞同；记录拒绝和不一致。
记录匿名ID、日期、样本来源、原话和上下文、记录文件、允许使用范围。无真实访问不写“客户说”，推演单列。

## 家庭支付链
旧房预期成交区间－未偿贷款－交易支出=旧房净回款；再加可动用现金及已确认支持资金，扣家庭保留资金，得到可投入自有资金。
新增贷款结合本地政策、银行估值、收入负债、年龄期限与审批，不能根据最低首付反推人人贷满。卖旧签约/到账、新房付款、过渡居住、解押等时间放同一张表；企业资产不自动是家庭现金。
客户池按去重家庭、真实购买期限、资金资格和替代选择收窄，不把员工数、小区户数、意愿样本直接当成交量。

## 验证回流
否决点 → 产品/展示/交易修正；含价选择 → 配置与总价取舍；复述与下一步 → 概念与销售证据；真实行为 → 更新假说。
意见冲突先查样本和激励，记录不确定性与下一步，不能以多数投票代替可行性。空间/审批已锁定时只建议可调整项并算成本。
