# 人文概念与受众传播

> 11.0适用说明：本文件保留创作方法、历史案例或旧格式经验；固定页数、字数、候选/支柱数量、词性和旧脚本门槛仅作历史参考。新任务按SKILL.md、《价值提炼与推导》及《11版数据契约与验收》执行。关键假设进入决策正文，公共技能不随项目操作自动回写。

## 人文概念的资格

人文概念不是历史符号、名人引文或艺术风格。它必须回答：

1. 这群人今天正在承受什么具体矛盾；
2. 项目对此采取什么清晰立场；
3. 这种立场如何成为可重复的日常实践；
4. 哪些人会因此认出自己、愿意加入并向别人转述。

生成链：

`地方/时代事实 → 当代人的矛盾 → 共同价值选择 → 项目立场 → 空间/产品/服务实践 → 参与者行为 → 可传播的公共意义`

只有“文化来源”没有“当代矛盾”是符号挪用；只有“精神口号”没有“日常实践”是广告；只有活动没有参与者关系是流量。

## 四层转译

### 1. 城市层：公共意义

说明项目为城市补上什么缺失的关系、空间或生活方式。避免“城市封面”；写清谁会因此受益、城市旧问题怎样被改变。

### 2. 社区层：共同生活

把概念转成公共空间、规则、服务、社群和持续内容。重点写清谁能发起、谁能参与，以及关系和记忆如何形成。

### 3. 家庭层：具体进步

把宏大概念译成家庭共同决策：时间怎样被释放、代际关系怎样改善、孩子看到什么、老人怎样参与、家庭身份如何被确认。

### 4. 个体层：自我表达

给客户一个可复述的自我定义和可完成的动作。人文概念最终应让人说“这像我想成为的人”，而非“开发商很有文化”。

## 受众翻译矩阵

完整方案至少覆盖四类受众：

1. **核心购买者**：承担主要资金与最终选择；
2. **家庭共同决策者**：配偶、父母、子女等否决或推动者；
3. **市场解释者**：经纪人、媒体、地产大V、老业主，决定概念如何被转述；
4. **文化/社群种子**：主理人、教育者、艺术与运动社群、未来活跃业主，决定概念能否成为真实生活。

每类必须写：

- 已有判断：他现在怎样理解该板块、同类产品和项目；
- 隐性焦虑：他不愿公开说，但会影响选择的担心；
- 期望身份：他希望购买后成为怎样的人或家庭；
- 证据门槛：什么事实、人物或体验才足以让他相信；
- 主信息：只对这一类人最重要的一句话；
- 内容母题：用哪类连续故事反复证明；
- 可信讲述者：谁说比开发商自说更可信；
- 触达场景：在决策链哪个时刻出现；
- 行动：看完之后做什么；
- 指标：怎样判断信念被改变，而非只有曝光。

“小红书/视频号/活动/私域”只是载体，不是矩阵答案。

## 从概念到内容的五章

1. **看见**：用土地、城市或人物事实打破旧认知；
2. **认出**：让目标受众在具体处境中认出自己；
3. **相信**：用设计选择、工程代价、实景或第三方证据证明；
4. **参与**：让受众完成一次真实动作，成为共同创造者；
5. **见证**：让交付、运营和业主行为持续反证主张。

每章都要有旧认知、核心证据、人物故事、内容载体、可信讲述者和承接动作。五章是认知进程，不是五场活动。

## 三条传播回路

### 购买决策回路

搜索/听说 → 比较 → 到访 → 家庭讨论 → 资金判断 → 认筹/成交。内容依次解决“与我有关、可信吗、值得贵、家人同意、风险可控”。

### 社会证明回路

种子人物先体验 → 形成可观察行为 → 第三方记录 → 同类人转述 → 新参与者加入。没有真实行为，KOL只能制造短期声量。

### 长期品牌回路

项目主张 → 运营制度 → 居民实践 → 内容资产 → 公共评价 → 反哺产品和服务。人文概念必须允许真实反馈修正，不得只维护话术一致。

## 传播底稿结构

建立 `人文传播底稿.json`：

- `人文概念`：概念、地方/时代事实、当代矛盾、项目立场、生活实践、公共意义、失败边界；
- `受众翻译`：至少4类受众卡；
- `内容五章`：看见、认出、相信、参与、见证；
- `触点一致性`：案名、销售说辞、示范区、内容栏目、活动、交付运营如何同源；
- `验证计划`：访谈、内容测试、到访观察、转述测试、成交/流失复盘。

## 人文概念否决项

- 只引用地方历史、器物、诗词，没有当代人的问题；
- 把“高知、高净值、精英”当精神身份；
- 所有人收到同一句话，只换平台和海报尺寸；
- 可信证据全部来自开发商自述；
- 内容只有节庆和打卡，没有日常与制度；
- 受众看完只能点赞，不能形成到访、讨论、参与或选择；
- 概念在销售期结束后无法继续被交付和运营验证。
