# 叙事导演卡、视觉母题与情感节奏

## 适用边界

本文件用于将已经通过前策、价值推导、概念比选与独立创意终审的项目，组织成可记住、可视化、可销售复述的故事线。它只决定叙事入口、节奏和表达系统；不得以城市事件、历史、符号或文采替代事实，亦不得反向改写产品、价格和定位。

## 一、叙事导演卡

每个项目定稿前建立一张卡，只允许 1 个主切入角度与 1—2 个辅助角度：

| 角度 | 可用条件 | 必填证明 | 常见失效 |
|---|---|---|---|
| 城市价值 | 城市、板块或规划机制确实改变项目机会 | 规划、交易、产业或供给事实及其产品后果 | 宏观口号未落到客户选择 |
| 历史文脉 | 有可核验的场所、人物、事件或遗存 | 原始来源、地点、时间、可转化机制 | 用传说或泛古风冒充记忆 |
| 生活方式 | 已有目标人物、动作摩擦和空间解决方案 | 人物时刻、产品机制、支付理由 | 把美好生活当作生活方式 |
| 价值观共鸣 | 企业或客群有可验证的共同选择 | 目标决策者、真实代价、空间/运营载体 | 开发商自我表扬 |
| 城市事件 | 事件与项目有真实且持续的机制联系 | 事件来源、时效、长期价值后果 | 借热点替代长期判断 |
| IP或符号 | 土地、空间、名称或运营中存在独有线索 | 来源、人物连接、跨触点应用 | 谐音、泛意象或凭空造物 |

卡片最低字段：`主切入角度`、`辅助切入角度`、`选择依据`、`事实锚点`、`叙事对象`、`禁用联想`、`失效或撤回条件`。主角度必须服务于已成立的核心概念；辅助角度只能补充，不能形成第二套定位。

非住宅项目先写清叙事对象：商办面对企业决策者，产业园面对企业成长机制，商业同时面对消费者与招商方，综合体则先写城市母题，再为每种业态写独立分镜。住宅话术、居家温情或单向消费者视角不能直接套用。

## 二、视觉母题卡

每个最终概念至少有 1 张视觉母题卡。母题不是 Logo，也不是“光、水、山、自然、未来、梦想”之类可替换的词。

`真实事实来源 → 可见的物件/形态/节律 → 人物正在发生的动作 → 空间或服务机制 → 视觉语言 → 传播与运营触点`

每张卡须包含：

- `母题`：具体且可被画出、拍出、设计出；
- `事实来源`：可定位到土地、空间、历史、名称或运营事实；
- `人物或生活连接`：谁在什么时刻怎样感知它；
- `视觉语言`：材质、光线、构图、运动或声音的可执行方向；
- `空间或传播触点`：至少两个，覆盖空间、案场、内容、活动或服务中的真实场景；
- `禁用俗套`：与项目气质冲突、会造成误读或无证据支撑的表达。

筛选时逐项检查：离开项目是否仍成立、能否在视觉中识别、能否跨触点延展、是否改变客户对产品价值的理解。任何一项为否，退回重做。

## 三、情感节奏卡

故事线需有完整的情感路径：`进入 → 触动 → 共鸣 → 认同 → 余韵`。每一段都要写已被验证的事实或项目机制，且将情感高点放在认同前后，而非开头堆砌气氛。

至少配置 2 个情感锚点。每个锚点记录 `类型`、`人物或细节`、`事实或机制`、`所在章节`：

- 具体细节：人物与物件的可见动作；
- 时间跨越：已核验的过去、现在与可兑现的未来；
- 认知转折：先前比较标准因何被改写；
- 身份认同：特定人群如何认出自己的处境；
- 留白：在已完成价值论证后留下可由客户自行补全的余韵。

严禁用没有事实依据的名言、历史传说或“我们相信”收束。若使用署名引文，仍须遵循故事线导演法中的出处、译文及其改变空间或产品决定的完整记录。

## 四、输出前检查

1. 主切入角度能否被至少两项上游事实和一个产品/经营后果支持？
2. 主角度删去后，核心概念是否仍能由项目事实识别；若不能，先补足前策。
3. 每个视觉母题能否落到至少两个真实触点，且不会被竞品自然复用？
4. 情感锚点是否让目标人物看到自己的动作、两难或改变，而非只看到形容词？
5. 非住宅是否同时覆盖正确的决策对象与其对应的价值证明？

全部通过后，才允许进入章节、主视觉、影片及销售转述的制作。
