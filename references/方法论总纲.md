# 方法论总纲 · 11.0
## 任务先于流程
先明确本轮决定什么、决定后什么能改变。前策、定价、滞销、概念、运营各自选模块；专项不强制展开全案。

## 六个衔接判断
1. 目标与边界：阶段、经营优先级、现金时限、可改/锁定项、合作方和权限。
2. 市场与客户：真实替代品、有效需求规模、家庭/企业任务、预算与付款时序。
3. 产品与经营：比较实质不同的可行方案，联算面积货值、成本、去化和现金，记录舍弃。
4. 价值与概念：解释资源怎样改变客户结果，选择有证据的优势，统领兑现和表达。
5. 操盘与反馈：库存诊断、动作比较、预算负责人、可回退试验、净成交与回款复盘。
6. 交付与决策：结论与关键前提同屏，制作成品时实际检查页面。
允许证据驱动的回退，不为保住概念隐去成本和反方证据。

## 规则分层
法规/合同核适用性；长期方法管同口径、现金流与可证伪；项目约束来自真实资金工程与授权；渠道偏好是经验假说；个案案名、修辞、面积及视觉反馈是案例偏好。后二者不能升级为全国否决项。

## 两个闭环
经营：目标库存 → 流失原因 → 替代动作 → 增量现金与资源影响 → 执行 → 同批客户/房源复盘。
价值：事实 → 可用机制 → 客户获得与代价 → 竞争比较 → 选择/支付证据 → 项目取舍 → 概念表达 → 产品及市场验证。
稳定主张允许不同购买入口；战略一致不要求每条传播重复同一意象。

## 三种独立状态
证据：已核验/待核验/冲突/估算/已失效。
决策：探索/条件推荐/待责任人批准/已批准。
发布：内部研究/对外提案/公开物料待审/可发布。
研究完整不自动允许发布；未知项按影响限制结论，继续完成不依赖该项的工作。

## 验收问句
最大经营问题是什么？客户为何现在改变选择？最强替代是什么？差异能兑现且愿支付吗？动作改善多少现金并牺牲什么？什么证据会让我们改向？报告有没有清楚写出关键前提？
