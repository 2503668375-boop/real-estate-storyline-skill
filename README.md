# 地产故事线 11.3

面向中国地产策划、营销和经营团队的 Codex Skill。从市场、土地、客户和竞品里找出购买理由，再把它落到项目定位、产品取舍、价格和推售动作。

[在线介绍与案例](https://2503668375-boop.github.io/real-estate-storyline-skill/) · [Skill 入口](SKILL.md) · [项目资料清单](references/项目输入清单.md)

## 适用场景

| 你在做什么 | Skill 可以协助交付什么 |
| --- | --- |
| 项目定位和前策 | 客户购买任务、竞品替代、产品情景比较和设计建议 |
| 卖点、主题和故事线 | 核心购买理由、备选主题及取舍、章节主线与传播表达 |
| 定价、持销和去化 | 价格、库存与回款的对比测算，销售动作及适用条件 |
| 汇报和完整提案 | 含证据、比较、推荐及执行安排的正文，以及成品检查 |

11.3 扩充了完整提案的论证方法和检查工具。完整故事线要能逐项指出关键判断来自哪段正文，以及项目最终为何选择这个产品、价格或动作。可以只调用某个模块，例如单独审查一组卖点。

## 安装到 Codex

把下面这句话复制到 Codex，等安装完成后开一个新会话使用。

```text
请用 $skill-installer 安装地产故事线 Skill。仓库是 2503668375-boop/real-estate-storyline-skill，分支是 main，Skill 在仓库根目录（--path .），安装名使用 real-estate-storyline-8-1。已有同名 Skill 时先核对版本。
```

手动安装也可以。点击绿色 **Code → Download ZIP**，解压后将整个文件夹命名为 `real-estate-storyline-8-1`，放到当前项目的 `.agents/skills/`。个人所有项目共用时，放到 `~/.agents/skills/`。保留 `SKILL.md`、`agents/`、`references/` 和 `scripts/` 的相对位置。

## 试用

```text
用 $real-estate-storyline-8-1 帮我做改善住宅项目的定位和完整故事线。先根据我给的项目资料判断哪些产品条件可改，再比较目标家庭的备选楼盘。给出主推购买理由、最强备选和改判条件，把主推方向落实到产品、价格和推售动作。资料缺失处列明假设和验证办法。
```

可以先提供项目阶段、已锁定的产品条件、销售目标、客户反馈和竞品成交口径。联网研究、图片和 PPT 制作取决于所用环境。检查和测算脚本需要 Python 3，核心脚本使用标准库。

## 方法与公开资料

- [`references/`](references/) 提供按任务选读的方法、模板和失败示例。示例中的设定用于演示和检查。
