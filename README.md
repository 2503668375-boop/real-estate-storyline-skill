# 地产故事线 Skill · 公开分发版

将项目事实、客户需求、产品价值与经营判断组织成有依据的地产策略和故事线。适用于前策定位、价值提炼、现售与持销、营销推售和完整提案。

本公开版基于 11.1，保留 `real-estate-storyline-8-1` 调用名。

## 能做什么

- 从市场、客户与产品事实推导定位，整理价值主张及证明链。
- 将项目经营约束转成可比较的价格、货量与营销动作。
- 组织有文学辨识度的故事线、标题和演示顺序。
- 检查证据、数值口径、表达和成品完成度。

## 安装与使用

将整个仓库放入支持 `SKILL.md` 的智能体技能目录，并将目录命名为 `real-estate-storyline-8-1`。例如个人 Codex 技能目录可使用 `~/.agents/skills/real-estate-storyline-8-1`；已有同名目录时先核对，不直接覆盖。

调用示例：

> 使用地产故事线 Skill，根据我提供的项目资料，先判断当前阶段和主要经营问题，再梳理客户、产品价值与故事线。缺少的数据明确列出，不编造事实。

`SKILL.md` 是入口；`references/` 提供按任务读取的方法；`scripts/` 提供数据契约和交付检查。脚本需要 Python 3。联网研究、PPT 或图片制作由所在智能体环境提供。

## 公开范围

本仓库包含方法说明、通用模板、检查脚本和失败回归样本。未附带实际项目底稿、客户资料、内部经营数据库、账号配置、密钥或旧仓库历史。回归样本用于检验结构与失败情形，不是实际业务结论。

政策、价格和市场信息须在具体任务中重新核查适用范围和日期；结构校验不能证明市场判断正确、销售效果或视觉质量。使用者应只提供有权处理的项目资料。

方法来源的引用与链接见 `references/方法来源索引.md`。
